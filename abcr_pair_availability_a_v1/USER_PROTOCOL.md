建议开展一个不训练 ABCR 的“跨任务有效样本对可用性实验”（Cross-Task Pair Availability Study），先统计真实 LIBERO 回放数据中共享动作对、动作分叉对的数量、覆盖率和匹配可信度，再决定 ABCR 是否值得训练。

该实验需要回答三个问题：有效样本对是否存在、数量是否足够、能否在实际 Mini-batch 中稳定采样。

## 一、实验分为两个阶段

| 阶段             | 使用的数据                                 | 目的                           |
| -------------- | ------------------------------------- | ---------------------------- |
| 实验 A：原始 MLR 筛查 | 现有 `.pt` 文件中的 `feature` 和 `actions`   | 不修改回放数据，统计视觉相似且动作一致／冲突的候选样本对 |
| 实验 B：物理状态复核    | 原始 LIBERO 示范重新导出的机器人状态、未调制视觉特征及短期未来动作 | 确认候选对是否真正具有可比状态与动作分叉关系       |

我核对了作者的 [MLR 数据读取代码](https://github.com/yfqi/lifelong_mlr_ifa/blob/main/libero/lifelong/algos/mlr.py)。典型文件存储的特征形状是 `[1, 8, 4, 512]`，同时包含动作标签。

这里有两个重要限制：

- 保存的多模态特征已经过语言相关处理，不能直接将其余弦相似度视为真实物理状态相似度。
- 现有动作窗口可以比较最后一步动作，或回顾窗口内的历史动作；但不能保证提供窗口结束之后的未来动作。

因此，实验 A 是候选样本筛查，实验 B 才是判断 ABCR 机制能否成立的主要证据。 目前只有论文和代码、没有实际 LIBERO `.pt` 回放文件，无法提前报告真实的样本对数量。

## 二、实验 A：在原始 MLR 文件中统计候选样本对

### 1. 按原始终身学习阶段取数据

严格模拟论文的数据可用条件：

\\[ \mathcal M_k=\mathcal D_k\cup\mathcal B\_{k-1} \\]

只允许当前任务样本 \\(i\in\mathcal D_k\\) 与历史回放样本 \\(j\in\mathcal B\_{k-1}\\) 配对，不能提前访问未来任务的数据。

按照原论文的任务顺序，分别在 LIBERO-OBJECT、LIBERO-GOAL 和 LIBERO-50 的持续学习阶段统计。有多个新任务同时进入的阶段，应单独统计各新任务与历史缓冲区的匹配情况。

Yu 等 - Lifelong imitation learning with multimodal latent replay and incremental adjustment.pdf



### 2. 计算视觉相似性

原始特征表示为：

\\[ H_i\in\mathbb R^{L\times M\times E} \\]

初步筛查采用最后时间步的两个视觉模态：

\\[ s\_{ij}^{v} = \frac12\left[ \cos(v_i^{agent},v_j^{agent}) + \cos(v_i^{eih},v_j^{eih}) \right] \\]

定义视觉候选对：

\\[ C\_{ij}^{A}=\mathbb I(s\_{ij}^{v}\geq\tau_v) \\]

建议先扫描以下阈值：

| 视觉阈值 \\(\tau_v\\) | 实验用途   |
| ----------------- | ------ |
| 0.70              | 宽松筛查   |
| 0.80              | 中等筛查   |
| 0.90              | 严格筛查   |
| 0.95              | 高相似度筛查 |

这些只是敏感性分析的候选阈值，不代表已经校准的物理状态相似度。

### 3. 比较专家动作

先采用原始文件中与最后时间步对应的 7 维专家动作。

将前六个运动控制维度分别按固定统计量归一化，计算：

\\[ D\_{ij}^{motion} = \sqrt{\frac16\sum\_{d=1}^{6} \left( \frac{a\_{i,d}-a\_{j,d}}{\sigma_d} \right)^2} \\]

夹爪开合维度单独比较，避免其离散性质被运动维度掩盖。

对于视觉候选对：

\\[ w\_{ij}^{+} = C\_{ij}^{A} \mathbb I(D\_{ij}^{motion}\leq\tau\_+) \mathbb I(\text{夹爪动作一致}) \\]

\\[ w\_{ij}^{-} = C\_{ij}^{A} \mathbb I( D\_{ij}^{motion}\geq\tau\_- \\;\lor\\; \text{夹爪动作冲突}) \\]

要求 \\(\tau\_+<\tau\_-\\)，确保共享与分叉类别互斥。

还应单独统计双侧运动接近零的共享对。这些对可能只是机器人同时处于静止状态，不足以支持通用运动技能复用的结论。

## 三、必须输出的统计指标

不要只报告全部组合中的正负对数量，因为滑动时间窗之间高度重叠，容易夸大有效样本量。

建议每个持续学习阶段生成以下统计表：

| 指标                        | 定义                                            | 判断作用     |
| ------------------------- | --------------------------------------------- | -------- |
| \\(N\_{\mathrm{all}}\\)   | 所有跨任务组合数量                                     | 数据规模     |
| \\(N\_{\mathrm{match}}\\) | 视觉匹配候选数量                                      | 是否有可比较状态 |
| \\(N\_{\mathrm{share}}\\) | 状态候选匹配且动作相似的数量                                | 共享约束可用性  |
| \\(N\_{\mathrm{bif}}\\)   | 状态候选匹配且动作冲突的数量                                | 分叉约束可用性  |
| \\(R\_{\mathrm{share}}\\) | \\(N\_{\mathrm{share}}/N\_{\mathrm{match}}\\) | 共享对条件占比  |
| \\(R\_{\mathrm{bif}}\\)   | \\(N\_{\mathrm{bif}}/N\_{\mathrm{match}}\\)   | 分叉对条件占比  |
| \\(C\_{\mathrm{share}}\\) | 至少拥有一个共享匹配的新任务样本占比                            | 新任务覆盖率   |
| \\(C\_{\mathrm{bif}}\\)   | 至少拥有一个分叉匹配的新任务样本占比                            | 分叉监督覆盖率  |

其中，覆盖率尤其重要：

\\[ \boxed{ C\_{\mathrm{share}} = \frac1{|\mathcal D_k|} \sum\_{i\in\mathcal D_k} \mathbb I\left(\sum_jw\_{ij}^{+}>0\right) } \\]

分叉覆盖率同理。

例如，即使存在大量共享对，如果它们全部集中在少数重复时间窗上，ABCR 对大部分新任务样本仍可能不起作用。

## 四、实验 B：验证真实的状态可比性与未来动作分叉

这是决定是否值得开发完整 ABCR 的核心环节。

利用原始 LIBERO HDF5 专家示范，重新导出与每个 MLR 样本严格对应的：

- 机器人状态：关节状态、末端姿态及夹爪状态，以实际可用观测字段为准。
- 未经 FiLM 语言调制的双视角视觉特征。
- 从当前监督时间步开始、长度为 \\(q\\) 的未来专家动作片段。
- `task_id`、`demo_id`、`timestep`、有效长度掩码。

### 1. 状态可比性复核

\\[ \boxed{ C\_{ij}^{B} = \mathbb I(s\_{ij}^{v,raw}\geq\tau_v) \mathbb I(D\_{ij}^{state}\leq\tau_s) } \\]

这里的 \\(D\_{ij}^{state}\\) 可以使用归一化机器人状态距离，或末端位置、姿态的物理距离。

阈值应在基础任务的校准数据上固定，不能为了得到足够多的正负样本而在测试阶段反复调整。

### 2. 使用未来短期动作

\\[ A_i^+=[a\_{t_i},\ldots,a\_{t_i+q-1}] \\]

比较 \\(q=1,3,4\\) 三种设置。

尤其关注：两个样本在当前物理状态上具有可比性，但后续几步动作开始产生明显不同的操作方向。

这一条件比单纯的动作向量不同，更接近 ABCR 所声称的 Action Bifurcation。

需要说明的是，未来动作只用于离线判断和对比监督，不作为策略当前时刻的输入。

### 3. 人工抽检

从共享、分叉和不确定三类中，按任务对分层随机抽取样本，例如每类 50–100 对。

查看对应原始视觉帧及短期动作轨迹，检查：

- 机器人是否处于真正可比较的操作状态。
- 共享对是否体现有意义的运动共性，而非单纯静止。
- 分叉对是否体现控制意图差异，而非时间错位或状态匹配错误。

建议由两名标注者独立判断，统计类别正确率与标注一致性。因为自动匹配特征可能存在系统性偏差，不能把阈值分类结果直接当作真实标签。

## 五、模拟实际 Mini-batch：检查训练信号是否足够

即使全数据中存在大量匹配，也不代表训练时可以稳定获取。

需要对比两种采样方式：

| 策略     | 设置                                 |
| ------ | ---------------------------------- |
| 随机平衡采样 | 每批随机采样 5 个新任务样本、5 个旧任务样本           |
| 匹配检索采样 | 对每个新任务样本，从历史 Buffer 检索 Top-5 个候选邻居 |

分别模拟例如 500 个训练批次，记录：

\\[ P\_+=P(N\_{\mathrm{share}}^{batch}\geq1) \\]

\\[ P\_-=P(N\_{\mathrm{bif}}^{batch}\geq1) \\]

\\[ \boxed{ P\_{\mathrm{both}} = P(N\_{\mathrm{share}}^{batch}\geq1 \land N\_{\mathrm{bif}}^{batch}\geq1) } \\]

同时记录每批正负对的平均数量、不同旧任务覆盖数量，以及去除重复轨迹窗口后的有效样本对数量。

这能回答一个非常实际的问题：ABCR 是否需要专门的 Hard Pair Mining，还是原始随机 Mini-batch 已经能够提供充分监督？

实验 B 有轨迹标识后，还应以演示轨迹为单位进行 Bootstrap，给覆盖率和批次可用率提供置信区间，而不是将同一演示的重叠窗口当作独立观测。

## 七、如何根据实验结果决定是否采用 ABCR？

可以预先设定以下工程性判断标准。这些不是 LIBERO 已验证的经验阈值，而是帮助做 Go/No-Go 决策的初始标准。

| 实验现象                                        | 判断         | 下一步                   |
| ------------------------------------------- | ---------- | --------------------- |
| 人工复核的共享和分叉样本正确率都达到约 80% 以上，且检索训练批次大多能获得两类样本 | 值得开发 ABCR  | 开始训练消融实验              |
| 全数据中正负对充足，但随机批次里经常缺失                        | 采样机制不足     | 加入跨任务 Top-\\(K\\) 检索  |
| 共享样本几乎全部来自静止动作                              | 共享监督质量可疑   | 排除静止主导样本，加入动作阶段判断     |
| 分叉样本极少，但集中于明确的接触或抓取决策阶段                     | 仍可能有价值     | 设计针对关键阶段的分叉采样         |
| 视觉相似对经物理状态复核后大量失效                           | 匹配机制存在问题   | 改善状态描述符，不宜直接训练 ABCR   |
| 两类样本在多阶段、多任务对中均非常稀少                         | 核心机制缺乏数据支撑 | 重新考虑 ABCR 或替代 IFA 的方向 |

最终建议：先运行实验 A，重点查看 `anchor_share_coverage_retrieved`、`anchor_bif_coverage_retrieved` 和 `fraction_batches_with_both` 三个字段。

随后对筛出的候选对做实验 B 的状态复核。只有确认这些匹配不仅数量充足，而且确实反映机器人操作的共享技能与动作分叉，才有充分理由投入完整 ABCR 训练。

这个前置实验只能证明监督信号的可用性与可信度，还不能证明它一定提高 FWT 或产生正 BWT；后两者仍需完整持续学习闭环评估。
