**下一步只新增 E1-U：保留 E1 的候选池、500步刷新和50%同任务替换，将池内按分数加权改为均匀有放回抽样，用一次 LIBERO-OBJECT、seed42 的完整闭环实验区分“评分加权”与“小候选池复用”的作用，已有 E0、E1 均不重跑。**

复盘已经确认：评分确实影响了检索，但短期重复主要来自候选范围限制；现有日志尚不能判断这两部分分别对闭环表现产生什么影响。因此，本轮是**机制消融实验，不是提前认定均匀采样会更好**。

# 一、实验定义：只取消池内评分加权

## 1. 三个版本的关系

| 版本 | 旧样本位置如何处理 | 本轮是否运行 |
|---|---|---|
| **E0：原始 MLR＋IFA** | 原 DataLoader 随机规则 | 不运行，读取已有结果 |
| **E1：保护性检索** | 约一半保留原样本，另一半从同任务64候选池按分数抽样 | 不运行，读取已有结果 |
| **E1-U：同池均匀检索** | 保留相同替换机会，但从同任务64候选池均匀抽样 | **只运行这一组** |

E1 当前使用：

\[
q_j^{E1}(i)=
\frac{\exp(s_i/\tau)}
{\sum_{k\in C_j}\exp(s_k/\tau)}.
\]

E1-U 改成：

\[
\boxed{
q_j^{U}(i)=\frac{1}{|C_j|},\qquad i\in C_j.
}
\]

正常情况下 \(|C_j|=64\)，因此每个候选的概率为 \(1/64\)。

**候选池仍保持500步，不扩大、不缩短刷新周期、不改成无放回抽样。** 否则这次实验就无法单独检验评分加权的作用。

## 2. 预先规定两个比较

设三个版本的主口径总体 AUC 分别为 \(A_0,A_1,A_U\)。

\[
\Delta_{\mathrm{weight}}=A_1-A_U
\]

用于判断：**在同一候选池复用机制下，评分加权是否带来额外收益。**

\[
\Delta_{\mathrm{structure}}=A_U-A_0
\]

用于判断：**不使用评分时，这种候选池重采样结构相对于原随机规则是否有收益。**

第二个比较包含“小池限制＋有放回替换”等采样结构变化，**不能单独解释成候选池大小的纯因果效应**。两个差值也都只是本次单 seed 的观测，不是稳定效应估计。

当前源码的候选构造、评分、概率保存及抽样入口都集中在 `replay_selection.py`，可以完成这种局部修改。

E1-U 仍计算历史参考、新任务参考和候选头部梯度，保留原数值检查、模式恢复和随机状态隔离。

这样做是为了**尽量只改变概率规则**，不同时改变评分调用、异常路径及计算结构。评分结果只作为旁路日志，不进入训练损失、样本数量控制或检查点选择。

还要修改复制后的 `prepare.py`：当前代码通过 `asdict(SelectionConfig())` 生成运行配置和合同，必须让这两个位置都显式生成 `pool_weighting="uniform"`，不能只改一份未被读取的配置文件。

# 三、严格配对：候选池要相同，不只是候选数相同

这是本轮比普通消融更重要的执行要求。

## 1. 保持原随机调用方式

原选择器使用同一个独立 `random.Random` 实例，依次完成参考抽样、候选抽样、替换门控和候选抽取。

E1-U 继续使用原调用：

```python
item_id = self.rng.choices(
    distribution["ids"],
    weights=distribution["probabilities"],
    k=1,
)[0]
```

只把 `probabilities` 换成均匀概率。

**不要改成 `random.choice()`、`randrange()` 或另一种抽样实现，也不要重新排序候选ID。** 否则随机数消耗方式或ID映射可能改变，使后续候选池和替换机会不再对应。

## 2. 用 E1 已有日志检查配对是否成立

按“阶段—刷新步—旧任务”逐项比较：

| 配对对象 | 要求 |
|---|---|
| 历史参考ID | 与 E1 相同 |
| 当前参考ID | 与 E1 相同 |
| 候选ID及排列顺序 | 与 E1 相同 |
| 刷新步数 | 与 E1 相同 |
| 被尝试替换的位置 | 在无回退、无否决的情况下，与 E1 相同 |
| 实际抽中的候选ID | **允许不同，这是实验处理本身** |
| 梯度、分数、模型参数 | **允许不同，这是训练轨迹改变后的结果** |

比较器只读取旧日志作检查，不用 E1 的分数、模型或闭环结果指导 E1-U。

原 E1 没有无效候选、退化回退或IFA参考否决，因此在相同输入、相同随机调用路径下，本轮有条件保持严格的候选池配对。

如果出现配对差异，必须保留日志并检查原因，**不能换seed、重抽候选直到匹配，或事后把不同候选池称为同池对照**。真实发生的数值回退仍执行原安全规则；如果因此破坏配对，应在结果中明确降级该比较的解释强度。

## 3. 不改变原训练 batch 的结构

继续维持逐批不变量：

\[
n_N^U=n_N^{E1},\qquad
n_R^U=n_R^{E1},\qquad
n_j^U=n_j^{E1}.
\]

当前任务样本不替换；旧样本仅替换为同任务样本；任务排列、batch长度及IFA首条语言参考保护规则不变。

**0.5依然是旧样本位置进入替换分支的概率，不是整个batch的回放比例。**

# 六、日志与验收：补齐抽样身份，但不再增加昂贵诊断

## 1. 保留现有日志，新增三类只读信息

| 日志 | 必需内容 |
|---|---|
| **候选配对日志** | 阶段、刷新步、参考与候选的有序ID、与E1是否一致 |
| **概率日志** | 原始分数、旁路softmax概率、真正使用的均匀概率、有效候选数 |
| **实际样本日志** | 原始ID、最终ID、任务、位置、是否尝试替换、是否真正换了ID、是否被IFA规则否决 |

原始ID应从采样器实际产生的索引旁路记录，**不能为了记录ID再次迭代采样器或重新抽一批数据**。新增身份信息不得进入模型输入或改变样本顺序。

这能区分“执行了一次赋值”与“真正换了样本”，并计算本轮完整回放流的覆盖。已有E1缺少保留分支完整ID，因此仍不能伪造对应的E1完整流统计。

本轮不增加逐步重评分、Hessian计算、虚拟更新或额外环境验证。

## 2. 诊断预期不是性能验收标准

均匀模式应满足：

\[
\mathrm{ESS}=\frac{1}{\sum_iq_i^2}=64,
\qquad
\sum_iq_i^2=\frac1{64}.
\]

按当前记录分数划分的最高分25%候选，其**期望**抽样份额应为25%，但有限抽样中的实际比例不要求精确等于25%。

重复率应按 E1-U 的实际抽样次数重新计算。对于同一64候选池内的 \(n\) 次均匀有放回抽样：

\[
\mathbb E[\text{不同ID数}]
=
64\left[1-\left(\frac{63}{64}\right)^n\right].
\]

不要把上一轮解析得到的89.29%写成“本轮必须测到的结果”。同样，重复率降低或代理分数变化都不能替代总体闭环指标。

## 3. 成本分别记录

分别记录训练总时间、评分时间、替换处理时间、日志与检查点开销、主评估时间、次评估时间和峰值显存。I/O已经包含在处理时间中时，不重复相加。

原E1约用56.52分钟训练、5小时45分钟评估，可以作为同设备条件下的排期参考，**不是本轮耗时承诺**。E0原训练时间不可得，不计算虚构的E1-U相对E0加速比。

## 1. 主结果表

| 版本 | 总体 AUC ↑ | 总体 FWT ↑ | 总体 NBT ↓ |
|---|---:|---:|---:|
| E0，已有seed42 | 77.708 | 77.500 | −0.278 |

总体AUC继续采用任务均衡聚合。将四个增量任务重编号为1—4，令 \(R_{k,j}\) 为完成阶段 \(k\) 后任务 \(j\) 的成功率：

\[
\boxed{
AUC=
\frac14\sum_{j=1}^{4}
\frac{1}{5-j}\sum_{k=j}^{4}R_{k,j}.
}
\]

FWT、NBT沿用已核定的汇总实现；不要把所有三角矩阵单元直接平均当作AUC，不截断负NBT，也不新增事后加权综合指标。

## 2. 如何解释不同结果

当前已有 \(A_1<A_0\)，因此可以预先固定下表：

| E1-U主AUC结果 | 本次可以作出的判断 | 扩展处理 |
|---|---|---|
| **\(A_U>A_0\)** | 均匀池方案超过原基线；本次评分加权没有带来正向增量 | 具备补齐E1-U三seed的条件 |
| **\(A_1<A_U\leq A_0\)** | 去掉评分后有所恢复，但仍未超过原基线 | 不扩展seed |
| **\(A_U=A_1\)** | 主AUC没有观察到两种池内规则的差别 | 不扩展seed |
| **\(A_U<A_1\)** | 评分在该候选池机制下有正向观测增量，但原E1仍未超过E0 | 不据此扩展E1或叠加E2 |

这张表不把单seed差异称为统计显著，也不把最后一种情况直接解释成“小候选池造成了全部损失”。它只是决定下一步是否有值得继续验证的证据。

**只有“E1-U超过E0”，而不是仅仅“超过失败的E1”，才满足总体改善的扩展条件。** FWT、NBT和次口径仍完整报告，任务级结果只作解释。
