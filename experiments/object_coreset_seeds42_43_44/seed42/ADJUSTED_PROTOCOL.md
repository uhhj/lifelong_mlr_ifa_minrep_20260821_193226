## 3. 不能仅修改batch和gamma的共同对齐项

### 状态模态与缓存

导出、训练声明及评估都显式使用布尔值：

```yaml
policy:
  use_vision: true
  use_language: true
  use_state: true
```

CompletePolicy沿用现有分支拼接 `torch.cat([lang_tok, vision_mod, state_mod], dim=2)`；每步token顺序为language、agentview、eye_in_hand、state；状态字段顺序joint_states、gripper_states。保留4个token及512维，不增加摄像机或重写模型。

必须检查官方checkpoint完整cfg.policy。若缺失use_state，记录pretrain_use_state=unknown、effective_use_state=true、DISCLOSED_GAP，不把本轮选择伪写进官方元数据。状态编码器、状态FiLM及所有前端参数必须形状兼容并完整加载，禁止随机冻结参数填补。

原OBJECT历史缓存use_state=False，不能直接用于本轮正式训练，也不能通过补标签变成True。新目录只导出一次含状态潜特征，两组共享字节相同的文件；保存输入/前端哈希、实际预处理与模块模式、模态合同、每文件形状和SHA256。导出增广沿用官方实现，不因语义测试临时关闭增广而改变正式模式。

模态语义检查：第四token确实来自state_mod；只改变状态时前三token不变且第四token响应；False仅作软件负对照；相同latent经Complete/Brief的时间解码器与策略头产生相同分布参数。软件测试不增加正式训练组。

### IFA公式

共同实现论文公式4—7：当前任务样本对齐自己的语言reference，并对选中的当前—旧任务对求均值后乘0.1。公开base.py直接逐对累加且以batch第一条样本作为当前reference的路径不能原封不动地称为论文公式复现。

测试包括：没有任务对时IFA为零；重复同一任务对不把平均损失翻倍；batch首样本属于旧任务时当前reference仍正确；角度margin用正确两任务的语言reference。旧任务reference只从保留缓存取得，当前reference从当前合法数据取得。语言reference应先验证同任务稳定性；若实际导出存在变化，须披露并固定一致处理，不能静默挑有利值。

IFA相似度公式8及任务对选择保持相同算法。Coreset改变缓存后允许其实际任务对改变，并逐阶段记录；这是整体方法对照的间接作用，不冻结成E0任务对。

### 学习率及论文未公开细节

正文只公开AdamW、1e-4和linear scheduler，未给出warmup、调度调用粒度、AdamW其余参数或最终checkpoint选择方法。

两组共同沿用此前可审计的工程补全：warmup500个optimizer step（来自公开base.py fallback），总步数=100×实际DataLoader长度，scheduler在每次optimizer更新后推进；每任务重建优化器和调度器，网络参数跨任务继承。AdamW其余参数继承固定公开配置。此补全**不是论文公开的精确学习率轨迹**。1e-4是配置基准/峰值；使用warmup时首个实际更新学习率低于它，逐epoch记录首个更新前及最后更新后的实际lr，并保存scheduler状态；可据固定调度公式重建逐步lr，但不能把重建序列声称为逐步实测日志。

撤销此前按发布代码逐epoch推进的方案：公开代码用step总量构建调度器却按epoch调用，混合单位会导致100epoch内仍停留在warmup段。本轮两组共同采用一致的step单位，并把修复与warmup未公开的缺口写入审计。

## 4. Coreset唯一组间变量

样本仍是原始完整.pt窗口；只复制文件，不改latent、动作或创建聚类中心。每任务入库数与Random完全相同。原容量参数59660000是文件条数门槛，不是字节预算；本轮数量远低于容量，保持原未超容量时追加语义；若意外触发超容量则停止并报告，不改变旧任务配额或重新读取旧任务已丢弃样本。

距离保持附件设计：

`D(i,j)=0.5*D_H(i,j)/s_H + 0.5*D_A(i,j)/s_A`。

- D_H：8个时间位置×两个真实视觉token（索引1、2）的余弦距离均值。不用语言token区分同任务，也不把新增状态模态加入Coreset距离。
- D_A：最后一步7维专家动作按当前十条真实示范的逐维稳健尺度标准化后，计算RMS欧氏距离。尺度使用1.4826×MAD；某维退化时依次使用IQR/1.349、范围、1。无裁剪，不按结果调权重。
- 两类距离分别用固定4096个无序不同候选对的正距离中位数标定，不足4096用全部；实现以1e-12作数值零阈值；无超过阈值的距离时scale=1并记录。用独立Random(42)，不消耗训练或Random入库RNG。
- 初始中心为对固定最多256个参考候选平均组合距离最小的真实样本。参考子集按稳定文件ID及独立seed42固定；不足256用全部。
- 后续按距离已选集合最近中心最远原则选样，直到k=ceil(0.5N)，不因相似提前停止。文件名词典序解决并列，并预先固定float64、绝对并列容差1e-12、block256；不建立完整N×N矩阵。并列容差用于避免完全相同向量因浮点点积的舍入误差产生伪顺序差异。

稳健尺度、参考子集大小和退化规则是本次把附件补充为可执行定义的选择，不是论文参数。正式启动后冻结。初始选择器代码是准备工件，不能当作完整入口已通过GPU验收。

## 7. 指标、后续seed和解释边界

对j=6,7,8,9，r(i,j)为阶段i最终checkpoint在任务j的成功率：

`FWT = (1/4) Σ_j r(j,j)`。

`NBT = (1/3) Σ_{j=6..8} [(1/(9-j)) Σ_{i=j+1..9} (r(j,j)-r(i,j))]`。

`AUC = (1/4) Σ_{j=6..9} [(1/(10-j)) Σ_{i=j..9} r(i,j)]`。

按成功次数和20次分母用精确分数计算，再转换显示；不可将10个三角单元直接平均充当AUC。
