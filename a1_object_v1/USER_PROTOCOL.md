# 三、A1的数学定义与代码插入位置

## 1. 定义阶段参考子空间

令第 \(k\) 阶段合法可用的语言参考集合为：

\[
\mathcal R_k=\{r_j:j\text{属于预训练任务或已经到达的增量任务}\}.
\]

其张成空间的一组正交基为：

\[
U_k\in\mathbb R^{512\times q_k},
\qquad U_k^\top U_k=I.
\]

定义正交投影：

\[
P_k=U_kU_k^\top.
\]

对原解码器输出 \(z\)，定义：

\[
d=P_kz,\qquad s=z-d.
\]

这里 \(d\) 称为**参考子空间成分**，\(s\) 称为**补空间成分**。本轮报告中不直接将二者命名为“任务知识”和“共享技能”，因为几何分解尚不能证明这些语义。

## 2. 动作分支完全不变

原策略仍使用：

\[
\hat a\sim\pi_\theta(\cdot\mid z).
\]

**不要把 \(d\) 输入策略头，也不要将 \(s\) 丢弃。**实际代码继续直接传入原 \(z\)，无需计算 \(s+d\) 后再重组，以免引入无意义的浮点变化。

本次读取的`BasePolicy.compute_loss`本来就同时返回原BC损失和`last_feat`，因此可以保留已经完成的BC前向，只在后续IFA分支使用投影后的特征。

## 3. 修改后的IFA

对原规则选中的当前任务 \(k\) 与旧任务 \(j\)：

\[
\ell_{kj}^{A1}
=
\left[
\operatorname{ang}(P_kz_k,r_k)
-
\operatorname{ang}(P_kz_k,r_j)
+
\alpha\operatorname{ang}(r_k,r_j)
\right]_+.
\]

最终目标为：

\[
\boxed{
L_{A1}
=
L_{\mathrm{BC}}(\pi_\theta(\cdot\mid z),a)
+
\lambda_{\mathrm{IFA}}L_{\mathrm{IFA}}^{A1}
}
\]

参考和margin继续使用原向量及原计算结果；**不再对参考做中心化、白化或重新学习**。原论文的参考是固定语言嵌入，margin来自任务参考间的角距离。Yu 等 - Lifelong imitation learn… Yu 等 - Lifelong imitation learn…

## 4. 投影必须放在第一次特征归一化之前

对按当前任务mask选出的原始`last_feat`，计算：

```python
# U: [512, q]，固定常量；z_cur: [B_current, 512]
z_ifa = (z_cur @ U) @ U.T
```

然后让`z_ifa`进入原角距离计算路径。

**禁止先归一化完整 \(z\)，再投影。**虽然在忽略稳定项的理想算术下部分表达式等价，但这会保留不必要的全局范数路径，并使有限精度和归一化稳定项的作用不同。

当前代码使用`x / (norm(x) + 1e-8)`进行归一化，并对余弦夹紧后计算`acos`；原路径还存在重复归一化。A1应保留这些原运算，只在其之前插入一次投影，不能同时改用另一种归一化定义。 

投影只做一次，不在每个任务对循环中重复投影；不能原地覆盖供BC使用的`last_feat`。

## 5. 预期性质与边界

在精确投影下，任何 \(v\in\ker P_k\) 都满足：

\[
L_{\mathrm{IFA}}^{A1}(z+v)=L_{\mathrm{IFA}}^{A1}(z).
\]

因此，补空间成分不再直接影响该IFA目标。

但：

\[
\nabla_\theta L_{\mathrm{IFA}}^{A1}
=
J_{z,\theta}^{\top}P_k\nabla_dL_{\mathrm{IFA}}^{A1},
\]

仍然会更新原解码器参数。**输出处的补空间梯度为零，不等于解码器参数更新后补空间表示不变，更不等于旧行为获得保护保证。**

另一个风险是：\(\|P_kz\|\)小于\(\|z\|\)，投影后的角度梯度可能更大。A1不是简单“减弱IFA”，它同时改变了作用方向和局部敏感度。首轮不添加梯度补偿，保留这个设计的真实效果并记录。

# 四、参考来源与子空间构建规则

这是A1最需要固定的工程部分：不能因参考恢复困难而临时改变子空间定义。

## 1. 每阶段允许使用哪些参考？

| 阶段 | 子空间可用参考 | 不允许使用 |
|---|---|---|
| task6 | 预训练任务0—5＋task6 | task7—9 |
| task7 | 任务0—7 | task8—9 |
| task8 | 任务0—8 | task9 |
| task9 | 任务0—9 | 其他未到达任务 |

**预训练参考只增加任务描述元数据，不重新读取其示范用于BC，也不加入预训练任务回放。**

这一元数据状态是A1的额外记忆，需要计入存储；“没有新增示范”不等于“总存储完全不变”。

子空间包含所有已合法获得的参考，而不是只包含当前选中的IFA任务对。这样避免把“修改作用空间”与“修改配对对象”混在一起。

## 2. 参考怎样取得？

**预训练任务0—5：**从既有预训练元数据恢复原任务描述，使用同一预训练检查点中的语言编码路径生成参考。必须包含该路径实际使用的权重、适配器和投影，不能直接换成一个未经预训练适配的CLIP文本输出。

**新到达任务：**从该任务当前合法潜在特征中的语言token取得固定参考，并保存任务ID、来源文件及校验值。该任务之后成为旧任务时，继续使用已保存的参考，不重新用当前解码器生成参考。

源码中的语言token直接来自`language_encoder`，视觉和状态的FiLM处理在其后分别进行。因此，参考恢复应对齐这个实际输出位置，而不是任选一个语言模型层。

开跑前，用已到达任务的缓存语言token核验文本编码路径，确认二者归一化方向一致。已有审计曾确认历史缓存内每任务语言参考稳定，但A1仍需要核验此次加载的检查点和缓存身份。

若预训练描述或正确编码路径无法恢复，记为**准备条件未满足**；不能悄悄省略0—5、使用另一编码器或扫描全部未来任务来凑齐参考。

## 3. 基础向量按到达顺序追加

首轮固定采用**CPU／FP64、两遍修正Gram–Schmidt正交化**。处理顺序为预训练任务ID递增，再按增量到达顺序追加。

对一个新参考：

\[
\hat r=\frac{r}{\|r\|}.
\]

在已有 \(U\) 上进行两遍残差消除：

\[
v\leftarrow\hat r,\qquad
v\leftarrow v-U(U^\top v).
\]

第二遍对新的 \(v\) 重复相同操作。若残差范数超过固定数值阈值，则追加：

\[
u_{\mathrm{new}}=\frac{v}{\|v\|}.
\]

否则，认为该参考在数值容差内已由现有空间表示，不增加方向。

**保留旧基向量，不每阶段重算并旋转整套基。**A1的投影原则上不依赖基的旋转，但追加式保存便于断点一致性，并为后续A2保留稳定坐标。

## 4. 数值参数预先固定

| 参数 | A1-v1取值 |
|---|---:|
| 正交化计算精度 | CPU FP64 |
| 训练投影精度 | 与原训练一致的FP32 |
| 单位参考残差入基阈值 | \(10^{-7}\) |
| FP64正交误差上限 \(\|U^\top U-I\|_F\) | \(10^{-10}\) |
| FP64单位参考重建误差上限 | \(10^{-6}\) |
| FP32正交／单位参考重建误差上限 | \(10^{-5}\) |
| 原特征归一化稳定项 | 沿用 \(10^{-8}\) |
| 原`acos`夹紧余量 | 沿用 \(10^{-6}\) |

前五项是本轮数值规则，不按闭环结果调节。后两项来自原代码。 

不做PCA解释方差筛选，不搜索子空间维数，不减去参考均值，不移除所谓“公共语言方向”。

每阶段实际维数 \(q_k\)由上述规则确定。OBJECT四阶段分别至多为7、8、9、10维，**实际秩必须计算，不能直接把这些上限写成观测值**。

## 5. 阶段内不更新子空间

在阶段开始时完成参考登记和 \(U_k\) 构建，阶段内100 epochs固定使用同一个 \(U_k\)。

不根据当前模型表示、BC损失、成功率或梯度变化更新基。否则就从固定参考投影变成了另一种自适应子空间算法。

# 五、训练接入、数值异常与恢复

## 1. 一次更新仍然只有一次原前向和正式反向

执行顺序：

\[
\text{原前向得到BC与 }z
\rightarrow
\text{IFA分支计算 }P_kz
\rightarrow
\text{原损失相加}
\rightarrow
\text{一次反向}
\rightarrow
\text{原裁剪和AdamW}.
\]

不运行E1检查，不生成P1教师，不计算G1的两套参数梯度。

\(U_k\)固定、不求梯度；**\(P_kz\)对 \(z\) 必须可反向传播**。不能给投影分支加`detach`或`no_grad`，否则会提前变成A3式梯度隔离，甚至让IFA完全失去训练作用。

## 2. 保持模型结构和检查点格式

建议将参考表和 \(U_k\) 存在训练控制器及独立状态文件中，不新增到策略网络参数。

这样：

**训练的模型参数集合与基线一致；闭环策略网络结构与基线一致；原模型检查点加载逻辑无需因投影改变。**

训练恢复时需要 \(U_k\)，闭环动作执行时不需要。不得在评估加载器里把 \(z\)投影后再送入策略头。

## 3. 小投影范数只诊断，不静默切换算法

记录：

\[
\rho_z=\frac{\|P_kz\|}{\max(\|z\|,10^{-8})}.
\]

将 \(\rho_z<10^{-6}\) 记为小投影事件，阈值只用于日志。

出现有限但较小的投影时，仍执行原数值稳定化和原梯度裁剪，**不自动退回全局IFA，不把该样本的IFA置零，也不额外加大范数下限**。

若出现非有限损失、梯度或参数，保存失败批次、基、参考和更新前状态，停止并记录为数值失败。修复实现错误与修改算法稳定化必须分开：后者需要新的版本号，不能无标记地继续同一正式运行。

| 恢复与加载 | 同阶段恢复不重建基；闭环加载不使用投影改变动作路径 |

第一阶段原本没有可作用的旧任务IFA。A1虽已建立参考空间，但不会因此新增IFA任务对；这提供了自然的无干预核验条件。历史修正对照也记录了第一阶段不同实现参数一致。

**不能通过重复运行、挑选一个第一阶段成功率更接近历史值的seed 42结果来“校准”实验。**

# 七、正式闭环评估与扩展条件

## 1. 首轮完成四阶段，不在中间根据表现调参

固定seed 42，运行全部400个阶段—epoch。保存各阶段`ep99`，不依据训练损失、IFA激活率或单任务成功率提前结束或更换检查点。

主评估沿用原执行初态、顺序、终止规则和GMM动作采样方式。原受控对照的主端点就是固定`ep99`与20次执行，没有事后最好epoch选择。

| 检查点 | 主评估任务 | 次数 |
|---|---|---:|
| task6／ep99 | task6 | 20 |
| task7／ep99 | task6、7 | 40 |
| task8／ep99 | task6、7、8 | 60 |
| task9／ep99 | task6、7、8、9 | 80 |
| **合计** | **10个有效矩阵单元** | **200** |

预训练任务不加入本轮已有主指标范围。保留所有原始执行记录，不只保存均值。

## 2. 指标继续使用原定义

令 \(R_{ij}\) 为学完第 \(i\) 个增量任务后，对第 \(j\) 个任务的成功率，\(M=4\)：

\[
\mathrm{FWT}=\frac14\sum_{j=1}^{4}R_{jj},
\]

\[
\mathrm{NBT}
=
\frac13\sum_{j=1}^{3}
\frac1{4-j}\sum_{i=j+1}^{4}(R_{jj}-R_{ij}),
\]

\[
\mathrm{AUC}
=
\frac14\sum_{j=1}^{4}
\frac1{5-j}\sum_{i=j}^{4}R_{ij}.
\]

直接复用已验证的汇总程序，并从执行记录独立复算一次。这些公式对应原论文的指标口径，不能替换为最终成功率或另一种NBT平均方式。Yu 等 - Lifelong imitation learn…

## 3. 扩展规则

首轮计算：

\[
\Delta\mathrm{AUC}_{42}
=
\mathrm{AUC}_{A1,42}
-
\mathrm{AUC}_{\text{修正IFA},42}.
\]

**未舍入差值大于零：**冻结A1配置，补OBJECT的43、44；三seed总体平均收益仍为正，再用相同新增设置扩展GOAL与LIBERO-50，各3seed。

**差值不大于零：**当前A1配置停止，不补seed，不直接叠加A2来补救。

NBT、FWT和单任务表现只解释总体结果，不另设单任务性能门槛。

全量扩展时，保持原论文对应的任务划分：GOAL四阶段、每阶段一个新任务；LIBERO-50五阶段、每阶段五个新任务。只沿用原数据集特有角度系数，A1的参考规则和数值参数不重新调节。Yu 等 - Lifelong imitation learn… Yu 等 - Lifelong imitation learn…

扩展前需要核对对应任务集是否已有**同口径、正参考一致的基线**。缺少时明确登记，不能用论文均值冒充配对结果，也不在本方案中自动重跑基线。

单seed正向只是计算投入信号；三seed报告全部结果、均值、标准差和逐seed差值，不把筛选后的均值直接解释为统计显著。

# 八、机制日志、成本与结果解释

## 1. 随正常训练记录，不增加训练控制

| 层面 | 必须记录 |
|---|---|
| 参考空间 | 可用任务ID、实际秩、正交误差、参考重建误差、阶段基校验值 |
| 表示尺度 | \(\|z\|\)、\(\|P_kz\|\)、投影能量比例、小投影事件比例 |
| IFA行为 | 原配对、正负角距离、margin、hinge激活比例、加权贡献 |
| 原行为学习 | BC、总损失、原裁剪前梯度范数、裁剪触发情况、学习率 |
| 成本 | 参考生成、正交化、投影计算、完整训练和闭环评估耗时，峰值显存 |

可固定每100个基础更新，在**同一批已经得到的 \(z\)** 上，额外无梯度计算一次原全局IFA与子空间IFA的几何差异。它不增加模型前向、不影响训练，也不用于选择样本或修改权重。

该比较只能说明**A1自身轨迹上的两个几何目标不同**，不能当成历史基线的反事实结果。

不在每步计算完整参数梯度探针，避免重新引入G1的主要成本。

## 2. 存储和计算边界

训练投影使用：

\[
Z_{\mathrm{IFA}}=(ZU_k)U_k^\top,
\]

不显式建立512×512的 \(P_k\)。计算量随当前样本数和 \(512q_k\)增长；只在原IFA需要使用的批次执行。

OBJECT最终 \(q_k\le10\) 时，单份FP32基的数值载荷最多为：

\[
512\times10\times4=20{,}480\text{字节}.
\]

CPU双精度主副本、原参考表和元数据另计。**A1无新增可训练参数，但并非完全没有额外状态。**

没有额外模型前向或参数梯度探测，预计成本结构较轻；实际时间和显存必须测量。没有匹配的基线计时，就只报告A1实测时间，不为测速重跑基线。

## 3. 成功与失败分别支持什么？

| 观测结果 | 可支持的结论 |
|---|---|
| AUC改善，机制与数值检查正常 | 参考子空间约束在该协议下优于完整表示约束 |
| 子空间IFA更低，但AUC未改善 | 几何目标变容易或被优化得更好，未转化为总体收益 |
| 小投影、强裁剪明显增加且AUC下降 | 提供数值敏感性线索，但不能仅凭相关性认定根因 |
| AUC改善但低于某个历史旧取样结果 | 可称优于修正IFA，不能宣称超过全部历史版本 |

即使A1成功，也不能仅凭总体AUC或论文FWT宣称“已经证明增强了前向迁移”。原FWT是任务初学成功率的平均，没有单独扣除不使用增量历史知识的对照。Yu 等 - Lifelong imitation learn…
