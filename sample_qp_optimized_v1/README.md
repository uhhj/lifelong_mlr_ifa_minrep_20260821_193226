# 逐样本位移QP：工程优化候选版

本包保留 `sample_step_closedloop_v1` 的科学定义，独立实现较轻的训练热路径。
原实验源码、checkpoint和报告不改写。当前没有可用GPU，候选版尚未获准替换正式实现，
不能据CPU测试声称真实机器人策略已加速或数值完全一致。

## 保持不变

- 同一起点、32个参考窗口/旧任务、逐步刷新全部参考梯度；当前task8共64条约束。
- 每个参考batch仍为8个窗口，仍逐样本反向；没有更换框架、向量化求导或混合精度。
- 参数范围仍为原全部可训练参数；解码器与策略头合并，不使用Fisher或低秩近似。
- 原生混合BC、样本权重、裁剪、AdamW、scheduler和随机序列。
- 实际位移QP，联合处理全部样本约束，不采用任务平均门控。
- 原SLSQP与坐标精修求解器、float64内积、65536元素分块和原数值容差。
- AdamW先提交完整MLR moments，再修正参数位移；不更改moments。

## 改动

1. 只在设备上复制可训练参数，直接计算原生位移；不为此复制整个模型和AdamW状态。
2. 直接在设备上按 `native_parameter + (-correction)` 写入参数。
3. 逐样本梯度矩阵预分配并复用，但每一步重新计算和覆盖全部列，不缓存旧梯度。
4. 复用求解前已经得到的原生方向内积，避免再次遍历梯度矩阵。
5. 去掉每窗口转换Python标量、每步强制Python垃圾回收、每步完整状态哈希。
6. 保留损失有限值、矩阵分配预算、QP KKT和投影残差检查；完整状态核验放入验收脚本。

没有预先承诺加速倍数。当前13倍开销包含诊断，因此不能视为逐样本QP不可降低的固有成本。

## CPU测试

服务器原环境：

```bash
source .migration/activate.sh
python -m unittest sample_qp_optimized_v1.tests -v
python -m sample_qp_optimized_v1.validate --audit-only
```

CPU测试包括：原函数内积/投影对照、跨65536分块、64列矩阵、正反/重复/零约束、
聚合掩盖冲突、梯度不写入`.grad`、内存复用刷新、AdamW moments/RNG不被位移修正改变，
以及完整GMM NLL下连续20步参数/moments/scheduler一致。
测试模型很小，结果仅证明这些实现路径；不是完整策略GPU验证。

## GPU验收

GPU可用后在原服务器仓库运行：

```bash
source .migration/activate.sh
python -u -m sample_qp_optimized_v1.validate --run-gpu
```

脚本不会开启闭环rollout或完整终身训练：

1. 再次校验原冻结输入、三seed原状态及历史300步终点；任何缺失/变化即停止。
   更换GPU时，先以未修改的原实现执行首步，并逐位核对历史首步状态；失败则停止，不将其归因为优化版错误。
2. 在三个固定真实起点上比较全部64列参考梯度。
3. 使用相同状态、样本和随机序列，原版/优化版各运行20步；每步分别核对完整状态哈希。
4. 相同预热，执行顺序按seed交替；用CUDA同步的墙钟时间比较20步，不把外部哈希计入计时。
5. 单独测量同步分项profile，不把含profile开销的时间当作正式加速比。
6. 优化版在三个起点分别执行原300步序列，逐位核对历史模型、AdamW、scheduler、RNG等终点哈希。
7. 任一数值不一致则失败，不能自动放宽容差或改换起点。

验收目录 `reports/sample_qp_optimized_v1/gpu_validation/` 若已存在，脚本拒绝覆盖。
首版验收总上限6小时、每起点2小时、显存分配20GiB/保留22GiB、主机RSS28GiB，
仅保存小型日志和哈希，不新增完整模型副本。无GPU时会明确拒绝运行GPU验收。

`PASS`要求三起点逐位一致且每起点的20步热路径比原版更快。只有通过后才考虑接入新训练。
这里测量的是包含原诊断开销的旧实现与优化热路径的比较，不能把它称作纯QP求解器加速。
完整终身训练跨任务的参考池构建与task9的96条约束不在本次已验证接口范围内。

## 接口

`Workspace`按模型建立一次，在每次更新间复用。`adapter.update(...)`接收原固定实验的数据与起点信息，
调用原生MLR更新后做位移QP。原数据前向、优化器、裁剪、scheduler均复用，不另造训练目标。

禁止为部署方便直接改写原冻结实验文件。GPU验收完成前，候选版只用于工程验证。
