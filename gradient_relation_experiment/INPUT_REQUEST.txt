**建议做“梯度关系预测＋同状态反事实更新＋隔离评估”的实验，先验证这个信号是否有用，不加入新的投影或保护模块；关键是不能先把正内积定义为共享、负内积定义为负迁移，再用同一个定义证明自己正确。**

先收紧我前面的表述：**梯度同向表示当前参数和样本上的局部优化对齐，不等于已经识别了共享知识。** 用任务梯度衡量相互影响已有PCGrad、Task Affinity Grouping等研究基础；我们要验证的是它在当前机器人终身学习协议中的可靠性及额外预测价值，而不是把梯度余弦本身当成创新。([NeurIPS Proceedings][1])

## 一、先把三个待验证目标分开

| 待验证目标        | 实验中的可测定义                                  | 不能混淆的概念                 |
| ------------ | ----------------------------------------- | ----------------------- |
| **局部共享收益**   | 加入旧任务梯度后，新任务在独立数据上的学习更好；反方向也可分别检验         | 正余弦不直接等于共享知识            |
| **局部负迁移／干扰** | 在其他条件相同时，加入任务 \(j\) 的梯度，使任务 \(k\) 的独立损失更高 | 不等同于旧任务遗忘               |
| **实际旧任务损伤**  | 原生MLR更新后，旧任务独立损失相对更新前增加                   | 不一定由新任务单独造成，也不直接等于成功率下降 |

这里先研究**局部、方向性的任务影响**。完整的迁移还涉及历史训练及任务获取：Hiratani论文就分别定义迁移与保持，不能用一个损失上升标签替代两者。

一个有意义的结果可能是：

> 新任务梯度对旧任务有局部不利影响，但完整MLR更新没有造成旧损失增加——说明“存在局部冲突”和“需要额外保护”确实是两件事。

## 二、实验起点：覆盖真实干预发生的区域，但不只选择冲突事件

### 建议的首轮规模

| 项目     | 建议                               |
| ------ | -------------------------------- |
| seed   | 45、46、47，作为已有资产上的机制诊断，不称为新seed确认 |
| 当前训练任务 | task7、task8                      |
| 训练阶段   | ep30–69、ep70–99                  |
| 起点抽取   | 每个seed×task×阶段固定抽取10个，共120个目标起点  |
| 更新范围   | 时序解码器＋策略头整体；分模块指标只作辅助分析          |
| 方法改动   | 无新增控制器，只有诊断分支                    |

这个位置选择来自你已经完成的触发分布报告；但**抽取具体起点时不依据梯度正负、触发强度或后续损失结果**。

优先使用可完整恢复的原MLR状态。若现有快照只来自soft轨迹，必须单列为soft载体，不能称为MLR历史；缺失状态需要忠实恢复，不能重置AdamW代替。

**只有触发事件快照时，也不能直接估计总体精确率或损伤发生率。** 那属于经过筛选的样本；需要额外的规则抽样起点，或明确将结论限于触发子集。

### 三类数据严格分开

**训练批次**用于产生真实更新；**参考样本**用于计算梯度关系；**监测数据**只产生独立评价标签。

首版主分析使用同一次混合前向中实际出现的新任务及各旧任务样本。旧任务没有出现在batch时，标为“本步未观测”，不能记为零冲突。可以从当前buffer额外抽取等量旧样本检验梯度估计稳定性，但它们只作辅助测量，不进入主更新。

监测库A/B沿用已经核验的轨迹隔离原则，且必须避开**整个后续20步**的训练和参考轨迹。附件IGFA也明确讨论了训练锚定与独立功能评估的区别，不能用被控制器访问的数据同时充当泛化证据。

## 三、核心实验：同一个状态，分别保留或移除新、旧任务梯度

这是本轮最有辨别力的部分。

在同一混合batch上计算：

$$
g_k=\nabla L_{\mathrm{new}},\qquad
g_j=\nabla L_{\mathrm{old},j}.
$$

原MLR梯度为：

$$
g_{\mathrm{MLR}}
=a g_k+\sum_{\ell<k}b_\ell g_\ell,
$$

其中 \(a,b_\ell\) 保持**该batch实际样本比例**。

针对旧任务 \(j\)，把其他旧任务的贡献记为：

$$
q_j=\sum_{\ell\ne j}b_\ell g_\ell.
$$

建立四个诊断分支：

| 分支     | 首步送入原裁剪＋AdamW的梯度     | 含义               |
| ------ | -------------------- | ---------------- |
| **11** | \(q_j+a g_k+b_jg_j\) | 完整原MLR           |
| **10** | \(q_j+a g_k\)        | 只移除旧任务 \(j\) 的贡献 |
| **01** | \(q_j+b_jg_j\)       | 只移除新任务贡献         |
| **00** | \(q_j\)              | 同时移除二者，用于检查交互影响  |

**移除后不重新归一化剩余损失。** 否则同时改变其他任务的权重，无法判断差异来自哪里。这些是机制干预分支，不是四种准备正式训练的新方法。

所有分支共享初始参数、AdamW moments、scheduler、batch和随机状态，并执行原生更新。即使某分支梯度全零，也要明确零梯度更新与“不执行step”的区别：AdamW的历史矩估计仍可能参与更新。([PyTorch Documentation][2])

### 从独立监测损失得到三个标签

设 \(\theta_{xy}\) 为相应分支更新后的参数，\(L^Q\) 为监测库上的损失。

**① 新任务对旧任务的边际影响**

$$
E_{k\rightarrow j}
=
L_j^Q(\theta_{11})
-
L_j^Q(\theta_{01}).
$$

正值表示：其他贡献不变时，**加入新任务梯度让旧任务更差**；负值表示局部帮助。

**② 旧任务对新任务的边际影响**

$$
E_{j\rightarrow k}
=
L_k^Q(\theta_{11})
-
L_k^Q(\theta_{10}).
$$

正值表示：**加入这部分旧任务回放梯度妨碍了新任务学习**；负值表示旧任务回放帮助新任务。

**③ 完整MLR是否真的损伤旧任务**

$$
H_j^{\mathrm{MLR}}
=
L_j^Q(\theta_{11})
-
L_j^Q(\theta).
$$

这里正值才是规定监测数据上的实际旧损失增加。

这三项能区分：**谁影响谁、影响方向如何，以及总更新最终有没有损伤。** 两个边际影响都为负，才是较强的“双向局部互助”证据；只有一个为负，只能称单向帮助。

另外，梯度余弦是对称的，而实际影响可能不对称，因此必须分别测两个方向，不能只输出一个“共享/冲突”标签。Task Affinity Grouping也采用方向性的更新影响来刻画任务关系。

## 四、同一次实验测第1、5、20步，避免重复此前的局限

四分支**仅首步不同**。第2–20步全部恢复原MLR规则，使用相同后续batch安排与随机种子，各自保留自然演化的参数和moments。

这样，第20步比较回答的是：

> 首步新任务或旧任务的这份梯度贡献，其影响能否持续，而不是持续改变训练目标后的综合效果。

第20步作为主终点，第1/5步观察过程。三个标签在各终点分别计算，不根据结果选择最有利的步数。

同时补两个检查：

**参考稳定性检查。** 同一参数状态下，用几组不同的buffer样本重新估计 \(g_j\)，记录余弦符号翻转率。不能把“换几条演示就变号”的分数当作稳定任务属性。

**幅度检查。** 移除梯度可能改变实际步长。记录各分支参数位移，并增加一个仅用于单步分析的等位移范数对照，帮助区分方向影响与简单的步长变化；不把这个人工对照冒充原生AdamW多步方法。

## 五、怎样判断梯度关系具有预测价值？

每个起点先记录分数，再生成后续标签，不使用未来损失调阈值。

### 必须比较的预测量

| 分数                            | 作用                  |
| ----------------------------- | ------------------- |
| \(s_j=\cos(g_k,g_j)\)         | 当前要验证的核心信号          |
| \(g_k^\top g_j\)，及两个梯度范数      | 判断余弦是否忽略了重要幅度       |
| \(g_{\mathrm{MLR}}^\top g_j\) | 与此前“混合更新风险”判据比较     |
| \(g_j^\top d_{\mathrm{MLR}}\) | 与真实AdamW位移的一阶风险比较   |
| task、训练阶段、学习率、样本数等基础信息        | 检验梯度关系是否只是这些因素的替代指标 |

对于方向性的边际影响，还可用 \(g_j^\top(d_{11}-d_{01})\) 作为优化器感知对照；它与完整位移风险不是同一个量。

**不要把实际位移内积当作真标签。** 真标签仍是独立损失实测值；附件IGFA的完整损失变化表达也保留了一阶项与有限位移的曲率贡献。

### 评价方式

同时报告连续预测与分类结果：分数与损失差的秩相关；损伤识别的ROC-AUC、PR-AUC；固定零阈值下的精确率和召回率；各类标签的发生比例。这里的ROC-AUC不是项目的成功率AUC。

A/B分别报告。数值容差由重复测量与无干预一致性确定，不为了增加“正确预测”而调整。GMM NLL可以为负，因此使用**损失差值**，不照搬以原损失作分母的百分比改善。

若拟合预测模型，采用留一seed验证：两个seed开发、第三个测试，轮换三次。不能随机拆散同一轨迹的相邻窗口。只有三个seed，应把结果定位为有限机制证据。

**通过条件不是“正余弦组均值更好”这一条，而是：它在隔离数据、不同seed和训练阶段上，能提供超出基础信息及已有混合梯度判据的额外预测价值。**

## 六、最后用闭环确认，才讨论“知识共享”和完整负迁移

上述实验最多首先支持**局部优化关系**。要进一步说它预测机器人能力，需要两类验证：

**闭环能力。** 对事前选定的任务对和起点做配对rollout，不能只挑BC已经改善的案例。若20步差异不足以在成功率上辨别，报告证据不足，不不断延长到出现正结果。

**完整迁移。** 复用或补充之前方案中的“任务 \(k\) 单独学习”和“先学 \(j\)，再学 \(k\)”对照，从共同预训练初始化出发，固定新任务数据、更新预算和评估；源任务训练的额外预算单列。梯度分数在新任务学习开始前或预登记早期窗口形成，不能事后平均完整轨迹再称预测。

这一步区分“当前回放梯度妨碍一步更新”和“旧任务历史真正造成负迁移”。项目最终仍以闭环成功率相关指标评价，而不是用BC标签替代。

## 本轮的明确交付与去留

**先执行120个目标起点的四分支机制诊断，不启动新控制器。** 最终报告应分别给出：

| 结果                       | 后续判断                |
| ------------------------ | ------------------- |
| 只在原训练样本或第1步有效，隔离/20步失效   | 不支持将该梯度关系直接作为保护依据   |
| 能预测局部任务互助，但不能预测完整MLR损伤   | 可以研究关系分析，不能直接据此触发保护 |
| 能预测隔离损伤，但没有超出混合梯度或实际位移对照 | 没有建立新增关系层的必要性       |
| 有独立增量预测价值，并得到闭环支持        | 再研究如何利用该信号选择性控制更新   |

**这次要验证的不是“负内积是否存在”，而是“在不知道后续结果时，梯度关系能否识别哪些任务贡献真正有益、哪些有害，以及这些影响有没有被原MLR补偿”。**
