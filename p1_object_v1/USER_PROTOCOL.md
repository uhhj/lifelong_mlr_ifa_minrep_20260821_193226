**下一轮固定为“P1-OBJECT-v1”：关闭E1，只在原MLR＋IFA上加入固定旧策略分布回放，先跑LIBERO-OBJECT的seed 42，以原主评估协议下的总体AUC筛选；基线、预训练和已有潜在特征全部复用，不重新运行。**

本方案将上一轮提出的 **蒸馏权重 \(\beta=0.05\)、每个旧窗口16个蒙特卡洛动作样本**固定下来，并明确目标保存、损失归一化、随机性、代码接入和评估规则。这些是**本轮实验预设**，不是已经验证的最优参数。

# 三、新增记忆：为每个旧窗口保存固定GMM目标

## 1. 保存内容

原MLR保存：

\[
(H_i,a_i).
\]

P1在不改变这些窗口及专家动作的前提下，额外保存：

\[
(H_i,a_i,\bar\pi_i),
\]

其中 \(\bar\pi_i\) 是**该窗口所属任务刚训练结束时，本次P1模型对同一输入输出的GMM分布**。

当前代码实际使用`BriefPolicy`内部构造的`GMMHead`，输出7维动作；损失评价最后一个动作位置。不能只看配置文件中某个策略头名称，就误用另一种时序输出格式。 

在当前5分量、7维动作设置下，每个窗口保存：

| 字段 | 形状 | 含义 |
|---|---|---|
| `teacher_log_weights` | `[5]` | 归一化混合权重的对数 |
| `teacher_means` | `[5, 7]` | 各分量实际均值 |
| `teacher_scales` | `[5, 7]` | 各分量实际标准差 |
| 元数据 | — | 窗口ID、来源任务、来源epoch、模型及输入校验值 |

**保存的是输出分布的实际参数。**均值已经经过原代码的`tanh`，标准差已经经过原激活函数和最小标准差处理，读取后不能再做一遍这些变换。

全部使用FP32保存并停止梯度，不保存教师网络的计算图。

## 2. 什么时候生成？

**每个任务完成100 epochs后，使用该阶段`ep99`模型，对原缓存规则新选中的当前任务窗口生成一次目标。**

| 正在训练的阶段 | 可用于蒸馏的历史目标 | 阶段结束时新增目标 |
|---|---|---|
| task6 | 无，初始旧缓存为空 | 本次P1的task6／ep99输出 |
| task7 | task6入库时的固定输出 | task7／ep99输出 |
| task8 | task6、task7各自入库时的固定输出 | task8／ep99输出 |
| task9 | task6、task7、task8各自入库时的固定输出 | task9／ep99输出，作为最终缓存记录 |

初始缓存为空是当前已冻结流程的设置。**不额外导入预训练任务0—5的样本，也不从历史基线或E1检查点生成教师目标。**

例如，task6窗口的目标在task7、8、9训练期间始终不变，不能每到新阶段就用最新模型覆盖。这是P1区别于“保持上一个优化步”的关键。

教师目标来源固定为`ep99`，不根据闭环成功率挑选“最好教师”，不设置教师质量门控。后两者属于后续可能增加的模块，不放进本轮。

## 3. 与原缓存同步，但分开存储

建议使用独立的教师目标存储目录和清单，**不要把教师`.pt`文件放进原潜在窗口的扫描目录**，避免被训练数据加载器或IFA特征扫描误当作新样本。

目标与窗口通过稳定ID绑定，至少包含任务ID和原窗口标识；不能仅使用可能跨任务重复的文件名。

阶段结束时执行一次完整事务：

> 原规则选择并更新缓存 → 为新增窗口生成目标 → 删除已移出窗口对应的活动目标 → 校验一一对应 → 原子提交清单与恢复状态。

旧窗口目标缺失或校验不匹配，应报错停止，**不能静默跳过蒸馏，也不能临时用当前模型补成“历史目标”**。

# 四、训练算法：固定教师到当前策略的KL蒸馏

## 1. 完整目标

令原训练批次为 \(B\)，其中合法旧回放窗口构成 \(B_{\mathrm{old}}\)。本轮使用：

\[
\boxed{
L_{\mathrm{P1}}
=
L_{\mathrm{BC}}
+
0.1L_{\mathrm{IFA}}
+
0.05L_{\mathrm{policy}}
}
\]

\[
L_{\mathrm{policy}}
=
\frac{1}{|B_{\mathrm{old}}|}
\sum_{i\in B_{\mathrm{old}}}
D_{\mathrm{KL}}
\left(
\bar\pi_i\;\|\;\pi_\theta(\cdot\mid H_i)
\right).
\]

**方向固定为“历史教师 \(\rightarrow\) 当前学生”。**

蒸馏只使用**正常训练批次中已经出现的旧样本**，不另抽20个检查样本，不沿用E1的每10步检查机制。

归一化规则固定如下：

| 操作 | 规则 |
|---|---|
| 原BC | 原混合批次上的原始归一化，不改 |
| 原IFA | 原实现，不改 |
| 每个旧输入 | 对16个动作样本取平均 |
| 旧窗口之间 | 仅对 \(B_{\mathrm{old}}\) 取平均 |
| 动作维度 | 联合对数概率对7维求和，不额外除以7 |
| 无旧窗口的批次 | \(L_{\mathrm{policy}}=0\) |
| 额外比例因子 | **不再乘** \(|B_{\mathrm{old}}|/|B|\) |

因此，\(\beta=0.05\)只对上述定义有效，不能在实现中更换平均方式后还认为权重含义相同。

## 2. 蒙特卡洛估计：每窗口16个动作，不是16次模型前向

对每个旧窗口，从缓存教师分布抽取：

\[
\tilde a_{i,m}\sim\bar\pi_i,\qquad m=1,\ldots,16.
\]

计算：

\[
\boxed{
\widehat L_{\mathrm{policy}}
=
\frac{1}{16|B_{\mathrm{old}}|}
\sum_i\sum_{m=1}^{16}
\left[
\log\bar\pi_i(\tilde a_{i,m})
-
\log\pi_\theta(\tilde a_{i,m}\mid H_i)
\right]
}
\]

教师参数、采样动作及教师对数概率全部停止梯度；只有当前学生的对数概率参与反向传播。

**每次旧窗口重新出现在训练批次时，重新抽取16个动作。**固定的是教师分布，不是永久保存16个伪动作。16是每个窗口的总样本数，不是每个混合分量16个。

GMM由分类分布和多维高斯分量组成，可以用原有分布结构计算采样与`log_prob`；PyTorch也提供相应的`MixtureSameFamily`、`Independent`和`Normal`接口。本轮沿用安装环境，不需要升级依赖。[PyTorch Docs](https://docs.pytorch.org/docs/2.13/distributions.html)

## 3. 必须比较完整混合分布

GMM的对数概率应计算为：

\[
\log\pi(a\mid H)
=
\operatorname{logsumexp}_k
\left[
\log w_k+
\sum_{d=1}^{7}\log\mathcal N(a_d;\mu_{kd},\sigma_{kd}^2)
\right].
\]

不能改成以下替代量：

**只比较混合均值、按编号逐个分量做MSE、只保留最大权重分量、或把16个样本扩成16份输入反复经过解码器。**

学生对一个旧窗口前向一次即可得到完整分布，然后评价16个采样动作。上述完整分布定义也避免把教师与学生的“第1分量”强行认定为同一个行为模式。

本轮保护的是**训练用完整GMM分布**，不是宣称已经精确保持了实际执行时的分量选择及闭环轨迹；原评估动作规则保持不变。

## 4. 数值与梯度规则

**蒙特卡洛KL估计偶尔为负不直接视为错误。**有限采样下，样本均值可能为负；不得擅自使用`relu`或`clamp_min(0)`，否则会改变训练梯度。记录其出现比例即可。

**采样动作不做额外裁剪。**不将动作裁剪到 \([-1,1]\)，不把夹爪维度二值化。当前代码是均值经过`tanh`、随后建立高斯混合分布；再裁剪采样动作会改变这里所定义的期望。

**标准差不重新放大或缩小。**不额外增加温度、不动态修改蒸馏权重、不对高KL窗口降权。遇到非有限值，保存现场并停止排查，不能静默跳过困难旧窗口。

所有新增概率计算使用FP32和稳定的对数域计算；原基础训练精度、原梯度裁剪保持不变。

# 五、确定性分支、代码接入与每阶段流程

## 1. 基础前向与蒸馏前向分开

为避免缓存目标与学生受到不同dropout影响，本轮固定采用：

| 前向用途 | 模式 | 是否反向传播 |
|---|---|---|
| 原BC＋IFA | 原训练模式，完全保持 | 是 |
| 阶段结束生成教师目标 | 关闭随机层，保留训练GMM定义 | 否 |
| 旧窗口学生蒸馏 | 与教师生成相同的确定性模式 | **是** |

这意味着，有旧窗口的训练批次会增加一次**只处理旧窗口的学生前向**。不复用原随机前向的旧分布，也不为了复用计算而关闭整个基础训练的dropout。

当前`BriefPolicy.forward`只在`self.training`为真时返回分布与特征。因此，不能直接整模型`eval()`后照搬原损失调用。应保留该输出分支，临时关闭实际随机层，保证GMM仍使用学习到的标准差，结束后恢复原模式。

蒸馏学生前向必须保留计算图。不能复用E1的无梯度检查结果，也不能在计算图存活期间随意原地写回其依赖的缓冲张量。

## 2. 随机数隔离

为蒸馏动作采样建立独立CPU随机数生成器，例如固定初始化为：

\[
\text{distill seed}=2\,000\,003+\text{训练seed}.
\]

这只是本轮预注册的随机流编号，不是论文设置。该随机流在整条四阶段运行中持续推进，并写入断点，不每次抽样重新设seed。

从缓存教师参数采样分量编号和高斯噪声，再将动作送入设备计算学生概率。新增采样、教师生成和诊断不得消耗正常训练的数据采样或dropout随机流。

模型模式及运行状态需要完整恢复；教师生成不能推进优化器、调度器、归一化统计或动作历史。

## 3. 接入位置必须在原反向传播之前

现有`observe`已经包含原损失计算、反向传播、优化器更新及调度调用。因此，**不能像E1一样先调用完整原`observe`，然后再追加蒸馏更新**。

P1的接入点应是：

\[
\text{原BC＋IFA损失}
\rightarrow
+\beta\widehat L_{\mathrm{policy}}
\rightarrow
\text{一次总反向}
\rightarrow
\text{原梯度裁剪}
\rightarrow
\text{一次AdamW及原调度}.
\]

建议在独立的`p1_object_v1`实现中保留原损失构造顺序，仅增加目标查找、蒸馏前向和损失相加。原代码、历史报告、E1代码及结果不覆盖。

旧窗口身份与教师ID必须由数据加载器稳定传递，不能根据混合batch的位置猜测。当前任务样本不查教师；旧样本缺教师则立即报错。

## 4. 完整控制流程

以下是待实现的逻辑规范，不是仓库现成命令：

```text
加载已有OBJECT预训练检查点
建立P1专用输出目录、空潜在缓存、空教师目标库
读取冻结协议、特征清单与历史基线结果
初始化独立蒸馏采样随机流

对 task6、task7、task8、task9 依次执行：
    校验现有旧缓存与教师目标一一对应
    按原规则构建当前数据 + 旧回放训练集
    按原规则初始化本阶段优化器和调度器

    对100个epoch中的每个原训练batch：
        optimizer.zero_grad()

        按原训练模式计算：
            L_native = 原BC + 原IFA

        从同一个batch识别合法旧窗口
        如果没有旧窗口：
            L_policy = 0
        否则：
            按窗口ID读取固定教师GMM
            用独立随机流为每窗口采样16个动作
            教师参数、动作和教师log_prob均停止梯度

            对旧窗口进行一次确定性、可反传的学生前向
            计算完整GMM上的MC KL
            按“动作样本平均 → 旧窗口平均”归一化

        L_total = L_native + 0.05 * L_policy
        一次backward
        原梯度裁剪
        一次AdamW更新
        原调度器调用

        记录训练、蒸馏和开销日志
        按原规则保存训练断点

    保存本阶段ep99主检查点
    按原规则选择并更新潜在缓存
    仅为本阶段新入库窗口生成固定教师GMM
    保留旧窗口原教师目标，清理已淘汰窗口的活动目标
    原子提交缓存、教师清单与阶段结束状态

按原PRIMARY_EP99协议执行闭环评估
从原始执行成功记录重建指标矩阵并汇总
```

阶段结束目标生成不依赖任何闭环结果；评估先后顺序可以由运行脚本安排，但不能据评估改变教师检查点。

# 六、开跑前工程验收与断点恢复

## 1. 只做必要的工程测试

这些是小规模单元测试与少量批次检查，**不重新训练基线，不新增一套研究实验**。

| 验收项目 | 必须满足的条件 |
|---|---|
| P1关闭或 \(\beta=0\) | 跳过新增计算与采样，保持原更新路径 |
| 原训练一致性 | 新增代码未改变原BC、IFA、梯度裁剪和调度次序 |
| 教师重建 | 保存、加载GMM后，对固定动作的`log_prob`与保存前一致 |
| 分量置换 | 对同一组动作，完整分布概率不依赖混合分量编号顺序 |
| 目标身份 | 旧窗口与教师严格匹配；缺失、错配、跨seed目标均报错 |
| 梯度范围 | 教师和采样动作无梯度；学生解码器与策略头有梯度 |
| 冻结边界 | 原冻结参数不发生更新 |
| 更新次数 | 每基础步骤一次AdamW、一次原定调度 |
| 无旧样本 | 不生成伪教师，不额外抽样，蒸馏项为零 |
| 模式和随机状态 | 蒸馏不改变正常训练随机流与持久状态 |
| 阶段生命周期 | 旧教师不刷新；新增教师来自本次对应阶段`ep99` |
| 数值计算 | 一分量高斯特例与解析KL的采样估计相符 |
| 恢复一致性 | 恢复后数据顺序、教师库和独立采样流一致 |

有一个容易误设的测试条件：**教师与学生分布完全相同时，逐点对数概率差应接近零，但16样本的蒙特卡洛梯度不必精确为零。**不能因此把正确实现判成失败，也不能为了强行得到零梯度而改变目标。

## 2. 阶段结束必须支持事务恢复

保存以下阶段状态：

`TRAINING → EP99_SAVED → BUFFER_AND_TARGETS_COMMITTED`

如果在生成教师目标期间中断，恢复时使用**本次同阶段ep99检查点**完成未提交事务，不能用后续模型补目标，也不能重复抽一次缓存样本。

普通训练断点至少包含：

模型、优化器、调度器、阶段与epoch、正常训练随机状态、独立蒸馏随机状态、原缓存清单、教师目标清单及校验值、代码与协议版本。

已经提交的教师记录不得覆盖；临时记录和失败尝试保留可追溯信息，活动清单只指向完整一致的版本。

## 1. 首轮只执行一条P1完整训练序列

| task7／ep99 | task6、7 | 40 |
| task8／ep99 | task6、7、8 | 60 |

## 3. 指标计算与去留

继续使用已经冻结的指标程序。若以 \(R_{ij}\) 表示学习第 \(i\) 个增量任务后，对第 \(j\) 个任务的成功率，则：

\[
\mathrm{FWT}=\frac14\sum_{j=1}^{4}R_{jj},
\]

\[
\mathrm{NBT}
=
\frac13\sum_{j=1}^{3}
\frac1{4-j}\sum_{i=j+1}^{4}(R_{jj}-R_{ij}),
\]

\[
\mathrm{AUC}
=
\frac14\sum_{j=1}^{4}
\frac1{5-j}\sum_{i=j}^{4}R_{ij}.
\]

这与附件1采用的定义一致，不能把NBT分母换成其他论文的版本，也不能把最终平均成功率当作AUC。Yu 等 - Lifelong imitation learn…

首轮判断：

\[
\Delta\mathrm{AUC}
=
\mathrm{AUC}_{P1,42}
-
\mathrm{AUC}_{\mathrm{历史IFA},42}.
\]

**\(\Delta\mathrm{AUC}>0\)：冻结配置，进入另外两个seed。**

**\(\Delta\mathrm{AUC}\le0\)：当前配置未通过，不自动补seed，不叠加其他模块。**

比较使用原始成功率矩阵重建的未舍入数值，表格显示77.708等三位小数，避免显示精度造成假提升。NBT和FWT照常报告，但不要求每项、每个任务同时改善。

## 4. 三seed阶段

仅追加P1的43、44，历史基线继续复用；已有协议中记录了三个对应seed的基线结果。

报告三个P1结果、均值和标准差，以及与各自历史基线的差值。不能把三个seed都与seed 42基线比较。

单seed筛选是计算投入规则，不是统计显著性检验；历史同seed也不意味着逐位一致的反事实运行。若只在筛选seed上提升，新增两个seed不延续趋势，应标为不稳定，不能仅靠三seed平均包装为可靠改进。

# 八、日志、计算成本与交付文件

## 1. 训练日志必须能够解释P1究竟优化了什么

每个训练步骤记录或按epoch完整累计：

| 类别 | 记录内容 |
|---|---|
| 基础学习 | 原BC、原IFA及其加权贡献、总损失、学习率 |
| 蒸馏 | 旧窗口数、MC KL、加权蒸馏项、每窗口KL摘要、负估计比例 |
| 分布状态 | 教师／学生标准差摘要、混合权重摘要 |
| 覆盖 | 旧窗口ID、目标来源阶段、教师目标命中率 |
| 数值 | 总梯度范数、原梯度裁剪是否触发、非有限值 |
| 成本 | 训练时间、教师生成时间、蒸馏附加计算时间、峰值显存 |

**KL变小只是机制诊断，不是实验成功。**没有另外增加逐步梯度投影、损失触发或阈值接受机制。

## 2. 明确存储预算发生了什么变化

缓存的原窗口数和示范等价数量不变，但新增教师输出会增加总字节数，不能宣称完全相同的总存储预算。

按本轮记录格式，每窗口需要：

\[
5+5\times7+5\times7=75
\]

个FP32数值，即**300字节数值载荷**，另外加窗口元数据、索引和序列化开销。这个数值是记录格式的直接计算，不包含 \(H,a\) 本身。

实际报告：

\[
\text{总活动记忆}
=
\text{原潜在缓存字节}
+
\text{活动教师目标字节}
+
\text{索引元数据字节}.
\]

旧窗口淘汰时活动教师一起淘汰。归档的阶段检查点可保留用于审计，但训练不能借此重新查询已经不在合法缓存中的旧数据。

## 3. 计算成本不能预先称为“很小”

与E1不同，P1每个含旧样本的batch都会有蒸馏计算。主要额外成本是：

> 旧窗口的确定性学生前向及对应反向图，加上GMM采样和概率评价；阶段结束时另有一次目标生成。

**虽然每步只调用一次总`backward`，但并不等于没有额外反向计算。**另一方面，16个动作样本只增加概率计算，不应造成16次解码器前向。

不保留常驻教师网络，不复制整套视觉骨干。教师生成batch size首轮固定64，仅影响阶段末输出计算，不改变基础训练batch size。

已有同硬件基线耗时时计算实际倍率；没有则报告P1实测成本，不为测速重跑基线，也不沿用E1的10.51%作为P1开销。
