## 诊断结论

近期 B1 同时暴露了两类问题。多个模型在接近时没有持续把木块保持在夹口目标位置；最新 ODE 的两次直接停机，则发生在夹爪已收到闭合目标、反馈开度未能同步减小的时候。B3 的短测主要受关节跟踪限制。在一个模型上延长训练，或统一放宽保护，都不能处理这些不同的失败。优先在已保存的数据上把夹爪宽度差按接近、接触、持物分段，同时按木块在夹口中的位置评价；独立留出整条示范，分别检查动作方向、闭爪时机和接触后的表现。现场接触及硬件原因的确认还需要同钟的夹爪电流或力度与独立总线记录。
