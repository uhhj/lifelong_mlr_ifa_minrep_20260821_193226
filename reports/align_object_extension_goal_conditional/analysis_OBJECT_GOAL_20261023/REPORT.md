# ALIGN 在 OBJECT 与 GOAL 的闭环表现及解释边界

ALIGN 在 OBJECT 的三seed平均AUC高于RA 6.944444个百分点，在GOAL低0.868056个百分点。OBJECT的净AUC增益有96%来自最后一个任务橙汁入篮的贡献；旧任务最终均值没有改善。GOAL有更明确的后续保持问题：碗放到盘子上在刚学完时优于RA，训练酒瓶上架后，三个seed最终都落后RA 15个百分点。两套件结果支持任务依赖的学习收益，不能称普遍防遗忘或跨套件一致改善。

分析只读取六个已完整验收的本地包和既有源码诊断，不新增训练、模型前向或环境评估。所有训练及自动扩展保持用户取消状态。本次计算是已验收矩阵的描述性分解，不重新授予实验验收或自动分支。

## AUC 的任务贡献

令p(s,t)为学完阶段s后在任务t上的成功率。本项目冻结定义为 AUC = 1/4 × sum_t [sum_{s=t..9} p(s,t)/(10−t)]。它不是十个cell直接平均，也不是梯形积分。Task6每cell权重1/16，Task7为1/12，Task8为1/8，Task9唯一cell为1/4。各任务等权，评估次数较少的后期任务单cell权重更大。

OBJECT Task9橙汁入篮最终成功率为ALIGN 90/90/60%，RA 45/60/55%，每seed都正。均值80%对53.333333%，提升26.666667pp，乘1/4即AUC +6.666667pp，占净增益96%。这是代数贡献，不是因果归因或96%的评估episode改善。其余三个任务贡献净和仅+0.277778pp。OBJECT的对角线cell共贡献+5.972222pp，后续旧任务cell净贡献+0.972222pp；主要改善新任务学习表现，不能等同于全面旧任务保持改善。

将所有600条既有episode作未加权汇总，仅作为另一种描述：OBJECT为457成功对436成功，即+3.5pp；GOAL为478对474，即+0.666667pp。GOAL总成功数略多却AUC略低，说明其收益和损失分布在不同权重的cell上，原预定AUC结论不应因此替换。OBJECT的30个配对cell为12正/7平/11负，GOAL为9正/10平/11负。

## 机制解释及尚不能确认的原因

ALIGN相对RA同时改变两件事：BC从a[u]换为a[u+1]，并屏蔽身份不合法、填充和无下一动作的样本NLL。DataLoader人口与主更新数保留，BC按有效样本取均值，IFA照常。因此当前对照识别的是“标签前移加mask”整体效果，不能把收益全部分给单独时间偏移，也不能把mask比例解释成BC损失系数按同等比例降低。三seed累计屏蔽曝光比例OBJECT约4.2379%，GOAL约6.0893%；边界样本排除是否影响终止、放置或接触切换，目前没有分事件证据。

数据核验确实证明obs[u]的关节与夹爪对应执行a[u]后的states[u+1]。但已有Temporal诊断及本次六个CONTRACT中的三个主干源码SHA精确绑定同时确认：当前读出是最后时刻语言位置28，普通因果mask阻断同帧物理token29–31。最新可达物理token来自obs[u−1]。沿已核实的post-action时序，该帧关节/夹爪对应states[u]。因此原a[u]可能已与读出实际可见的最新物理状态对应；ALIGN目标a[u+1]则更接近从历史状态预判下一拍动作。不能把文件级obs与action错位直接等同于策略有效读出错位，并据此宣布ALIGN完成了整个控制链的因果对齐。

这是一项结构推导，六个ALIGN run的brief、complete_policy、transformer_modules源码与已有真实诊断逐SHA相同。此前14次CPU前向及输入VJP使用TACR41训练后Temporal和合成潜在输入；本次没有对ALIGN检查点新增前向，也没有把该探针当作真实demo预测质量证据。源码结构限制通用，具体闭环损益仍需专门对照。

最合理但未证实的任务机制假设是：OBJECT四个增量任务都是不同物体的抓取并入篮，动作过程较相似，历史运动可用于下一拍动作预测，某些物体上的提前量或边界mask可能改善闭环。当前最有力的结果集中在橙汁，不能推出所有物体都同等受益。GOAL四任务包含入碗、开炉灶、碗上盘、酒瓶上架，目标和接触过程更异质；仅从历史物理状态预判，可能更依赖任务阶段识别，对接触、释放或停止切换更敏感。现有成功率记录不能判断失败发生在抓取、移动、释放还是接触位置，不能把这些假设写成已发生的轨迹诊断。

GOAL最后阶段的训练人口提供一个更具体的干扰条件：旧RA成员1396，新任务1969，总3365，旧样本占41.49%；OBJECT对应旧2301、新1319、总3620，旧占63.56%。两套件的原RA各自与ALIGN使用同样人口和成员，因而这个差异不能单独解释套件内ALIGN相对RA的退化；它可能与变化后的BC目标及梯度发生交互，使GOAL后期保持更困难。GOAL Task8刚学完较好、进入Task9后系统下降，与这种阶段干扰解释相容，但尚无梯度冲突或成员有效覆盖诊断证明因果。

两套件也不是只换任务名称的单变量对照：OBJECT继承gamma .3、官方ep99初始化、105500主步，GOAL继承gamma .7、官方ep96初始化、76100主步；样本、语言和演示均不同。每套件内部与同seed RA协议一致，但跨套件差异不能完全归因于“OBJECT动作简单、GOAL复杂”，也不能把gamma差异直接解释成某种保护强度。

## 对方法结论的影响

当前最准确的结论是：在共享原Temporal读出、原RA采样和IFA下，下一动作加合法mask在OBJECT带来任务集平均收益，主要由橙汁入篮学习推动；GOAL未得到总体AUC收益，并暴露碗上盘在后续训练中的保持退化。ALIGN值得作为已观察到的经验变体保留，但尚不是完成物理可见性修复、普遍改进因果对齐或防遗忘的方法。

后续如重新设计，应先用数据层时序、主干实际可见token、部署决策时刻三者共同定义目标。区分mask-only与标签前移、原读出与可见最新物理信息的读出，才可能识别收益来源；直接换最后token会改变预训练GMM接收的表示，不能当作无代价修复。本段仅说明解释所需的对照，不授权或启动新实验。
