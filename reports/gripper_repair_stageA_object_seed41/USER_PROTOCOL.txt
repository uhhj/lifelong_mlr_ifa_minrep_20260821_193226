要证明新残差具有修复父策略具体错误动作的能力，不能只证明训练损失下降、输出发生改变，甚至不能只证明残差策略的整体成功率提高。

真正有说服力的证据应当是：

> 找到父策略在某个真实机器人状态下的具体错误动作，证明正确动作能够挽救该状态，再证明新残差能够产生这一修正，并实际改善后续控制结果。

我建议建立一套三级验证体系：动作可修复性 → 真实错误纠正 → 因果闭环恢复。

## 一、先明确：现有实验还缺少什么证据？

最新 SAZR 报告已经证明：

- 残差参数可以训练并产生非零修正。
- 成功锚点能够构造零响应。
- 独立验证和父策略回退正确执行。
- 在1562个训练窗口中，有10个窗口的父策略夹爪动作符号与专家动作不一致。
- 但由于夹爪输出 `tanh` 饱和，现有残差无法改变这些窗口的夹爪动作。

最后一项尤其重要。

父策略的夹爪均值前激活满足：

\\[ |b_g|\ge9.8876 \\]

而当前残差上限为：

\\[ |\delta_g|\le0.1. \\]

因此：

\\[ \operatorname{sign}(b_g+\delta_g) =\operatorname{sign}(b_g). \\]

这说明现有残差在这些状态下，不可能纠正夹爪开合方向。

不过，那10个专家标签不一致的窗口，尚不能证明就是七个验证失败初态的原因。

我们需要把这两个问题分开验证。

## 二、第一级：证明残差在结构上能够纠正错误动作

这是成本最低、必须首先完成的检查。

### 1. 不再通过饱和的 `tanh` 修正夹爪

新版本应将动作拆成：

\\[ a=(a\_{\mathrm{motion}},a\_{\mathrm{gripper}}) \\]

前六维继续表示连续运动控制，第七维使用独立的夹爪修正通道。

例如：

\\[ \hat y_g=f\_\phi(z) \\]

其中 \\(\hat y_g\\) 是夹爪开合的分类 logit，用真实专家夹爪标签进行二分类监督。

执行时，将分类结果映射到原 LIBERO 使用的夹爪动作取值。这里必须核对环境中正负号对应开合的实际约定，不能凭经验假定。

对于当前任务指令，候选夹爪动作可以独立于父 GMM 饱和的均值产生；对其他受保护指令，直接保持父策略输出。

这样才能从结构上消除“父策略夹爪输出饱和，残差永远无法翻转”的问题。

### 2. 使用真实错误标签进行单样本检查

需要检查：

| 检查对象                 | 通过要求            |
| -------------------- | --------------- |
| 父策略夹爪预测正确的窗口         | 候选应能保持正确开合      |
| 父策略夹爪符号错误的窗口         | 候选能够输出专家标注的相反指令 |
| 夹爪修正的训练梯度            | 非零且有限           |
| 旧任务及未知指令             | 仍满足原零响应／父策略回退   |
| 真实 `get_action()` 输出 | 与训练端的修正一致       |

不能只观察新分支的 logit 或输出张量，还要核对最终送给仿真环境的实际动作命令。

另外，现有10个符号错误窗口如果已经参与训练，就不能再把在它们上面的纠正率当作泛化结果。应使用按原始演示轨迹隔离的未见标签；若缓存缺少可靠演示身份，则需要单独采集验证状态。

通过这一级，只能证明：

新残差具备修正某类错误动作的表达能力。

它还不能证明修正是有用的。

## 三、第二级：证明父策略在真实状态下确实做出了错误动作

这是最关键的一步。

### 不能直接用“父动作与专家不同”定义错误

机器人完成同一个任务，可能存在多种正确动作。

例如，父策略选择从左侧接近物体，专家选择从右侧接近，两个动作可能都正确。

同样，一条轨迹最终失败，也不能确定失败是由某个夹爪动作造成的。

因此，我们需要找到有明确物理或专家依据的错误事件。

### 建议从 Task 6 的失败轨迹开始

此前独立验证的初态30–39中，有7条父策略与 SAZR 候选均失败。

可以将这些已经使用过的初态作为机制诊断集，重新执行父策略并记录：

- 每一步完整仿真状态及8步观测历史；
- 父策略的7维原始动作和实际环境动作；
- 夹爪开合命令及夹爪实际状态；
- 物体位置、夹持关系和任务阶段等可获取的物理信息；
- 成功谓词、首次失败或偏离事件的时间。

如果仿真环境不能提供足够的接触或夹持信息，则需要人工检查轨迹或提供同状态专家操作，不能编造物理错误标签。

对于一个怀疑错误的时间点 \\(t\\)，保存：

\\[ (s_t,H_t,a_t^{P}) \\]

再获取同一状态下的可信纠正动作：

\\[ a_t^\*. \\]

这里 \\(a_t^\*\\) 必须是针对父策略实际遇到的状态给出的纠正，而不是把另一条专家演示在相同时间编号上的动作直接拿过来。

## 四、第三级：同状态反事实实验，证明纠正动作带来实际改善

这是证明“修复具体错误动作”最强的实验设计。

在父策略执行到已确认的错误状态 \\(s_t\\) 时，保存完整可恢复的仿真状态，包括机器人和物体的动力学状态，以及策略所需的历史输入。

然后从完全相同的状态启动三条分支：

同一个父策略错误前状态 \\(s_t\\)

相同观测历史、物理状态、后续动作采样噪声

A 父策略

保持原动作

B 专家纠正

替换错误动作

C 新残差

执行学习的修正

分别观察物理事件与最终任务成功

### 必须区分两种结果

第一种：专家纠正有效。

父策略继续执行失败，而专家替换该动作后成功。

这支持该时间点确实存在一个可纠正、会影响结果的控制错误。

如果专家替换一个动作依然失败，不能直接宣布该动作不是错误；也可能需要连续几步修正。可以事先固定长度较短的纠正动作段，再重复对照。

第二种：残差实现了相同的挽救效果。

父策略失败，专家纠正成功，而新残差产生合法的纠正动作，最终也成功。

这才是直接支持：

> 新残差能够在一个真实错误状态下，纠正父策略行为并挽救任务。

为了隔离某个动作的因果作用，首先只允许三组在指定动作或预定短时间窗口内不同，随后都交还给同一个父控制器。

之后还需要单独评估残差持续参与整条轨迹时的表现；因为单点纠正成功，并不等于持续运行残差也成功。

如果无法准确恢复中途仿真状态，就不能称为严格的同状态反事实实验，只能退而求其次，从相同初始状态使用固定噪声进行配对 rollout。

## 五、应该报告哪些指标？

我建议不再把训练 L1、NLL、KL 作为主要有效性判据。

| 指标       | 定义                         | 证明什么         |
| -------- | -------------------------- | ------------ |
| 错误动作纠正率  | 未见、已确认错误状态中，实际执行动作被正确修复的比例 | 能否学会动作修正     |
| 可救援状态恢复率 | 专家纠正可救援的状态中，残差也成功救援的比例     | 修正是否具有实际控制作用 |
| 父策略成功保持率 | 父策略成功的独立状态中，残差仍成功的比例       | 是否产生不必要的退步   |
| 完整闭环增益   | 相同初态下残差与父策略成功率之差           | 实际任务收益       |
| 纠错类别覆盖   | 已证实修复夹爪、位置、旋转等哪些动作错误       | 能修复什么，不能修复什么 |

最重要的是同时报告两种配对计数：

\\[ N\_{\mathrm{rescue}} = \\#(\text{父失败，残差成功}) \\]

\\[ N\_{\mathrm{harm}} = \\#(\text{父成功，残差失败}). \\]

以及：

\\[ \boxed{ \Delta\_{\mathrm{success}} = \frac{N\_{\mathrm{rescue}}-N\_{\mathrm{harm}}}{N} } \\]

这可以直接揭示残差究竟是在挽救失败，还是同时破坏原有成功。

不过，10条验证状态中出现两次新增成功，仍只适合作为推进下一阶段的初步信号，不足以证明统计显著性。正式确认还需要更多独立状态、多 seed 和配对置信区间。

## 六、针对当前代码，推荐怎样安排验证？

不建议立即重新跑完整 Task 6–9。

我建议分三阶段执行：

| 阶段       | 具体工作                                     | 环境成本         | 通过条件                         |
| -------- | ---------------------------------------- | ------------ | ---------------------------- |
| A：动作可学习性 | 修改夹爪输出结构，在真实专家标注窗口和独立留出窗口上检查符号纠正         | 0次环境 rollout | 能改变原饱和夹爪动作，旧指令不受影响           |
| B：错误状态干预 | 在少量父策略失败轨迹中寻找有专家纠正依据的动作，执行父／专家／残差三路同状态干预 | 少量定向 rollout | 至少观察到真正由残差挽救的可纠正错误，并保留所有失败案例 |
| C：独立完整闭环 | 使用从未参与诊断、标注、训练或模型选择的初态做配对验证              | 原协议或新增预先登记预算 | 多数独立设置有正向收益，且不系统性破坏父策略成功行为   |

数据隔离尤其重要。 之前用于 SAZR 验证的30–39，以及已用于正式比较的0–19，都不能在开发新残差之后再次冒充全新的独立确认集。若需要从实际错误状态获得新增专家纠正，这部分也必须计入新增监督和交互预算；普通 BC 适配器等对照应获得匹配的数据与训练机会。

### 为什么这比继续优化残差损失更重要？

以当前10个夹爪符号错误的训练窗口为例，即使我们让新分类头全部预测正确，也只说明它拟合了已知标签。

如果在某个真实失败状态中，父策略错误地发出开爪命令，而同状态专家闭爪干预可以完成抓取，那么：

1. 先确认新残差可以从实际环境输入中识别并发出闭爪命令；
2. 再确认执行这一修正后，物体确实被正确抓取；
3. 最后确认任务能够从这个状态继续完成。

这就从“离线动作拟合”提升成了“真实动作纠错”。

而且整个过程不依赖损失代理量、不确定性评分、梯度冲突或人为定义的样本重要性。

## 最终判断

严格意义上，无法仅凭有限离线数据证明残差必然修复所有父策略错误；但可以通过真实错误标注、可恢复的同状态干预和独立闭环结果，建立具体、可重复的纠错能力证据。

对当前项目，第一步应当先处理夹爪 `tanh` 饱和导致的不可修正性。这是已有代码和数据已经证明的结构限制。

随后，最有价值的实验不是“新残差的训练 L1 能下降多少”，而是：

从真实父策略失败轨迹中找到一个专家动作能够挽救的错误状态，并让新残差在完全相同的状态下，实现同样的挽救效果。

如果这一步都不能实现，那么继续叠加成功锚定、零响应门或 KL 约束，也无法证明残差真正具备我们希望获得的机器人行为修复能力。
