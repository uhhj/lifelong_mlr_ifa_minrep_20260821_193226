# DEBR 审稿修订版 RAS 模拟审稿意见

审阅日期：2026-11-09（Asia/Shanghai）。审阅对象为用户指定的《DEBR - A Dual-Experience Behavioral Retention Framework for Lifelong Robot Imitation Learning - 审稿修订20261109.docx》。本文为独立模拟审稿，不代表期刊实际决定。

**建议：大修（Major Revision）。** 研究问题具有机器人持续学习价值，方法描述已具备较好的可读性，两个套件的平均表现也值得进一步研究。但目前尚不足以接受：核心贡献的独立效果、主要基线的可靠性、预训练来源与独立确认，以及有限记忆条件下的实际资源代价仍需补足。部分问题需要补实验，不能仅靠措辞修改解决。

审阅覆盖全文、5张表、2幅原始嵌入图及公式；用 Word 只读导出得到19页PDF，检查全篇缩略图并放大核对关键公式页。默认LibreOffice渲染器因环境缺少soffice而未运行成功，随后使用本机Word完成导出。没有改动论文，没有访问或重跑训练、闭环评估或原始实验结果。本次数字核验仅为稿件内部算术及外部原始文献核对，不代表实验真实性审计。

**值得肯定的方面**

论文将专家示范与策略成功执行历史区分，动机与机器人闭环分布差异直接相关。保存实际执行高斯而非固定分量编号，且无需保留每个旧任务教师网络，具有明确的实现价值。第3.4.3节交代双候选同起点、完整训练状态恢复、固定探针和正式评估不参与门控，基本逻辑清楚。表2提供Random、K-Center、RA-Coreset对照；表3、表4分别给出累积组件与优化器调用匹配结果。论文明确说明额外交互和探针成本，并未将优化器调用相同宣称为全部资源相同，这些边界应保留。

**主要意见1：基线差距与ALIGN的性质需要澄清（第3.3.3、4.3、4.4.2节）**

OBJECT中，本地MLR＋IFA的AUC为68.3，原论文报告79.4，相差11.1个百分点；DEBR相对两者的差值分别为18.2和7.1。原论文OBJECT的FWT为84.6，本稿DEBR为80.4，因此相对原文并非所有指标占优。跨研究数字不能证明本地实现错误，但如此明显的差距会影响审稿人对18.2个百分点收益来源的判断。

尤其是ALIGN在OBJECT上将AUC从73.2提高至80.2，增幅7.0个百分点。若ALIGN是修正导出数据的观测—动作错位，则正确对齐应成为公平比较的公共数据处理条件，而不能只出现在增强方法中；若它是方法性变换，需要用原始轨迹时间戳、索引示例或小规模只读配对核验说明为何合法，区分“修复数据错误”与“提出新学习机制”。目前文字不足以作出其中任何一种定论。

建议提供MLR＋IFA复现差异表，列出权重、任务名单与顺序、示范采样、动作索引、有效窗口过滤、冻结模块、IFA参数、执行规则及评估初态。至少增加Random＋ALIGN这一经过相同数据处理的对照，并将原文报告值与本地复现值在表1中分行明确标识。

外部依据：MLR＋IFA原文表1及实验设置，https://arxiv.org/html/2603.10929v1 。

**主要意见2：现有消融无法充分支持核心机制归因（表2、表3）**

在强基础Execution Supervision之上，加入Support-Weighted Retention使OBJECT AUC从85.0变为84.6，GOAL从82.5变为83.5；完整DEBR相对该强基础的增幅为1.5和4.8。与无门控保持相比，门控带来1.9和3.8的平均AUC提升。这支持“受控保持整体有潜力”，但不能直接推出支持度加权本身有效，或两核心模块存在已证实的协同作用。

优先补充：在相同成功历史和其他设置下令非空任务q_j=1，与当前支持度加权比较；在相同ALIGN和执行监督下比较Random＋SHBR与RA-Coreset＋SHBR；用同一批自主成功历史进行普通行为蒸馏或直接成功经验回放，检验SHBR的执行分量保持与门控是否超过简单利用额外数据的效果。表2已经比较Random与K-Center，不应再把“缺少K-Center基线”作为问题；尚未分离的是覆盖感知交换相对简单随机与覆盖混合选择的额外价值。

累积消融显示条件增量，不能单独证明组件独立贡献，更不能据此进行因果百分比分摊。

**主要意见3：数据来源与开发评估需要形成可复查证据（第4.1、5节）**

稿件明确写明评估套件被重复用于开发，公开预训练权重的完整数据来源尚未独立核验。这种披露是必要的，但不能替代证据。应提供权重来源与哈希、实际预训练任务名单及数据范围、与增量Task6—Task9的关系，以及采集和评估初态的可复查分离清单。未核验来源不等于已经发生数据泄漏；审稿要求是闭合来源证据，避免把不确定性升级为指控。

建议冻结方法与超参数后，补充未参与开发的任务顺序、任务划分或套件上的确认。新评估初态或新种子可检验随机稳健性，但本身不能完全消除对既有任务套件的开发适配。

**主要意见4：终身学习验证范围偏窄（第4.1、4.6节）**

两个套件各10个任务，但实际持续学习与评价只覆盖四个增量任务Task6—Task9，且只有一个固定顺序。预训练六个任务没有进入当前指标，因而不能判断其已有能力是否被保留。建议至少报告这些预训练任务的阶段性成功率，并增加一种较长序列或未参与开发的任务顺序。真实机器人验证能提高机器人学说服力，但不能将“无实机”机械地视为RAS拒稿条件；当前更直接的问题是遗忘范围、顺序稳健性和长期增长没有充分检验。

**主要意见5：有限记忆与资源公平性尚未被量化（第3.3.2、3.4.1、4.4.3节）**

M_k^D=M_{k-1}^D∪S_k意味着每任务配额受限、总记忆随任务增加；每任务最多128个成功历史窗口进一步增加记忆。应区分“每任务固定配额”与“全生命周期固定总预算”，报告示范记忆、成功历史、元数据和训练状态快照的实际字节数及峰值开销。不能仅把重叠潜在窗口数直接等同于若干完整轨迹的存储量。

DEBR优化器调用约为标准执行监督的1.85倍（OBJECT）和1.87倍（GOAL），此外还有每任务10次交互、固定探针前向与状态恢复。表4已正确限定为优化器调用匹配，本条要求是在此基础上报告墙钟时间、环境步数、峰值显存、存储及选样开销。更有解释力的机制对照是允许简单基线利用相同额外交互数据，而不是仅增加其训练轮数。

**主要意见6：创新边界与门控外推需要更精确（第2、3.4.3、4.6.1节）**

M2Distill已包含GMM策略分布蒸馏；GEM等工作已研究使用历史记忆约束更新。论文需要说明自身差异具体位于自主成功状态来源、固定实际执行高斯、轨迹支持度及同起点候选选择，而不能把行为保持或新旧任务约束的宽泛概念当成新贡献。这里并非判断DEBR与这些方法相同，而是要求明确新增机制和直接证据。

固定当前探针最多64个窗口、每旧任务最多8个成功窗口，却在大量比较块中重复用于选择。图1接受点满足规则主要说明门控按定义运行，不能独立证明对未参与门控的状态或闭环表现具有保证。式（16）比较Q与C，也不保证相对块起点不退化。建议增加独立探针或未用于门控的历史窗口诊断，检验探针改善与真实任务成功率的关系。当前稿件没有提出正式理论保证，不应据此要求不必要的收敛定理。

外部依据：M2Distill第IV-B节，https://arxiv.org/html/2410.00064v2 ；GEM，https://arxiv.org/abs/1706.08840 。

**主要意见7：统计解释与外部误差项存在需修正的问题（表1至表5）**

三个训练种子、每阶段每任务20回合适合初步比较，但不足以仅凭均值宣称小幅增益稳定成立。OBJECT中RA相对K-Center的AUC只高0.9；门控相对无门控保持的平均AUC增益为1.9和3.8。应报告每个种子的配对差值及不确定性，区分训练种子与回合抽样两层随机性。200个回合并不是200个独立训练重复；仅凭已有均值和标准差不能可靠重建配对显著性。

表1统一标注“均值±标准差”，但M2Distill作者公开稿表I明确标注mean and standard error。稿件通过MLR＋IFA二次汇总这些外部数值，必须追溯各行误差项的原始含义，确认版本及是否有换算，不能未经说明统一改称标准差。这是呈现与可比性问题，不构成数据造假判断。

**次要意见与可直接修订项**

- 明确式（6）、（10）中s_g的统计量、数据范围、冻结时点与数值下限；目前只说根据训练统计确定，不能唯一复现。
- 明确K-Center首个中心、随机锚随机种子、128个窗口向10个回合的整数分配、探针抽取方式、无有效BC样本及无合法旧样本时的损失处理。
- 给出任务索引对应的实际任务名和顺序配置ID；补训练硬件、软件版本和可复查配置。
- 式（18）的FWT实际为学习当前任务后的对角成功率，定义与MLR＋IFA一致，不能误称公式错误；应提醒读者它不是未学习任务上的零样本前向迁移。
- 图2宜补最终绝对成功率和逐种子信息。相对差值能定位收益，却不能独立呈现机器人实际完成任务的水平。
- 方法信息密集而目前两幅图均为结果图，建议增加双经验流与同起点候选选择的框架图；这属于表达完善，优先级低于证据问题。

**数值检查与判断边界**

按稿件显示精度计算，主结果AUC差值18.2/10.9、门控增益1.9/3.8、等优化器预算差值5.6/3.6均与表格一致。RA对Random的OBJECT FWT在显示值上为73.3−66.7=6.6，而正文写6.7；这可能来自先计算未舍入均值再舍入，应核对原始均值或注明，不能凭显示值差异认定计算错误。原论文MLR＋IFA数值已核对；未从原始回合记录重算表格均值、标准差及图像。

**建议的修订优先级**

第一优先级是核验预训练来源、解释OBJECT基线差距及ALIGN，并统一公平对照条件。第二优先级是支持度q=1、相同自主数据的简单保持对照和Random＋SHBR，建立核心机制证据。第三优先级是未参与开发的确认设置、预训练任务保持和资源表。文字与图表修改应同步进行，但不能替代前三项。

若这些问题得到实质解决，我会倾向重新评估其可接收性；若仅润色文本而保留相同证据，则大修后的接收依据仍不足。
