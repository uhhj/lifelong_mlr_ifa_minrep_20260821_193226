# A1 执行价值与首轮边界

结论：值得执行一次附件限定的 OBJECT / seed42 完整筛选，但现有证据不支持提前判定收益。

## 为什么还有价值

已有正参考修正 IFA 的三 seed 原始矩阵和实际配置可核验。A1 的唯一变量是将原始 IFA 特征投影到合法语言参考张成空间；动作头和 BC 仍使用完整表示。它检验原角距离中完整表示范数是否造成不必要的补空间约束，与此前任务来源采样实验不同。

## 不能预设的结论

参考空间不能直接命名为任务知识，补空间也不能命名为共享技能。投影可能同时增大角度梯度；输出补空间梯度为零不能保证参数更新后的补空间不变。seed42 原配对只在 task7→6、task8→7 对当前任务施加 IFA，task9 不新增直接 IFA，后期结果包含路径依赖。

历史修正基线使用 RTX4090，本轮 RTX3090。短程同状态逐位 parity 已通过，但不声称完整训练轨迹跨硬件逐位一致。单 seed AUC 正向只是扩大计算投入的筛选条件，不构成统计显著性；不按成功率重跑、挑选 checkpoint 或修订门槛。

## 已执行的工程证据

- 完整预训练语言编码器及 LoRA 严格载入；task6 缓存单位方向误差 7.193560002513399e-7。
- 五项几何单元测试、二十项真实运行检查全部通过。
- A1 关闭和单位投影下的完整状态与原修正 IFA 精确一致；BC/动作路径不变；原生更新、RNG、恢复、失败前状态保存均已验证。
- 评估子进程导入检查通过，不消耗正式 rollout。

## 冻结执行与停止边界

首轮仅 seed42，四阶段各 100 epochs、共 200 PRIMARY_EP99 trials。比较修正 IFA 原始矩阵重建的未舍入 AUC（72.916666…）；差值严格大于零才自动补 OBJECT 43/44。无额外基线或预训练、无辅助闭环，无旧实验队列恢复。

三 seed 平均差值仍为正才进入附件规定的跨基准扩展。服务器规范资产目录目前仅有 OBJECT 预训练和 feature cache；GOAL/LIBERO-50 需要取得并核验已有对应输入与正参考基线，不能凭 OBJECT 结果臆造或重训基线。
