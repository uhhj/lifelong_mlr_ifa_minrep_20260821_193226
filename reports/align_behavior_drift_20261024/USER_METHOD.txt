## 一、方向1到底是什么？

### 1. 核心思想：允许学习新任务，但为旧动作设置变化范围

假设机器人已经学会 Task8：把碗放到盘子上。

原来的策略在某个状态下预测：

- 机械臂向下移动；
- 接近盘子后停止；
- 随后打开夹爪。

现在学习 Task9：把酒瓶放到架子上。

为了学会 Task9，模型需要更新共享的 GPT-2 时序解码器和 GMM 策略头。

问题是，这些参数更新可能同时改变 Task8 的动作。

信赖域的思想就是：

允许模型调整参数，但要求它在旧任务状态上的动作变化不能超过可接受的范围。

行为信赖域示意

概念示意。实际 GMM 策略的信赖域并非简单的二维圆形。

普通行为蒸馏通常是鼓励新旧策略尽量接近。

信赖域则进一步提出约束：

\\[ \min\_\theta L\_{\mathrm{BC}}+\lambda L\_{\mathrm{IFA}} \\]

满足：

\\[ D\_{\mathrm{old}}(\pi\_{\theta},\pi\_{\mathrm{teacher}}) \leq\epsilon \\]

意思是：

- 第一项负责学好当前任务；
- 第二项保留原来的 IFA；
- 约束负责限制旧行为变化；
- \\(\epsilon\\) 决定允许旧策略改变多少。

这里的目标是候选设计，并非你当前已经运行过的方法。

### 2. 什么叫“自适应”？

如果所有旧状态都使用同一个固定约束，容易产生两个问题。

抓取、夹爪释放等状态可能需要严格保护；而一些普通移动状态，即使动作略有变化，也未必导致任务失败。

因此，可以为不同状态设置不同的保护强度。

| 旧任务状态        | 候选保护方式          |
| ------------ | --------------- |
| 稳定、连续移动      | 允许适度更新          |
| 接触、抓取、释放     | 更严格限制行为漂移       |
| GMM 动作模式容易切换 | 重点限制模式切换        |
| 与新任务存在有益迁移   | 在不破坏旧行为的条件下允许更新 |

注意，这些保护强度不能仅凭动作幅度猜测。真正的设计难点，是如何从已有旧任务数据和教师策略中可靠地估计行为变化风险。

这才是该方向可能产生新颖性的地方。

第一，你有现成的旧任务回放数据。 RA-Coreset 已保存旧任务潜在特征，不需要重新访问旧任务原始图片，就可以对旧状态进行策略前向计算。

第二，你有可复用的阶段检查点。 可以将学习 Task9 前的策略冻结为教师，让正在训练的策略作为学生。

第三，你的 GMMHead 可以直接输出动作分布参数。 实际 `GMMHead.forward_fn()` 提供均值、标准差和混合 logits；现有 EFTR 已经验证过提取和比较这些参数的计算路径。

## 三、最关键的可行性核查：此前 EFTR 为什么没有达到保护目标？

你之前实际上尝试过一个相关方向：EFTR 使用旧任务教师、行为 KL 和候选优化器更新，尝试保护旧策略。

但它暴露了两个重要问题。

### 1. GMM 的 KL 可能极端放大

你的 `GMMHead` 使用 5 个高斯分量，每个分量预测 7 维动作，其中第 7 维控制夹爪。

实际部署不是从完整混合分布中随机选择分量，而是：

1. 选择 logits 最大的高斯分量。
2. 从这个分量的正态分布采样动作。

所以，即使两个模型的混合权重几乎相同，只要最大分量发生切换，最终动作就可能突然改变。

EFTR 的已有诊断发现：

| 指标         | 结果         |
| ---------- | ---------- |
| 旧任务回放样本    | 781        |
| GMM 模式切换   | 59         |
| 夹爪均值正负翻转   | 8          |
| 原历史行为评分    | 292,667.10 |
| 其中夹爪 KL 贡献 | 292,663.50 |
| 当时设定的保护预算  | 0.10       |

此外，即使完全去掉夹爪 KL，剩余评分仍为 3.60，超过原预算。

这说明不是单纯修改数值精度就能修复的问题。

需要注意：EFTR 后来由用户提前终止，没有最终完整闭环结果。现有证据证明的是原约束难以满足，而不是所有行为信赖域方法都无效。

### 2. 我进行了一个独立 CPU 数值验证

为了检查上述问题是否属于 GMM 的数学机制，而非某次训练的偶然现象，我使用 PyTorch 构造了与当前策略输出形状一致的双模式示例。

假设两个高斯分量分别预测夹爪动作 +1 和 −1。

教师与学生只是把两个几乎相等的 logits 对调：

- 教师选择 +1。
- 学生选择 −1。
- 两者混合权重几乎一样。

实际计算得到：

| 检验指标                 | 结果            |
| -------------------- | ------------- |
| 混合权重分布的 KL           | 约 0.000000125 |
| 实际选中动作均值差            | 2.0           |
| 选中高斯的 KL（标准差 0.0001） | 200,000,000   |
| 选中高斯的 \\(W_2^2\\)    | 4.0           |

这是本轮实际执行的 CPU 构造性测试，不是对你的真实训练检查点重新评估。

这验证了两个关键机制：

第一，只保护 GMM 混合权重或完整混合分布，未必能保护实际部署时的最大权重分量选择。

第二，使用普通 Gaussian KL 保护近乎确定性的夹爪动作，可能产生极大的数值惩罚。

我还验证了一个包含动作均值偏移和模式保持 margin 的可微代理损失，均值参数与 logits 都得到了非零、有限的梯度。

这说明可以构造能够反向传播的保护目标，但并不意味着它已经在实际机器人任务中有效。

## 四、应该怎样设计适合你的信赖域？

我建议不要直接对整个 GMM 施加统一 KL，而是首先保护实际部署行为。

### 第一步：保存旧策略的动作参考

学习 Task9 前，用 Task8 阶段的 ALIGN 检查点作为冻结教师。

在 RA-Coreset 的旧任务样本上缓存：

- 五个高斯分量的动作均值；
- 五个分量的标准差；
- 五个分量的 logits；
- 教师实际选中的分量。

这样在 Task9 训练时，可以直接比较学生与教师在同一旧状态上的预测。

按你现有 GOAL 最后阶段的 1,396 个旧样本、5 分量、7 维动作估算，若用 float32 缓存以上全部分布参数，原始数据约 0.42 MB，不含元数据。

这说明教师输出缓存的存储开销很小，而且你此前的 EFTR 已实现类似的教师缓存路径。

### 第二步：分别保护动作数值和动作模式

我建议采用两部分约束。

A. 动作距离保护

比较教师与学生在教师选定分量上的动作均值和标准差。

可以考虑对角高斯的 Wasserstein-2 距离：

\\[ W_2^2= \\|\mu_T-\mu_S\\|\_2^2+ \\|\sigma_T-\sigma_S\\|\_2^2 \\]

这与 KL 的区别是：它衡量动作分布在动作空间中的位移，不会仅仅因为标准差接近零，就把有限的动作差异除以极小方差。

但机械臂和夹爪仍需分别设定合理尺度，不能直接使用未经校准的全维平均。

B. 模式切换保护

只保护均值还不够，因为学生可能选择另一个高斯分量。

因此，还需要约束：

\\[ z^S\_{k_T} \geq \max\_{j\ne k_T} z^S_j+m \\]

其中 \\(k_T\\) 是教师选中的分量，\\(m\\) 是正的模式间隔。

通俗地说：不仅要求原来那个动作预测不要改变太多，还要求新策略不要轻易改为执行另一套动作。

这类约束有可微的 hinge 代理，可与原 BC 和 IFA 一起训练。

但固定教师分量编号也有局限：有时两个高斯分量可以交换编号而保持相似行为。之后可以考虑分量匹配，不过第一版应先检验原始模式切换是否确实与遗忘相关。

### 第三步：加入自适应风险，而不是平均保护所有样本

可以根据旧任务中已存在的信息构造一个风险估计：

\\[ r(x)=f(\text{动作切换},\text{夹爪变化},\text{模式不确定性}) \\]

然后令：

\\[ \epsilon(x)=\frac{\epsilon\_{\max}}{1+\alpha r(x)} \\]

风险越高，允许的动作漂移越小。

但这里必须先验证这些风险指标真的能够预测旧行为退化。否则只是给现有蒸馏损失增加了一套手工权重。

另外，如果要称作真正的信赖域方法，就应监控或约束实际漂移预算，而不能只是增加一个固定权重的损失项。可以探索对偶变量、自适应惩罚或更新接受机制，但深度非凸训练下不能保证所有约束必然满足。
