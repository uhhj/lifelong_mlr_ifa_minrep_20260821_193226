## 为什么六轴仍在纠偏却几乎不再靠近

使用同一份模型参数、归档腕部原图、八帧关节历史和日志中的俯视热图坐标，重算每条八步规划。用规划时间戳和步序对齐后，189 个重建目标与日志预测的水平坐标最大差值小于 0.000001 mm。

4.0 秒以后有 8 次新规划。低高度时，末段模型根据高度和视觉线索缩小水平修正量。重算显示这 8 次的高度项均为零，视觉线索给出的最终保留比例中位数为 19.0%。下表以每次新规划为单位计算中位数。

| 同一批观测的量 | 数值 |
| --- | ---: |
| 俯视估计的水平偏差 | 8.80 mm |
| 经腕部和姿态估计、尚未应用末段衰减的目标位移 | 3.67 mm |
| 经过末段衰减的目标位移 | 0.69 mm |
| 经过八步规划增益后的整段水平位移 | 0.43 mm |
| 仅在离线计算中略去末段衰减时的整段水平位移 | 2.31 mm |

在 4.0 秒后的下发帧，预测与实际下发的水平目标在 0.0001 mm 精度内一致。下发目标与当帧发送前反馈的水平距离中位数为 0.35 mm，最大 0.99 mm。根据反馈进行正运动学换算，从 4.0 秒后的首帧到最后一帧，夹口水平净移动 1.70 mm。时限解释了何时停机，末段衰减直接解释了对准尚未获确认时六轴给出很小的水平修正。
