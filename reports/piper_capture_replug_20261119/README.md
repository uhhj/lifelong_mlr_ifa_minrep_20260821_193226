# 直连录制入口的 USB-CAN 重插恢复

2026-11-19 22:06:22（北京时间），「PiPER AgileX 录制」已部署新的起录检查。现场选好任务并按回车后，直连录制入口核对 `can0`。同一次主机启动内，若原 USB-CAN 的厂商、产品和序列号一致、接口索引已变化，且新控制器为 DOWN / STOPPED，入口通过系统现有的 sudo 验证恢复 1 Mbit/s 可收发，核验后原子更新录制和 STOP 面板共用的绑定。授权有效时直接继续，授权过期时由操作员在录制终端输入一次系统密码。录制软件不接收或储存密码。[入口改动](entry.patch) · [恢复逻辑](capture_replug.py)

已就绪的接口走原有检查。原接口被主动停用、USB 身份变化及 BUS-OFF 均不会触发重插恢复。物理拔插期间用内核接口索引锁定配置目标。进程在接口启用后、绑定写入前中断，再次起录时会核验先前的恢复记录。接口调整只在直连起录前发生，原转发模式和录制中断流处理沿用原逻辑。[iproute2 索引解析](https://github.com/iproute2/iproute2/blob/v5.15.0/lib/ll_map.c#L246)

## 验证

在台架 Linux 上用临时绑定与模拟接口通过 11 项测试，涵盖正式录制入口的直连与转发分支、重插、授权取消、索引冲突、USB 身份变化、BUS-OFF 和中断后重试。旧录制文件有备份。部署后从实际 ROS 环境导入桌面入口并通过已就绪接口的检查，主机 TX 包计数保持 0。现场已拔电，本次没有实施物理拔插、恢复送电、复位、使能或运动测试。安装采用普通用户权限，没有新增免密 sudo 规则或特权程序。[离线验证](verify_replug.py)
