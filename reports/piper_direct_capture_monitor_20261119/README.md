## 录制和停机入口

- 已装的 `PiPER AgileX 录制` 入口仍读取原双接口遥操会话目录，只接受一个活跃绑定会话，动作来源为该会话的本机发送回显。单总线直连的目标帧需要从公共总线接收。现场的官方角色绑定不会创建原转发程序的会话。
- 录制桥的结束路径调用 `CaptureService` 的 `end` 请求。所装官方采集服务提供开始、结束和示范元数据字段；录制入口结束时只停止本条数据保存。 [AgileX data_tools 所用版本](https://github.com/agilexrobotics/data_tools/tree/1363e0579ad6cb3980f65e200a3c536481c819ab)
- 已装控制界面的 `button_piper_stop` 和停止状态打印的按钮分别绑定不同函数；机械臂 Stop 走 PiPER CAN 停机命令。厂家说明使用软件 Stop 后手臂可缓慢下落。目前 rlmi 的唯一 CAN 口处于硬件只听，旧转发程序的 500 ms STOP 也不在官方直连指令路径内。现场独立实体急停的接线和功能未远程核实。 [AgileX 控制界面说明](https://github.com/agilexrobotics/Piper_sdk_ui) · [厂家关于停机后下落的说明](https://github.com/agilexrobotics/piper_sdk/issues/20)
