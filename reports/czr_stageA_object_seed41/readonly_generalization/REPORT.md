# CZR跨演示泛化失败：只读证据审计

结论：严格局部球的确很保守，但现有数据不支持“只把半径放大即可修复”。直接原因是当前距离下同演示相邻状态很近，而跨演示错误没有形成与正确状态分离的局部簇。这说明当前特征距离与高精度动作纠错机制不匹配，不证明隐藏表示完全没有纠错信息。

## 1. 构造集修复主要来自自匹配

- 23个训练错误中，删除查询自身作为中心但保留其他中心、均值和半径后，只有2个仍落入另一错误中心的球内。这是中心自排除检查，不是重新拟合的独立验证。
- 原构造集23/23修复因此主要反映精确记忆，不应解释成学到跨演示规律。
- 8次逐示范留出均无触发、无修复；两条留出演示也无触发。

## 2. 保护半径由同演示的邻近正确时刻决定

- 23/23错误中心的最近正确样本都在同一演示；真实监督时刻仅相隔1–2步。
- 1255个训练窗口的自排除最近邻中，1251个来自同一演示（99.68%），时间差中位数1步。
这与窗口重叠、相邻时刻输入相似相符，但没有隔离视觉背景、操作进度和动作转换各自贡献，不能直接声称表示只编码了示范身份。
- 半径中位数约0.0703，而留出错误到匹配错误中心的最短距离约0.787–0.909。不同演示的错误在这个几何尺度上并不相邻。

## 4. 原保护集存在额外保守性，但放松它仍不解决问题

- 23个中心中有12个的最近正确邻居，其父夹爪类别与该中心不同。这类查询原本会被父类别门拒绝，却仍参与缩小原球半径，因此原定义有额外保守性。
- 改用相同父类别正确样本计算半径的离线对照，中位半径增大1.117倍，最大6.283倍。
- 但固定0.45系数下，跨演示和留出仍无修复。留出首次修复前仍触及7个正确窗口；放大至该对照半径6倍时，修复4个、损害102个。
因此“保护了不必要的正确案例”是次要限制，不能解释全部失败。

## 5. 有弱排序信息，不等于有可靠的动作替换边界

- 原距离/半径分数识别标签错误的描述性ROC-AUC：跨演示0.8712，留出0.9666。此AUC不是原任务成功率AUC。
- 这说明错误相对很多正确样本确实更接近错误中心；不能说特征毫无信息。
- 但留出只有4个错误、299个正确样本。8倍半径检出4个错误时同时误触27个正确样本，干预精确率仅4/31=12.90%。错误稀少时，较高ROC-AUC仍可能无法提供高精度纠错。
- 四个留出错误的最近同父类别正确样本均比最近错误中心更近。简单最近专家标签检索也未修复这4个错误，反而损害11个正确窗口。
- 跨演示最近专家标签检索修复6个、损害64个；不能把这项事后检索对照当作训练通过的新模型。

未中心化单位向量和原始欧氏距离都保留了同样的失败模式。这只排除了两个简单距离替换作为明显解释，不排除更合适的时序条件、纠错监督或表示中存在未被当前距离利用的信息。

## 判断与边界

当前证据支持：构造集自匹配＋演示内近邻主导＋罕见错误的极高精度要求，共同使各向同性局部球缺乏可迁移的纠错范围。0.45是直接拒绝原因，但单纯放大或删除额外保护并不能满足原零伤害门槛。
不建议根据这些留出结果调大半径；这会把诊断集变成调参集。也不能据此断言整个父表示无用，或证明这些标签差异会造成物理失败。
四个留出错误全部来自demo8，demo9没有父标签错误；窗口彼此相关。父模型以前见过全部10条示范，这里只有纠错记忆层面的留出。
未来若继续，优先需要能对应同类纠错需求的跨演示监督或可信同状态纠正，而不是增加残差参数量或继续扩大无条件邻域。本次不启动任何后续实验。
