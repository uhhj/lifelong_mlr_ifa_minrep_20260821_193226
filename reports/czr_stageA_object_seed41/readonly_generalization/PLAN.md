# CZR 跨演示失败的只读诊断

仅加载已保存的 native_features.pt（特征/父类别/专家标签），不加载或前向模型，不训练、不执行环境。原实验全部文件前后哈希验证；结果写新目录。

固定诊断，不将留出标签用于部署/选择阈值：

1. 原中心化单位向量距离，查看错误中心最近正确邻居的示范身份、真实时间差、父类别；统计自排除最近邻的示范集中度。
2. 原固定半径，排除查询本身作为错误中心，区分自匹配、同示范覆盖和跨示范覆盖。
3. 在已保存查询上反事实计算半径倍率1/2/3/4/6/8/10/16的FS/SF；另计算首个伤害、首个修复和零伤害前可修复数。这是事后阈值敏感性描述，不是新算法验收或调参。
4. 使用相同父动作类别的正确案例构造保护半径，检查原来无条件纳入其他父类别正确样本是否造成不必要限制。
5. 固定对照距离：原中心化单位向量、未中心化单位向量、原始欧氏距离。不学习度量、不白化拟合、不选择最优指标，只判断结论是否完全依赖当前归一化。
6. 留出查询的最近错误/同父类别正确距离、最近专家标签检索结果，用于判断特征是否仍包含有用的控制标签信息。全部训练均值只从该fold的合法构造数据计算。

只针对当前冻结特征+欧氏/角距离检索的可用性作结论，不能证明网络完全不编码错误信息；相邻窗口不独立，留出仅两条示范且父模型此前见过它们。
