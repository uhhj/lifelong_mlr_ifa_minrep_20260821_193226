# 新一代零响应残差：从全局动作校准转向局部错误修复

结合最新 `MLR` 分支（`624bc1a`）的夹爪 Stage A 实验、SAZR 原型，以及 ZR-v1～v3 的报告，我建议重新设计为：

CZR：保守式局部纠错残差（Conservative Zero-Response Repair）

核心思想是：

> 父策略是默认控制器。只有当前观测与有真实监督的错误案例具有充分一致性，而且没有与已知正确行为冲突时，残差才允许修改动作；否则完整保留父策略。

这与之前几代方法存在本质区别。

ZR-v1～v3 主要学习“如何修正动作”；SAZR 主要增加“哪些成功状态不应修改”；而 CZR 进一步要求：先获得局部修正的明确依据，再决定是否干预。

## 一、为什么我认为必须转向这种设计？

最新 Stage A 的结果揭示了三个问题。

| 已有证据                                | 反映的设计缺陷                 | 新方案需要做到          |
| ----------------------------------- | ----------------------- | ---------------- |
| 父策略留出夹爪准确率99.34%，独立分类头95.05%        | 新头全面接管父策略，收益空间很小但破坏空间很大 | 默认保留父策略，仅处理局部例外  |
| 缓存上纠正了2个留出错误，但原生图像定向检查中未纠正任何仍存在的父错误 | 训练与实际执行的特征输入不等价         | 使用与真实执行一致的观测编码   |
| SAZR 成功锚点投影后，仅剩3.47%的训练特征平方范数       | 全局正交投影保护过宽，削弱残差可用特征     | 只在受保护状态局部抑制修正    |
| ZR-v3 的 KL 上界成立，仍出现闭环退化             | 限制动作变化幅度不等于修正方向正确       | 将动作修改限定到有纠错依据的状态 |

最新夹爪实验尤其有说服力：在303个留出窗口中，父策略仅有2个夹爪标签错误，新头纠正2个，却新增15个错误，净损失13个正确预测。而定向原生图像复核发现，10个缓存父错误中只有4个在原生路径上仍然错误，新头对这4个均未修复。

这意味着：下一代残差最大的挑战不是提高修改动作的能力，而是降低错误介入的概率。

来源：[Stage A 报告](https://github.com/uhhj/lifelong_mlr_ifa_minrep_20260821_193226/blob/624bc1aaca4d83bb41c0852355b84687cd5f33bf/reports/gripper_repair_stageA_object_seed41/REPORT.md?utm_source=chatgpt.com)、[SAZR 失败诊断](https://github.com/uhhj/lifelong_mlr_ifa_minrep_20260821_193226/blob/624bc1aaca4d83bb41c0852355b84687cd5f33bf/reports/sazr_object_seed41/readonly_analysis/REPORT.md?utm_source=chatgpt.com)。

这些数据还不能证明 CZR 一定有效，但已足以否定“继续训练一个从零开始、全面替换父动作的分类头”作为首选方向。

## 二、我建议的完整算法：双重零响应＋局部纠错记忆

CZR 保留已经验证有效的语言零响应机制，但取消两个已经暴露问题的设计：全局成功特征正交投影和全面接管夹爪的独立分类头。

### 1. 第一层：语言零响应

仍使用真实冻结语言向量 \\(e\\)，构造原有的双向零响应门：

\\[ g_j(e_i)\approx \begin{cases} 1&i=j,\\\ 0&i\neq j. \end{cases} \\]

对于基任务、未知指令或无法可靠匹配的指令，返回父策略。

这部分不需要重新发明。过去几轮的工程检查已经说明，规范指令上的跨任务直接贡献可以被限制得非常小。

### 2. 第二层：建立“错误案例”和“正确案例”两种记忆

对于当前任务 \\(j\\)，先冻结其公共策略 \\(C_k\\)，使用原生评估模式的图像编码路径处理具有真实专家标签的训练窗口。

取当前时序表示：

\\[ z_i=T_k(H_i)\_{\mathrm{last}}. \\]

父策略真正执行的是 GMM 最大 logits 分量。因此，应根据所选分量的动作以及真实专家夹爪标签，建立两类集合：

\\[ \mathcal E_j= \\{(z_i,y_i^\*):\hat y_i^P\neq y_i^\*\\}, \\]

\\[ \mathcal C_j= \\{z_i:\hat y_i^P=y_i^\*\\}. \\]

这里：

- \\(\mathcal E_j\\) 是专家标签不一致案例。
- \\(\mathcal C_j\\) 是父策略与专家标签一致的保护案例。

必须强调：\\(\mathcal E_j\\) 目前还不是已经证明会造成物理失败的错误状态集合。它只能提供离线纠错监督。

这两组信息都需要保留，不能只根据错误样本训练一个新分类器。

### 3. 第三层：局部错误支持，而不是全局投影

对冻结特征构造一个预先固定的归一化表示：

\\[ \phi(z)=\frac{z-\mu\_{\mathrm{train}}} {\\|z-\mu\_{\mathrm{train}}\\|\_2+\epsilon_0}. \\]

其中 \\(\mu\_{\mathrm{train}}\\) 只使用合法训练数据计算，不能从留出演示或正式测试结果中反向调整。

对于每个错误案例 \\(e_i\\)，计算它到正确案例集合的最小距离：

\\[ d_i^C=\min\_{c\in\mathcal C_j} \\|\phi(e_i)-\phi(c)\\|\_2. \\]

然后定义局部修正范围：

\\[ \boxed{r_i=0.45d_i^C.} \\]

0.45只是需要预先固定的保守原型比例，不是从现有负结果中优化出来的最优值。

在新状态 \\(z\\) 上，只有满足以下条件才允许修正：

\\[ \\|\phi(z)-\phi(e_i)\\|\_2\<r_i, \\]

并且当前父策略选择的夹爪动作类别与该错误案例中的父动作类别一致、局部支持案例的专家修正方向不存在冲突。

否则不修正。

这一设计具有一个直接的有限集合性质：

对于所有用于构造 \\(r_i\\) 的正确训练案例 \\(c\in\mathcal C_j\\)，它不可能落入任何对应错误案例的修正球内。

因此，在冻结且确定性的特征编码下：

\\[ \boxed{R_j(c)=0,\qquad c\in\mathcal C_j.} \\]

这比此前 SAZR 的全局成功子空间投影更加有针对性。

SAZR 将成功锚点张成的所有方向从残差输入中删除，结果只保留约3.47%的训练特征平方范数。而这里不删除任何通用特征方向，只在有限错误案例周围建立局部动作修正区域。

当然，这种保证只覆盖已登记的正确案例。未见正确状态仍可能落入错误案例的邻域，因此还必须进行独立留出验证。

### 4. 第四层：直接修复动作，不重新学习全部夹爪决策

对于夹爪，继续采用已核查的物理控制约定：

\\[ -1=\text{张开},\qquad +1=\text{闭合}. \\]

CZR 不再训练一个从零预测开合的全局 `Linear(512,1)` 头。

对于局部错误案例，保存其专家夹爪动作 \\(y_i^\*\\)。只有通过局部支持检查时，才建立修正：

\\[ \Delta a_g=y_i^\*-a_g^P. \\]

最终动作：

\\[ \boxed{ a_g^{\mathrm{CZR}}= \begin{cases} a_g^P,&\text{局部修正条件不成立},\\\ y_i^\*,&\text{局部修正条件成立且修正方向一致}. \end{cases} } \\]

前六维动作在首个原型中完全继承父策略：

\\[ a\_{1:6}^{\mathrm{CZR}}=a\_{1:6}^{P}. \\]

这是一种以父策略为基底的稀疏动作残差，不是重新训练完整动作分类器。它直接绕开了夹爪 `tanh` 饱和，而且当局部修正不被允许时，父策略的实际动作可以完整保留。

默认不介入；局部错误支持成立且不与已知正确行为冲突时才修改动作。

## 三、为什么这一版比重新训练一个小分类头更合理？

上一版训练实际上要求：

\\[ f\_\theta(z)\longrightarrow y_g^\*. \\]

也就是让新网络重新预测所有状态的夹爪开合。

但父策略已经有很强的开合能力，因此更合理的学习问题是：

\\[ \boxed{ f\_{\mathrm{repair}}(z,a_g^P) \longrightarrow \text{是否存在有依据的局部例外修正}. } \\]

二者的难度和风险完全不同。

新方法对父策略正确案例建立直接的保护条件，而不是依赖一个新模型把所有正确行为重新学一遍。

还需要注意，局部纠错也存在明显风险：如果错误案例与正确案例在原生特征空间高度重叠，局部修正范围会变得非常小，甚至完全无法启用。

这不是应该通过强行扩大半径来掩盖的问题。

它可能意味着：

1. 当前时序表示无法区分这些动作状态；
2. 纠错依赖的时间信息没有进入表示；
3. 父策略与专家采用不同但可能都有效的操作方式；
4. 现有专家示范不足以支持可靠的纠错判断。

因此，这一版首先应该验证错误状态与正确状态是否在实际执行特征上可区分。

如果无法区分，就应停止局部修正，考虑增加合法的时序观测或新的专家纠正数据，而不是继续拟合一个更复杂的分类器。

## 四、与 Coreset 的协同方式

这一点需要谨慎设计，否则会重复此前 Event＋Coreset 的问题。

Coreset 继续负责全局历史记忆覆盖；CZR 负责对当前公共策略存在明确动作差异的局部区域进行修正。

两者在概念上具有不同职责。

但不能把额外保存的错误案例当作免费记忆。

| 资源                   | 处理方式                    |
| -------------------- | ----------------------- |
| 现有 Coreset／RA Buffer | 保留原成员和任务配额，不重新选样        |
| 当前任务原始示范             | 仅在当前任务训练阶段完整可用          |
| 错误案例特征和专家修正          | 作为新增残差参数或记忆，单独计算字节      |
| 历史任务可访问监督            | 仅合法旧 Buffer 和已计入预算的残差状态 |

首个 Task 6 原型可以暂时使用完整训练集建立正确案例排除区域，但扩展到 Task 7–9 时，必须规定每任务固定的错误案例存储上限，或者将其并入现有总记忆预算。

还需要在每个阶段重新核对父策略当前的实际错误案例。因为共享网络发生变化之后，上一阶段的错误修正未必仍然必要。

不建议无条件继承旧错误修正并继续激活。 这正是 ZR-v2、v3 在不同阶段可能发生不稳定修正的风险之一。

## 五、建议的实验顺序：先做一个不需要新训练的原型

这一设计有一个成本优势：第一步不必训练新的网络。

### 实验 A：原生特征下的局部纠错可行性

使用现有 OBJECT seed41 Task 6 的冻结 RA＋IFA 模型，保持 demo0–7 训练、demo8–9 留出。

| 步骤 | 执行内容                                 | 要回答的问题                 |
| -- | ------------------------------------ | ---------------------- |
| A1 | 用原生 `eval` 图像路径重新构造全部可唯一绑定的训练和留出窗口特征 | 是否消除了原来的缓存—推理差异        |
| A2 | 在训练集构造父动作与专家标签不一致案例、正确案例             | 是否有真实可用的局部纠错支持         |
| A3 | 检验错误／正确案例的邻域分离情况                     | 是否能在不误触发已知正确案例的条件下修正错误 |
| A4 | 构造局部残差，参数和半径仅由训练集决定                  | 能否形成实际可执行的稀疏动作修正       |
| A5 | 在留出演示的原生路径一次性检查纠正与损害                 | 是否真正得到净收益              |

这一轮不需要启动仿真环境，也不需要新训练400个公共 epoch。

错误案例最好按真实演示中的连续夹爪操作事件归并，而不是把相邻重叠窗口当成多个独立错误。这里仅改变残差案例的组织方式，不改变 Coreset 的 Buffer 选样。

半径选择应固定使用训练演示内部的跨演示验证规则，留出 demo8–9 不参与选择。若训练错误案例数量太少，无法获得跨演示支持，应报告证据不足，而不是调整阈值直到留出集提高。

### 实验 B：什么时候值得进入闭环？

先要求新方法在独立留出原生图像上至少实际纠正一个父策略标签错误，同时不新增已观察到的正确行为错误，并确保非目标指令、前六维运动控制和拒绝状态能够精确回退。

这只是进入闭环的原型门槛，不是统计显著性标准。

如果没有可区分的错误邻域，或者纠错仍伴随大量正确动作损害，就不进入闭环。

通过后，再使用独立初态与配对噪声验证 \\(N\_{\mathrm{rescue}}\\) 和 \\(N\_{\mathrm{harm}}\\)。若希望进一步声称具体物理错误得到修复，则仍需同状态专家纠正或可信的干预证据。当前静态示范不能代替这类证据。

## 六、三种候选方案的比较

| 方案               | 原理                        | 优势                  | 主要限制                       |
| ---------------- | ------------------------- | ------------------- | -------------------------- |
| A. 父策略蒸馏约束残差     | 学习新分类头，同时强制逼近父策略正确动作      | 可延续神经网络训练结构         | 仍需要学会何时修改；大量正确样本易淹没极少数错误   |
| B. 局部案例支持残差（CZR） | 只在真实监督错误案例的局部区域修正，并排除正确案例 | 默认保持父策略，有明确有限样本保护性质 | 错误案例稀少或特征不可分时，可能几乎无法激活     |
| C. 失败状态专家纠正残差    | 收集父策略真实失败状态的纠正动作，学习恢复控制   | 最直接对准闭环失败           | 需要新增专家来源、交互预算和可靠的状态恢复／监督协议 |

我的优先选择是 B，作为下一轮低成本可行性验证；C 才是长期最有可能产生真实闭环恢复能力的学习路线。

原因是目前尚未确认真实失败状态的可信专家来源。直接设计 C 的完整训练流程会预设一项实际还不具备的监督条件。

另一方面，B 即使失败，也能明确告诉我们：使用现有真实示范，究竟能不能在保持父策略正确行为的同时，构造具有一定泛化范围的局部纠错器。

这比再训练一次普通 BCE 分类头更有信息价值。

## 七、创新性与最后的判断

CZR 的创新点不能简单写成“使用最近邻”或“使用零响应门”。这些机制本身都有大量先例。

潜在研究贡献在于：

将语言空间的任务隔离与动作空间的局部正确行为保护结合，在固定历史记忆的持续模仿学习中，为残差干预建立一个可验证的保守条件。

它能够提供两个不同层次的结构性质：

\\[ \text{跨任务零响应} \\]

以及

\\[ \text{已登记正确案例上的零修正}. \\]

而在其他状态，残差只有获得局部错误监督支持时才有资格介入。

但还不能说这样的组合已经具有顶会级创新性。需要证明局部保护不只是一个额外的拒绝机制，还能真正提高未见状态的纠错能力，并且优于同样预算的普通稀疏分类器或简单案例查找。

我认为当前最合理的下一步，不是立刻运行完整 CZR＋Coreset 四任务，而是先运行上述实验 A。

它应该回答一个决定性的基础问题：

> 在实际原生推理特征空间里，那些父策略确实与专家标签不一致的动作，是否能够和绝大多数父策略已经正确的动作可靠地区分开？

如果答案是肯定的，CZR 才有理由进入局部修正和闭环验证；如果答案是否定的，那么继续加强残差网络并没有足够依据，下一项真正需要解决的将是状态可辨识性或失败状态纠正监督不足，而不是残差参数量不够。
