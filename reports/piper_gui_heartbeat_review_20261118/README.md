# PiPER 上位机心跳超时核查

复核 2026-11-18 14:42（北京时间）结束的现场测试。上位机绑定的 `teleop_binding/worker.py` 在持续跟随阶段运行 `while True`，结束条件来自 STOP 或保护检查。该执行入口没有会话总时长上限。

上位机的 Qt 定时器计划每 100 ms 通过 `panel.json` 写入单调时钟心跳。转发程序要求读取到的心跳小于 500 ms。本轮退出原因明确为 `upper-computer heartbeat lost`，从臂确认 STOP，未发现手动 STOP 标记。程序最终只保留了覆盖写入后的最后一次心跳，因此无法从该时间戳恢复停机前的心跳间隔。

Qt 刷新函数同步写入心跳并读取状态文件，时间线及状态快照也由同一个 ext4 文件系统持久化。事件窗口内未查到可用的系统异常记录或历史 I/O 采样。界面线程延迟与同步 I/O 是待验证的原因。本次为只读排查，控制程序未改动。
