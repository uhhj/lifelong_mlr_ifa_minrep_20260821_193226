# PiPER 真机预训练判断

核查日期为 2026-11-18（北京时间）。本次核查覆盖论文实验协议、仿真代码的动作接口和本地 PiPER 调试记录。服务器 SSH 主机身份未能验证，服务器上的采集程序和检查点存量仍待确认。

## 判断

- **主从遥操作采集可以在策略预训练前开展。** 人工示教和主从控制提供专家动作。最近一份本地调试记录仍有回零姿态和采集同步待验收，批量采集前应先通过短轨迹验收。
- **正式真机对照实验需要一份共用的、经实机验证的基础策略。** 如已有检查点与 PiPER 的观测、动作、预处理和基础任务划分一致，并已通过基础任务闭环验收，各方法可共用该检查点。否则，使用同一批真机基础任务示教进行一次共享的多任务行为克隆。可以评估复用 CLIP 视觉和语言编码器以及兼容模块作为初始化，用真机数据校准状态与动作，并训练真机动作头。
- **当前 LIBERO 整策略不能直接控制现有的 PiPER 关节跟随接口。** LIBERO 默认采用 Panda 的末端位姿控制，PiPER 调试使用关节目标和夹爪控制。两者即使都采用七维动作，分量含义仍不同。若正式使用关节空间，DEBR 的动作误差分组和尺度也应按实际关节及夹爪定义调整。基础策略验收后，再冻结共享前端，生成同域的回放特征，随后开展增量对照。
- **专家示教和 SHBR 数据来自不同的执行过程。** 采集时先划定基础任务与后续增量任务，保留外部和腕部图像、操作臂反馈、实际下发的关节及夹爪命令、时间戳、任务指令和成功标记。SHBR 的成功轨迹由学到该任务的策略自主执行后获得。

## 复核证据

本次从本地源文件重新定位了八项匹配证据。DEBR 稿件确认仿真基础任务划分、持续学习期间冻结前端、末端动作分组以及自主成功轨迹来源。仿真源代码确认 `OSC_POSE` 和七维策略输出，其中策略代码基于 `0769e165`。本地调试记录确认 PiPER 采用 `MOVE_J` 主从跟随，以及姿态和同步验收的记录状态。

- MLR + IFA 的基础任务训练与后续增量适配见 [原论文第 3 节](https://arxiv.org/html/2603.10929v1#S3)。
- 仿真及实机动作接口见 [LIBERO 环境代码](https://github.com/Lifelong-Robot-Learning/LIBERO/blob/master/libero/libero/envs/env_wrapper.py) 与 [AgileX PiPER 主从跟随文档](https://github.com/agilexrobotics/piper_sdk/blob/master/assets/double_piper.MD)。
