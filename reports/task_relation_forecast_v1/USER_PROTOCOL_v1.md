# 任务关系信号前瞻预测实验 v1

状态：方案，尚未执行。建议实验标识：`task_relation_forecast_v1`。

## 0. 主问题与本轮边界

在开始学习目标任务 t 之前，根据源任务 s、源任务训练后的模型以及少量目标任务演示，能否预测：

1. 相对于没有接受源任务训练的共同基座，源任务经验会提高还是降低固定目标训练预算后的成功率？
2. 学习目标任务会使源任务的成功率下降多少？
3. 结构关系加入行为相容性以后，是否提供可复现的预测增量？

本轮是受控的两任务诊断，不是新控制器，不恢复原正式 lifelong 训练。为隔离源任务参数经验，目标适应阶段两支均不回放、均按同一规则初始化优化器。取消回放只属于诊断协议，不是最终取消 MLR。

保留原 MLR 模型结构、模态接口、GMM NLL、动作执行和原生可训练参数集合。不做 QP、GN 更新删除、FP32 修复、Fisher 变体、buffer 选择算法、网络扩容或新的损失函数。

所有关系信号在相应目标适应分支开始前生成并封存。后续结果不得反向决定特征、任务、预算、rank 或分析规则。

## 1. 修正目标定义

### 1.1 学习进展不等于迁移

`P_t(K)-P_t(0)` 仅为本模型在 K 步内的目标任务学习进展。没有不含源经验的参照，不能归因于源任务。

本轮统一称下面的量为“固定目标预算下的条件迁移效应”，不用它替换既有 LIBERO FWT/NBT/AUC 的定义。

- θ_b：每个 seed 的共同预训练基座。
- θ_s：θ_b 仅接受源任务 s 的固定预算训练后得到的参数。
- θ_{s→t}(k)：从 θ_s 出发，在目标任务 t 上按本轮协议训练 k 步。
- θ_{b→t}(k)：从 θ_b 出发，使用完全相同目标数据流、学习率序列、优化器初始化和 k 步预算。
- P_t(θ)：按原生闭环评估接口计算的任务成功率。

主目标一：

    TRANSFER_K(s,t) = P_t(θ_{s→t}(K)) - P_t(θ_{b→t}(K))

正值是当前协议下的正向条件迁移，负值是负向条件迁移。源训练产生额外历史计算，因此这不是“总计算预算相同的算法比较”。不同源 s 的 prior 预算相同，可以比较它们对同一目标的相对作用。

主目标二：

    DAMAGE_K(s,t) = P_s(θ_s) - P_s(θ_{s→t}(K))

正值表示源任务退化，负值表示源任务改善。它与“源经验对目标有负迁移”是两个不同现象，不合并为一个标签。

### 1.2 分开零样本迁移与后续学习差异

    TRANSFER_0 = P_t(θ_s) - P_t(θ_b)
    ACQUISITION_DIFF_K = TRANSFER_K - TRANSFER_0

第二个量是两支从起点到 K 步的改善量之差，受天花板/地板和起点水平影响。报告它但不把它解释为纯粹的内在学习速率。

同样报告每支自身的目标改善、新旧绝对成功率和 NLL。已有成功率接近零的源任务保留，不把“无进一步下降空间”解释成保持良好。

## 2. 为什么不直接沿用上一轮36个中后期起点

已有 `actual_update_fidelity_v1` 和 `functional_component_counterfactual_v1` 的主要完整起点来自两个阶段、epoch30–99；它们适合预测训练过程中后续响应，不是目标任务尚未学习的状态。

不能把多个 epoch/batch 当作多个独立任务关系，也不能把一个混合旧模型在新任务上的同一个 NLL 复制成每个旧任务的方向性相容性。

保留其测量、恢复、GMM、Mean-GN代码。历史结果仅作背景/辅助分析，不拼入本轮主样本表。

## 3. 任务矩阵与公共基座

### 3.1 主设计

建议使用当前增量任务编号6、7、8、9，组成全部有序非对角任务对：

    source ∈ {6,7,8,9}
    target ∈ {6,7,8,9}, target != source
    seeds = {45,46,47}

共12种有序任务对、36个 seed×任务对实验单元。

编号必须先与实际 task_id、任务描述、数据集和套件对应。必须核验 θ_b 的机器人 BC 训练记录未包含这四个任务；通用视觉/语言预训练是两支共同条件，不等于本轮任务专门训练。

若公共基座包含某待测任务，不能把它包装成“未学习新任务”。先停止相关任务矩阵的执行并报告暴露缺口，不自动改用别的套件或重建基座。

### 3.2 源模型构造

每个 seed 从同一 θ_b 分别对四个源任务单独训练，不按6→7→8→9顺序构造 θ_s。源模型不能混有其他三个待测任务经验。

已有源单任务状态仅在共同基座、训练数据划分、优化器、步数、随机流及训练路径完全匹配时复用；不能把混合历史模型、ep95代理或不同预算的源模型当等价替代。

种子可能共享同一官方预训练权重：如实记录，不把微调种子误称为独立预训练种子。

## 4. 数据角色与访问边界

每个任务按演示轨迹ID固定分为：

- A_train：30条轨迹，训练源模型及目标适应。
- D_signal：10条轨迹，用于关系信号，只在允许时点访问。
- E_eval：10条轨迹，用于离线结果，不参与训练和预测特征。

以上为50演示任务的提议配额。先核验实际数目；少于50时按60/20/20的固定比例划分并记录实际数目，不复制轨迹补数，不跨集合借样本。

使用固定hash排序按轨迹分割，三个seed共用同一分割。这样三个seed检验优化随机性，不增加任务或数据集独立性。

D_signal每任务固定最多128个窗口，均衡覆盖各轨迹和相对时间位置。E_eval每任务固定最多320个窗口。窗口不足时报告实际数量；同轨迹样本仍相关，不能按窗口数宣称独立样本数。

源任务到达时预先保留源D_signal窗口及标签，计入微型诊断记忆成本。源原始全数据在目标阶段只允许独立evaluator读取 E_eval，不允许关系模块偷看。

目标任务的A_train及D_signal演示在任务到达时可访问。关系特征只使用预先指定的D_signal，影子一步使用A_train首个batch。E_eval不提供给信号脚本。

离线和闭环独立：演示NLL不是成功率替代。闭环使用原生评估初始化集合和固定rollout种子。

保存 `DATA_MANIFEST.json`、轨迹和窗口指纹、各模块访问权限。

## 5. 训练协议与复用计算

### 5.1 固定预算

- 源经验预算 K_source = 1000 次优化器更新。
- 目标适应主终点 K_target = 300 次优化器更新。
- 目标离线辅助终点 k = 100；不为它新增闭环评估。
- 源构造保存 step0、step100、step300、step1000。

1000步并不保证源任务已熟练，300步并不代表完整学习。源任务掌握程度必须报告，最终结论只覆盖这个固定短程预算。禁止因为迁移相关性不好临时延长某个源或目标预算。

若所有结局几乎为同一成功率地板/天花板，结果记为 `OUTCOME_RANGE_INSUFFICIENT`，不筛点或调信号“造出可预测性”。需要改变预算应另立下一协议，而不是修改本轮。

### 5.2 训练流程

采用现有模型的原生 BC/no-replay 训练路径、完整 GMM NLL、相同batch size与可训练参数集。IFA、QP和所有额外门控关闭。

目标两支在任务到达时均建立全新的、同超参AdamW和scheduler；一二阶矩及step计数一致。这个显式对照用来隔离参数历史，不是原生优化器状态续跑。源训练阶段同样按冻结初始化规则启动。

使用同一个原生学习率配置生成公共的逐步LR数组，源与直接目标参考的前300步数组必须相同。不要针对短实验把原余弦调度压缩成300步降至零。没有既定公共数组时，先在协议文件中登记实际配置和完整数组hash，再开始任何结果测量。

同一 seed、同一目标 t 的A_train minibatch序列、增广随机流、dropout种子及执行步数在不同源分支中配对。语言输入始终使用被评价/训练任务自身描述，不能为跨任务评价换成源任务描述。

### 5.3 参考分支无需重复训练

若公共基座、优化器初始化、LR数组和数据流完全相同，源任务 t 的单任务训练在step300的检查点，正是 θ_{b→t}(300)。保存并复用，不重复跑12次无源参考。

这些参考检查点仅用于结果对照；不得用于为 s→t 计算“学习t之前”的关系特征。特征脚本只能读 θ_b、θ_s 和允许的D_signal。

## 6. 冻结候选信号

不做特征自动搜索，不新增黑箱关系网络。

### 6.1 难度/掌握度基线 B

    b_t = L_t(θ_b; D_signal,t)
    b_s = L_s(θ_s; D_signal,s)

它们控制目标在公共基座上的可学性以及源模型当前拟合水平。保留完整GMM NLL的实际数值；NLL可为负，不能用任意相除或百分比解释。

### 6.2 原IFA输入信号

复用原视觉/语言余弦相似度计算接口并核对其定义。使用原始连续分数，不重新按当前只有四任务的排名设置“前50%”触发阈值。

### 6.3 潜特征结构信号 S_lat

同一共享编码坐标下，对有效时序帧按固定mask池化，得到各任务表示质心，计算余弦相似度。归一化、模态权重和池化方式在结果前冻结。

仅复用参数和编码器指纹一致的latent缓存。若原生训练改变编码器，必须在被测θ_s下重算，不比较坐标系不同的向量。

### 6.4 主行为信号 A：方向性动作相容性

    A_{s→t} = L_t(θ_b; D_signal,t) - L_t(θ_s; D_signal,t)

越大表示源训练后的模型比共同基座更能解释同一批目标专家动作。它是源训练的零样本NLL作用，不是固定K步后的成功率结论。

此处使用同一任务、同一专家动作和完整GMM log_prob，不把未对齐两条轨迹的动作直接求余弦。

这个设计借鉴TSN-Affinity的源策略动作相容评价，但新增共同基座校正；不是照搬其稀疏子网络或冻结复用架构。

记录期望动作误差、混合权重/尺度变化作为解释性诊断，不把它们增加为可事后替换主信号的候选。

### 6.5 功能结构信号 S_GN

在同一源参数点 θ_s、同一policy-head参数映射下，用源和目标D_signal分别估计既有Mean-GN：

    C_s(θ_s), C_t(θ_s)
    U_s, U_t：固定rank16
    S_GN = ||U_s^T U_t||_F^2 / 16

两者使用同一动作度量W（沿用已有构造规则，在源信号集上确定并同时用于两任务）。不从不同θ处直接拿历史基比较。

不改Mean-GN定义，不改为Fisher，不做更新投影控制。仅因数值秩不足而保留少于16列时，报告 r_s、r_t，并用 min(r_s,r_t) 代替分母16；该退化案例另列，不能据此扫描rank。零trace时记不可用，不伪造满秩。

可附带记录已有的shadow新任务更新在U_s中的介入比例，作为描述项；本轮不把所有谱/角度/介入指标都加入回归。

### 6.6 较贵的参考信号：一次影子适应

从θ_s及本轮目标初始化optimizer做一次目标A_train首batch候选步d_t，不写入正式诊断分支状态。

    R_old = L_s(θ_s+d_t; D_signal,s) - L_s(θ_s; D_signal,s)
    R_new = L_t(θ_s+d_t; D_signal,t) - L_t(θ_s; D_signal,t)

这是“一步试探”，不是零更新信号，单列计算成本。可以附带h_s^T d_t核对，不建立逐样本约束，也不再验证上轮已完成的整体梯度理论。

影子操作后完整回滚参数、optimizer、scheduler、RNG和模型模式，然后目标训练仍从原θ_s开始。

## 7. 预测器，不是控制器

使用同一简单岭回归，对 TRANSFER_300 和 DAMAGE_300 分别拟合。禁止深网络、自动特征选择及全数据调参。

冻结6个模型族：

- M0：B。
- M_IFA：B + 原视觉相似 + 原语言相似。
- M_A：B + A。
- M_LA：B + S_lat + A + S_lat*A。
- M_GA：B + S_GN + A + S_GN*A。
- M_probe：B + R_old + R_new。

每个连续特征只在训练fold上标准化。交互项由训练fold标准化后的两信号构造，再用训练fold统计量标准化。零方差特征置零并登记。

target也只按训练fold中心化/标准化；若训练target无方差，使用训练均值预测并标记该fold缺乏可学习目标。

固定目标：mean((y-zβ)^2) + 1.0*||β||²；截距不罚。此λ只是冻结的工程默认，不是理论最优，不新增调参搜索。

额外报告零样本迁移 TRANSFER_0 与 ACQUISITION_DIFF_300。某信号只预测前者、不能预测后者时，只能称“预测初始优势/固定预算表现”，不能声称预测学习加速。

## 8. 真正的任务级留出

### 8.1 主评估：严格留出目标任务

对四个待测任务分别做一折。目标为t的测试折中：

- 训练集删除所有 `source=t` 或 `target=t` 的行。
- 在其余3个任务的6个有序对×3seed上拟合。
- 测试其余3个source→t，共9行。

四折组成36个out-of-fold预测。不能只删除target=t却让t作为训练source泄漏任务信息。

### 8.2 辅助：留一seed

3折；用另外两seed拟合，在完整被留出的seed上评价。它只回答新优化随机性，不替代留任务泛化。

不可把同一轨迹窗口、同一任务对的重复测量随机拆到训练/测试。

## 9. 结果测量与行为预算

### 9.1 离线

每个source、reference、transfer模型在允许的E_eval上测原GMM NLL，报告k0、100、300；源prior另测1000步。逐轨迹汇总后再做任务级统计，不能用窗口池化伪增n。

### 9.2 闭环

沿用原生动作采样/执行方式、初始状态和最大时长。每个唯一model×task组合20次：

- θ_b在4任务上：3×4=12组合。
- θ_s在自身和其余3目标上：3×4×4=48组合。
- θ_{b→t}(300)在t上：3×4=12组合。
- θ_{s→t}(300)在s和t上：3×12×2=72组合。

总计144组合×20=2880次。共享基线不重复评估。所有源分支使用同一目标的配对初始状态/rollout RNG，保存逐次成功记录。

这只覆盖单个K终点，不是完整终身矩阵。20次的单对分辨率较粗，不把差1次自动判成正/负迁移，也不把无显著差异称为等效。

同时记录源和目标起点成功率用于解释地板/天花板；它们不作为主免费关系信号喂入预测器。

## 10. 评价指标与不确定性

主指标：每个目标分别计算OOF MSE、MAE，越小越好；并报告相对于M0、M_A和M_IFA的配对误差差。

辅助：OOF Spearman、校准斜率、逐held-out目标的误差、逐seed误差。比较源选择时，对固定目标在三个候选源之间按预测TRANSFER排序，报告实际成功率差；这仍是开发性诊断。

不能把MSE改善直接归因于“共享机制”或把Spearman高当成控制有效。

置信区间基于原始配对成功数组重算标签：对每个seed×被评价任务生成一次初态重采样索引，并应用到该任务的所有模型、起点和终点成功数组。这样同一target参考与同一source起点都在所有相关任务对中共享相同重采样结果。源/目标同一评估初态在前后分支配对，不拆开采样。

主不确定性报告限定于固定四任务和已测信号集合：整块重采样seed，内层配对评估初态，重新生成标签，并在每次重复中重新完成相同的留任务训练/标准化/预测流程。辅助留seed评估单列，不混入主bootstrap。重采样5000次；退化或目标方差为零时按前述均值预测规则处理并登记，不静默跳过有利化。

四任务和三seed无法支撑普遍任务总体CI。逐目标留出结果与任务删除敏感性直接呈现，不把36行称为36种独立任务关系。也不把2880rollout称为2880个关系样本。

预登记的两项主增量比较（TRANSFER目标）：M_A vs M_IFA，以及M_LA vs M_A。报告同时97.5%区间；M_GA vs M_LA与M_probe是次级诊断。DAMAGE目标各模型对比单列，避免两个目标混成一个好看的总指标。

开发集候选支持：主OOF误差降低、至少3/4留任务折同向、留seed不由单个seed驱动，并报告完整区间。若区间跨0则保持INCONCLUSIVE，不按胜率或某个task子集强行翻案。

## 11. 阶段与预算

### Stage0：只做定向资产检查

核验公共基座任务暴露、四任务数据、模型接口、可复用状态、原生训练配置和闭环接口。只保留身份/数据隔离/执行正确性必要检查，不开展全仓无限审计。

### Stage1：固定技术pilot

seed45上的6→7和7→6；对应两个source单任务构造及它们的300步prefix参考。

- 源更新2000步；两个目标续训600步；总2600步。
- 关系信号36点最终集合中的前2点；不算额外对照。
- 对应12个unique model×task组合×20=240次rollout。

只因技术/数据错位修代码。协议在pilot结果前冻结；不根据pilot迁移效果挑任务、rank、训练预算或回归模型。pilot测量合法则保留到主表。

### Stage2：补齐主矩阵

- 12个source先验×1000=12000更新。
- 36个source→target×300=10800更新。
- reference300从source训练prefix复用。
- 总计22800更新，另36次可回滚的影子一步；pilot包括在内。
- 总计2880次闭环，pilot包括在内。

如果缓存完全匹配，可少跑；不能为减少成本把不匹配缓存冒充相同条件。用pilot实测训练/rollout/建基吞吐估计耗时，不预先承诺小时数。

### Stage3：统一预测比较与结项

特征表封存后再开放结果给统计脚本；按固定模型和fold运行，不扫描新增关系信号。本轮结果不能触发自动正式训练。

## 12. 必要测试与工程约束

必要测试：
