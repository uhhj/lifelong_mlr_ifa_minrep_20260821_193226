# DEBR精修A版外观还原SVG

用户指出先前SVG与已选精修PNG外观不同。本次以原精修PNG为唯一视觉基准，按参考坐标重新绘制原生SVG，未修改原PNG或覆盖旧SVG。

交付：DEBR_A_refined_faithful.svg；预览：DEBR_A_refined_faithful_preview.png。

主要还原：1755×896画布、CADL与SHBR框位置及比例、门控框高出左框的布局、右侧Learned stage policy到Deployment横排、标题居中关系、蓝青橙渐变、底部紧凑两行记忆链、提交节点直接连接阶段策略。底部RA-Coreset保持蓝色，与CADL一致。

76个text元素均保留可编辑文字，框线、箭头、渐变均为SVG原生元素；未嵌入位图。Times New Roman为指定字体，需要查看设备安装该字体。数学符号和上下标由text/tspan排版。

这是尽量贴近参考图的可编辑矢量还原，不是逐像素等同的转换：原PNG为生成式栅格图，字形抗锯齿和细微光影不能据此宣称完全一致。上一版SVG为重新设计，本次恢复参考构图，不再改成竖排部署或扁平配色。

已分别目视核对原PNG、新SVG渲染结果；复核三项条件≤、≤、严格<，无明显文字裁切或模块重叠。原实验和Word不修改，无训练或评估调用。本目录仅发布本次图稿、代码及轻量审查信息，不涉及进行中的实验进度。
