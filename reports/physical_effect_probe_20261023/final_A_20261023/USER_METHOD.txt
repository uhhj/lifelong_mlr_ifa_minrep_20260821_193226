**建议把这次实验拆成两个连续关卡：先证明“完整最新帧读出确实恢复了物体状态”，再证明“预测的物理效果作为输入，能够在同等观测条件下改善GMM的真实闭环决策”；暂不加入跨任务迁移、TAC-ST或EFTR。**

否则，即使最终成功率变化，也无法判断收益来自最新帧、额外网络容量、物理监督，还是效果输入本身。

以下方案基于本次核查的 `MLR@2e6256d`。它是**待实现的验证方案，不是已经运行的实验**。

# 一、这次究竟验证什么？

必须把三个命题分开，不能用一个离线损失代替全部结论。

| 命题 | 所需证据 | 不能拿什么代替 |
|---|---|---|
| **最新帧确实可见** | 改变最新视觉／状态token，读出随之变化；计算图存在对应路径 | 输入张量长度是8 |
| **物体状态可恢复** | 在未参加训练的完整演示上，准确预测物体相对位置 | 夹爪开度预测准确、训练误差低 |
| **效果目标改善动作决策** | 相同观测与容量对照下，闭环成功率提高，且效果输入确实影响实际执行分布 | GMM输出变化、动作NLL下降、效果预测准确 |

现有报告已经表明：TAC与ALIGN使用相同的八步输入、下一动作目标和BC掩码，但TAC额外监督产生负增量；因此，本次应隔离验证“信息是否可用”和“策略是否受益”，而不是再次整体叠加。

**整体流程：**

\[
\text{输入与时间审计}
\rightarrow
\text{整演示留出的状态读出实验}
\rightarrow
\text{效果目标预测}
\rightarrow
\text{GMM输入干预}
\rightarrow
\text{Task6→Task7闭环对照}
\]

# 二、冻结实验范围

## 2.1 首轮只使用OBJECT的Task6、Task7

采用当前项目的 **seed41数据与训练配置**，任务为：

- Task6：黄油放入篮子。
- Task7：牛奶放入篮子。

选择这两个任务，是因为此前Task7在没有跨任务对比的情况下，TAC已经比ALIGN低20个百分点，适合检验物理辅助信息与控制之间的关系。**不是因为这两个任务能够代表全部持续学习场景。**

首轮分为两个性质不同的实验：

| 实验 | 数据使用方式 | 能形成什么结论 |
|---|---|---|
| A：物理读出探针 | 对每个任务独立做整演示交叉验证 | 当前特征能否恢复状态 |
| B：控制价值验证 | 按Task6→Task7持续训练，只使用当前数据与RA记忆 | 效果输入能否改善短序列闭环 |

**A实验的探针权重不得直接带入B实验。**B重新按任务到达顺序训练物理分支，避免把离线诊断中看到的未来任务信息带进持续学习。

本轮不读取Task8、9来训练模块，不启动四任务400 epoch完整方法实验。

## 2.2 不直接复用旧ALIGN作为唯一对照

旧ALIGN保留为历史参考，但本次增加了完整最新帧访问，并需要检查部署视图，因此必须建立**具有相同新信息访问条件的匹配对照**。

否则，效果条件模型优于旧ALIGN，可能只是因为它终于看到了最新视觉信息，而不是因为“物理效果目标”有价值。

# 三、数据准备：同时锁定时间关系和观测视图

## 3.1 时间定义

继续使用已审计的记录关系：

\[
o_u \leftrightarrow s_{u+1}
\]

对于八步输入：

\[
X_u=[o_{u-7},\ldots,o_u]
\]

当前状态标签来自 \(s_{u+1}\)，动作目标是 \(a_{u+1}\)，后续效果来自：

\[
s_{u+1}\xrightarrow{a_{u+1}}s_{u+2}
\]

当前 `science.py` 已包含动作序列绑定、唯一身份检查、填充窗口检查，以及关节／夹爪状态的时间核验，可在此基础上扩展。

每条样本保存明确的来源关系：

```text
task_id
demo_id
window_start
last_observation_index = u
current_state_index = u + 1
target_action_index = u + 1
next_state_index = u + 2
source_feature_sha256
source_hdf5_sha256
state_valid
action_valid
effect_valid
```

三个有效掩码分开处理：有当前状态而没有下一效果的样本，仍可参与状态预测；没有合法下一动作的样本不能伪造BC标签。

## 3.2 本轮的物理状态目标

**首版主目标先限定为物体平移关系，不把质量、摩擦或接触状态混进来。**

\[
q_u^*=
\left[
p_{\mathrm{obj}}-p_{\mathrm{eef}},
\quad
p_{\mathrm{obj}}-p_{\mathrm{goal}},
\quad
g
\right]\in\mathbb R^7
\]

其中 \(g\) 是夹爪实际开度。位置统一到固定、已核验的坐标系。

真正决定“物体状态可恢复”的是前两组三维位置。**不能因为夹爪开度容易预测，就让整体平均误差掩盖物体定位失败。**

物体姿态可作为附加探针，单独报告旋转误差与物体对称性问题；首轮不将它作为动作条件输入。这样本轮结论只能是“恢复了物体位置关系”，不能扩大成“恢复了完整物理状态”。

真实标签从记录的物体、篮子位姿和末端位置提取，不通过历史仿真重新执行动作来生成。现有代码已经具备对应读取逻辑。

## 3.3 必须检查缓存域与部署域

原特征导出代码明确使用训练模式及原增强流程；正式执行走的是评估预处理与空间编码路径。因此，**不能只在原缓存上训练、测试探针，就宣称部署也具备相同读出能力。**

A实验保留两套同身份输入：

| 输入视图 | 构建方式 | 用途 |
|---|---|---|
| 原训练缓存 | 原 `.pt`，完全只读 | 判断已有记忆包含什么信息 |
| 部署视图特征 | 对相同演示图像使用正式推理的预处理、冻结前端、`eval()`导出 | 判断实际执行时的信息可用性 |

需要比较：

1. 原缓存训练→原缓存测试；
2. 原缓存训练→部署视图测试；
3. 部署视图训练→部署视图测试。

**第三项作为物理分支的主要可行性结果，第二项用于定位域差异。**

B实验统一使用部署视图的新特征，三个对照完全一致。RA成员身份沿用原清单，但新增特征文件必须记录自己的SHA，不能继续宣称字节载荷与旧缓存相同。

这意味着B实验是新的匹配实验，旧ALIGN分数只作为背景参考。

# 四、实验A：完整最新帧究竟能恢复多少物体信息？

## 4.1 先做零训练可见性测试

当前token顺序为：

\[
[L_t,V_t^{agent},V_t^{wrist},S_t]
\]

原 `temporal_encode()`取每帧第0个输出。源码中的GPT-2仍使用因果注意力，因此这个位置不能读取同帧排在它后面的视觉与状态token。 [Hugging Face](https://huggingface.co/docs/transformers/model_doc/gpt2)

使用官方预训练权重、确定性评估模式，对同一输入执行三种局部干预：

- 只替换最后一帧两路视觉token；
- 只替换最后一帧状态token；
- 只替换前一帧对应token。

比较原语言位置读出与最后状态位置读出：

\[
h_{\mathrm{old}}=H_{u,0},
\qquad
h_{\mathrm{full}}=H_{u,3}
\]

记录读出变化量及对输入的梯度。

**预期结构结果：**最新帧后续token不影响 \(h_{\mathrm{old}}\)，但能够影响 \(h_{\mathrm{full}}\)。若实测不符，先检查实际运行代码、token顺序和掩码，不能继续沿用旧结论。

这里仅验证信息通路，不作为物理准确性的证明。

## 4.2 五组探针对照

| 编号 | 输入 | 验证目的 |
|---|---|---|
| P0 | 语言＋机器人本体状态，不含视觉 | 排除任务均值、轨迹和机械臂信息捷径 |
| P1 | 原末帧语言位置读出 \(h_{\mathrm{old}}\) | 当前旧读出的基准 |
| P2 | 同一GPT-2的末帧状态位置读出 \(h_{\mathrm{full}}\) | 只改变读出位置，是否已足够？ |
| P3 | 完整八步原始多模态token＋独立轻量读出 | 检验缓存的可解码信息上限 |
| P4 | 与P3同结构，但最新非语言token替换为前一帧对应token | 区分“网络更大”与“最新观测有效” |

P1、P2的预训练Transformer都冻结，使用完全相同的探针结构和训练预算。

P3、P4使用相同的小型编码器：

```text
每个512维token → LayerNorm → Linear(512,128)
每帧4个模态 → 同帧全注意力融合
8帧序列 → 2层因果Temporal Encoder
最后有效时刻 → 状态预测头
```

建议4个注意力头、隐藏维128、前馈维512。它直接读取全部模态，不经过旧语言读出。

P4仍然输入八帧，只在诊断对照中移除最新非语言观测信息；**它不是正式策略的七步版本。**

## 4.3 数据划分：必须按整条演示

每个任务的10条演示做五折外层划分：

- 每折2条完整演示作为测试；
- 剩余8条中固定1条作验证；
- 7条用于训练。

按数值排序后的demo ID确定划分，写入固定manifest。来自同一演示的所有滑动窗口，包括重叠窗口，只能进入同一集合。

空间编码器及P1/P2所用Temporal权重使用原六任务预训练版本，**不能使用已经在这些测试演示上训练过的ALIGN下游模型**。

训练配置建议统一为：

| 项目 | 设置 |
|---|---|
| 探针epoch | 50 |
| Batch | 128 |
| 优化器 | AdamW |
| 学习率 | 3e-4 |
| Weight decay | 0.01 |
| 监督 | 分物理量归一化的SmoothL1 |
| 模型选择 | 只根据验证演示的位置误差 |
| 测试 | 选定模型后一次性计算 |

这是诊断设置，不是修改正式策略的10条演示训练协议。

## 4.4 评价指标

必须分物理量、任务和运动状态报告：

| 指标 | 含义 |
|---|---|
| 物体—末端位置误差：中位数、P90 | 能否服务接近与抓取 |
| 物体—目标位置误差：中位数、P90 | 能否服务搬运与放置 |
| 夹爪开度误差 | 本体信息读出，仅作辅助指标 |
| 运动样本与静止样本分别统计 | 避免大量静止帧掩盖动态误差 |
| 最新视觉替换后的误差变化 | 验证是否依赖视觉条件 |
| 同任务不同演示的视觉置换 | 检查物体信息是否被真实利用 |

误差用毫米报告，不能只给归一化loss。

置信区间按**演示为单位**重采样，不能把高度重叠的几千个窗口当成几千个独立样本。

## 4.5 A关如何判断？

建议预注册以下判断：

**结构成立：**P2/P3对最新视觉和状态有真实响应，P1符合旧因果读出的预期。

**信息成立：**在部署视图的完整留出演示上，P2或P3的两类物体位置误差显著优于P0，且动态样本上的表现不是由历史位置滞后解释。

**控制精度可用：**首轮可将中位误差10 mm、P90误差25 mm设为工程筛选刻度，但必须在看到结果前结合物体和夹爪几何确认。它们不是论文公认阈值，也不代表通过后必然能改善控制。

若P2已经达到要求，优先使用P2的轻量读出；若只有P3达到要求，使用独立编码器，并在后续全部对照中提供同样的读出能力。

若所有完整读出都失败，结论应是：

> 当前冻结全局token尚未显示足够的物体位置可恢复性。

此时应改视觉特征来源或保留空间信息，而不是直接进入效果条件GMM训练。

# 五、实验B之前：先训练可部署的状态与效果预测器

## 5.1 必须区分“效果目标预测”和“动力学预测”

本轮验证的是：

\[
X_u
\rightarrow
\text{专家行为对应的下一步效果目标}
\rightarrow
\text{GMM动作}
\]

因此，效果目标预测器不能接收专家下一动作：

\[
\hat q_u=Q_\phi(X_u)
\]

\[
\hat e_{u+1}=P_\psi(X_u,\hat q_u,\ell)
\]

**专家动作 \(a_{u+1}^*\) 只用于GMM的BC监督，不进入 \(Q\) 或 \(P\) 的输入。**

否则，效果预测器训练时拥有部署阶段不存在的信息，这一验证会失去意义。

## 5.2 首版效果标签

为避免“物体没动就全是零效果”，使用：

\[
e_{u+1}^*=
\left[
\Delta p_{\mathrm{obj}},
\quad
\Delta(p_{\mathrm{eef}}-p_{\mathrm{obj}}),
\quad
\Delta g
\right]\in\mathbb R^7
\]

这样，接近物体、物体搬运和夹爪变化都有直接监督。

这七维标签与旧代码中的“平移＋旋转＋目标进展”不同，必须建立新的标签版本，不能只因维度相同就复用原字段和归一化。

本轮只验证短时平移与夹爪效果条件，不宣称解决旋转敏感操作或完整动力学。

## 5.3 先拟合、再冻结，避免再次混入共享梯度干扰

在每个任务开始时：

1. 用当前任务数据＋合法旧RA记忆训练 \(Q\)；
2. 冻结 \(Q\)，用其预测状态训练 \(P\)；
3. 冻结 \(Q,P\)，再训练本阶段策略。

首版各50 epoch，使用固定物理尺度归一化、AdamW、3e-4学习率。正式策略阶段不通过BC修改它们。

**动作训练始终使用预测的 \(\hat q,\hat e\)，不使用真实状态或真实未来效果作为动作输入。**

这样，本轮测量的是：

> 已获得的物理预测信息，作为输入是否有助于动作学习？

而不是同时测量“效果监督是否改变共享控制表示”。

三个闭环对照的 \(Q,P\) 数据来源、训练配置和阶段检查点完全一致，可以共享同一套独立训练的物理预测器。它们只读取合法训练数据，不来自某个对照策略的闭环结果。

Task7的物理分支只能访问Task7当前演示和Task6已保留RA成员，不能重新读取Task6全部原始示范。

## 5.4 效果预测本身的最低检查

比较 \(P\) 与以下简单预测：

- 全零效果；
- 当前任务训练集的平均效果；
- 仅机器人状态预测；
- 完整观察预测。

按运动段、接近段和夹爪变化段分别报告，防止大量静止效果主导平均值。

这是效果目标的预测能力检查，**不能代替闭环验证**。模仿学习中的策略动作会改变后续观察分布，因此离线表现和自身闭环状态上的表现不应直接等同。[Proceedings of Machine Learning Research](https://proceedings.mlr.press/v15/ross11a)

# 六、实验B：三个GMM控制对照

三个组拥有相同完整最新帧访问、相同预测状态、相同原GMM和相近条件网络容量。

令：

\[
h_u=T_\theta(X_u)_{\mathrm{full}}
\]

这里所有组统一使用能够读取当前完整帧的读出，不让效果组独享最新视觉信息。

动作输入为：

\[
\pi_\omega(a\mid h_u,c_u,\hat q_u,z_u)
\]

其中 \(c_u\) 是共同物理读出的上下文表示。各组唯一主要差别是 \(z_u\)。

| 组别 | \(z_u\) | 目的 |
|---|---|---|
| **B0：STATE-BC** | 固定零向量 | 有最新观察和预测状态，但没有效果条件 |
| **B1：LATENT-BC** | 同规模网络学习的7维匿名编码，由BC训练 | 排除增加非线性变换与容量的收益 |
| **B2：EFFECT-BC** | 冻结预测器给出的7维物理效果目标 \(\hat e_u\) | 检验明确物理效果是否有额外价值 |

B1编码网络采用与效果预测器相近的结构，但不接受效果标签，不能把它命名为物理效果。

总参数、可训练参数和训练计算分别报告；不必为追求形式上的完全相等而加入无意义计算。

### GMM接入方式

保留原5模式、7维GMM，只增加条件适配器：

\[
h'_u=h_u+A_\eta([c_u,\hat q_u,z_u])
\]

\[
\pi_\omega(a\mid\cdot)=\operatorname{GMMHead}(h'_u)
\]

适配器最后一层零初始化，其他层正常初始化。这样三个组初始GMM输出一致，但后续可以学会使用条件输入。

首版策略损失仅为：

\[
\mathcal L_{\mathrm{policy}}
=
-\log\pi_\omega(a_{u+1}^*\mid\cdot)
+0.1\mathcal L_{\mathrm{IFA}}
\]

**不加入效果误差对GMM的反传，不加入跨任务蒸馏，也不加入功能保护。**

当前GMM训练使用完整混合分布似然，部署选择最大logit分量再从对应高斯采样。因此，后续干预必须检查实际选中分量，而不能只比较混合均值。

---

# 七、效果目标是否“真的改变”GMM：干预实验

这一步在训练完成后进行，不修改参数。

## 7.1 同一观察下替换效果输入

固定同一个 \(X_u\)、\(\hat q_u\) 和策略检查点，比较：

| 输入 | 用途 |
|---|---|
| 正常预测效果 | 正常模型 |
| 零效果 | 检查去掉效果信息的影响 |
| 同任务、相近预测状态下的其他训练样本效果 | 检查模型是否区分具体效果目标 |
| 小幅、训练支持范围内的单分量变化 | 检查局部响应，而非极端分布外扰动 |

替换用的效果库只能来自训练数据的预测，不从正式测试轨迹的未来真值中取标签。

记录：

\[
\Delta\mu^{\mathrm{exec}},\quad
\Delta\sigma^{\mathrm{exec}},\quad
\Pr(k_{\mathrm{normal}}\neq k_{\mathrm{modified}})
\]

另记录夹爪指令变化、专家动作NLL变化及效果输入的局部敏感度。

不使用极小高斯方差作为唯一归一化尺度，避免重复EFTR中KL被少数样本支配的问题。

## 7.2 哪些结论可以成立？

- 输出几乎不变：效果输入可能被忽略。
- 输出明显变化：只能证明网络使用了效果输入。
- 正常效果比合理替换效果有更好的专家动作拟合：提供方向性证据。
- 正常效果在真实闭环优于匹配对照：才能证明控制价值。

**“动作变化”不是“动作改善”。**

离线可以额外用真实效果替换预测效果，诊断预测误差是否可能是瓶颈；但它使用了未来真值，不能作为可部署结果，也不是严格数学意义上的性能上界。

# 八、小型正式闭环：Task6→Task7，而不是直接跑完整四任务

## 8.1 训练流程

三个组均从相同官方六任务预训练权重开始，使用统一的新读出和部署视图特征。

| 阶段 | 操作 |
|---|---|
| Task6开始 | 仅用Task6合法数据拟合本阶段 \(Q,P\) |
| Task6训练 | 三组各训练100 epoch |
| Task6结束 | 保存epoch99；按原RA成员入库并保存标签 |
| Task7开始 | 用Task7当前数据＋Task6 RA记忆更新 \(Q,P\) |
| Task7训练 | 三组各训练100 epoch |
| Task7结束 | 保存epoch99；完成两任务闭环评估 |

若保留当前样本人口、batch10及原掩码规则，则两个阶段分别为15,700和22,700次主更新，即每组38,400次。实际数量仍以重新核验的dataset manifest为准，不为凑次数伪造有效标签。原完整协议的训练、掩码和评估规则见已冻结文件。

三个策略组共600个主训练epoch、115,200次主更新。物理预测器拟合、特征重新导出与诊断计算单独计账。

## 8.2 主要闭环评估

每组评估三个单元：

| 检查点 | 测试任务 | Episode |
|---|---|---:|
| 完成Task6 | Task6 | 20 |
| 完成Task7 | Task6 | 20 |
| 完成Task7 | Task7 | 20 |
| **每组合计** | 3个单元 | **60** |

三个组主要评估共 **180条episode**。

沿用原环境初态0–19、10路向量环境、600步上限、5步零动作、阶段随机数规则以及原GMM采样方式。原评估历史从1步增长到最多8步，新增读出也必须支持该启动过程，不能读取未来帧补足窗口。

本轮报告三个单元的完整成功率和两任务最终平均成功率，**不把它称为原四任务AUC，也不直接与81.46%的四任务ALIGN AUC比较。**

## 8.3 效果干预的闭环诊断

对训练完成的B2，再运行：

- 效果输入置零；
- 使用固定训练效果库中的条件匹配替换值。

每种干预同样60条，新增120条。连同主要对照，本轮闭环预算为 **300条episode**。

这些是机制干预结果，不是新增训练方法。它们不能用于重新挑选超参数或选择有利检查点。

如果正常B2优于自己的置零版本，但不优于独立训练的B0/B1，结论仍然只是：

> 该模型依赖效果输入，但尚未证明效果条件建模优于其他策略设计。

# 九、额外记录：离线物理读出能否经受闭环分布？

在正式评估期间，可以**只读记录**仿真真实物体状态，用于事后计算：

- 当前预测状态 \(\hat q_t\) 的误差；
- 预测效果目标与实际执行后变化的差异；
- 失败前物体定位、效果目标和动作输出的变化。

这些真实状态不能进入模型前向、门控、候选动作筛选或在线更新。

这可以区分三种情况：

| 现象 | 更可能的瓶颈 |
|---|---|
| 离线准确，闭环状态预测失效 | 观测分布变化、视觉遮挡或缓存／部署差异 |
| 状态准确，效果目标不合理 | 效果决策器没有学到可靠的操作意图 |
| 状态和效果目标合理，动作仍失败 | GMM对效果的实现能力不足，或目标本身不可由当前动作稳定实现 |

第三类判断需要结合录像和真实转移，不能只凭效果距离一个数值下结论。

# 十、明确的验收与决策规则

## 10.1 不设置一个混合“总分”

| 结果 | 结论 | 下一步 |
|---|---|---|
| 最新帧信息通路不成立 | 读出实现错误 | 修复代码，不训练策略 |
| 信息通路成立，物体位置预测不可靠 | 当前特征或监督不足 | 修改观测表征，不叠加迁移 |
| 状态可靠，但效果目标预测仅接近零／均值基线 | 效果任务缺少有效信息 | 重审标签和预测范围 |
| 效果输入不影响GMM | 条件输入被忽略 | 重设计接入方式 |
| 影响GMM，但闭环不优于B0/B1 | 有依赖，没有控制收益 | 暂不进入完整CAET |
| B2优于B0、B1且旧Task6没有明显恶化 | 有正向机制证据 | 冻结版本，扩展seed42、43 |
| 多seed结果稳定后 | 前提获得更强支持 | 再加入条件迁移与历史保护 |

20条episode的单元分辨率为5个百分点，因此一个或两个成功案例的差异不能被包装成稳定结论。

报告配对初态上的成功／失败差异和置信区间；单seed结果只作探索证据。后续多seed复验必须保留负结果，不能只扩展表现最好的组后宣称全面优越。

## 10.2 进入完整算法研究的条件

至少同时满足：

\[
\boxed{\text{最新帧信息真实进入模型}}
\]

\[
\boxed{\text{物体位置在独立演示和闭环状态上可恢复}}
\]

\[
\boxed{\text{B2优于无效果及容量匹配对照}}
\]

\[
\boxed{\text{没有用未来效果真值参与部署}}
\]

只有这样，才有依据继续研究“效果知识如何跨任务迁移”和“怎样保护历史功能”。

```bash
# 1. 输入和时间关系
python -m physical_effect_probe.binding_audit --suite OBJECT --seed 41
python -m physical_effect_probe.export_native_view --tasks 6 7 --seed 41
python -m physical_effect_probe.visibility_test --seed 41

  --arm EFFECT_BC --modes zero matched_donor --seed 41

python -m physical_effect_probe.audit --seed 41
```
