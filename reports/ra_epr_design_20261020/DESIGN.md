# RA-Coreset + EPR：专家校验的执行分布回放（设计候选）

状态：DESIGN_ONLY。2026-10-20。没有创建训练入口、连接服务器、加载模型、调用优化器或追加环境执行。下述诊断和实验均为待授权建议。

## 1. 判断

推荐优先研究训练期间的功能保留，而不是继续加入推理残差或再次改RA成员。暂称EPR（Expert-validated Policy Replay）。

RA解决“在有限记忆中保存哪些输入”；EPR尝试解决“后续训练如何保留这些输入上已有且获得专家证据支持的执行分布”。有效性未确认；若历史RA阶段模型没有足够可保护退化，直接停止，不为新模块强行构造作用。

本轮证据来自现有本地实验报告与公开一手论文。当前工作区没有确认的ResearchVault，未把模型记忆当作Vault证据；未修改文献库。

## 3. 唯一新增作用：回放时保留可信的执行行为

### 3.1 保存对象

每个任务k训练完成后，照常运行RA选样，成员、顺序、配额和载荷全部沿用已冻结实现。只对这些入库窗口建立额外元数据：

- sample_id、demo_id、真实start/target step、父阶段模型与模态合同哈希；
- 教师在该原latent上的实际执行Gaussian：7维均值和7维标准差；
- 教师赢家相对第二分量的logit margin；
- 专家一致性与缓存/原生视图检查结果。

教师是该任务刚学完的固定阶段模型，目标保存后不随学生更新，避免把遗忘覆盖为“新正确参考”。只保存输出元数据，无须在每个训练step运行教师，也无需长期保留一个额外GPU教师模型。

本实现执行规则已经核对：argmax(logits)选择分量，再从其Normal采样。完整GMM NLL用于BC；“整混合分布拟合好”与“真正执行分量好”不是相同命题。

### 3.2 专家与原生输入校验

这里的可信是“在已有示范上有一致性证据”，不称“成功锚点”：

1. 用真实末端专家动作比较教师赢家的前六维标准化误差，另检查夹爪符号一致性。使用已冻结动作尺度，不以σ大或自信高代替正确。
2. 为同一真实8步历史，从原始图像/状态按原生eval路径编码；核对绑定、padding、语言、state及前端权重相同。这里只对当前任务选中的窗口进行一次检查，后续不访问未入库旧任务数据。
3. 若缓存与原生视图的专家误差/夹爪结论严重不一致，或赢家Gaussian差异过大，不启用该窗口的辅助保护；原BC和IFA仍正常使用该窗口。
4. 不使用历史正式闭环成败名单选窗口，不为凑激活率放松门槛。

运动误差容差、跨视图容差和loss强度必须在未来诊断/验证前明确冻结。本设计不假装已经找到可靠数值；本轮没有参数搜索。容差由动作尺度和训练证据定义，不能由正式成功率倒推。

参考Gaussian来自与学生回放完全相同的原latent；原生视图用于可信性核验，不无声把另一输入的教师输出当成同输入目标。原生检查反映有限示范内一致性，不解决全部off-policy状态分布偏移。

### 3.3 同时保护分布参数与执行分量选择

对通过校验的旧样本i，固定参考Normal为q̄_i=N(μ̄_i,diag(σ̄_i²))。
学生一次原有前向已经给出5个分量的μ_ij、σ_ij、logit ℓ_ij。

使用对角Gaussian的平方Wasserstein距离：

    d_ij = (||μ_ij-μ̄_i||² + ||σ_ij-σ̄_i||²) / 7
    j*_i = argmin_j d_ij

取j*时停止索引梯度；相同值用固定分量索引消歧。这样不要求第m个分量永久拥有同一语义。均值与标准差均为原动作坐标，不额外改变动作缩放。

辅助损失：

    L_EPR,i = d_i,j* +
              [ max_{j≠j*} ℓ_ij - ℓ_i,j* + δ_i ]_+

其中δ_i为入库时教师赢家margin的预先封顶值；封顶规则须冻结。第一项保留参考分布，第二项使与参考最接近的分量具备被原argmax规则执行的条件。

只对argmax后的Normal做距离约束，通常不会把选择梯度传到logits；因此路由项不是可忽略细节。该损失是分段可微的训练正则，不保证每一步margin达到要求，也不保证轨迹成功。训练仍由原GMM BC监督全部样本。

    L = L_BC + 0.1 L_IFA + λ * mean_over_all_old_slots(c_i * L_EPR,i)

c_i为固定可信性标志。分母为该batch全部旧槽位数，不因只有一个合格窗口就把它放大成一整个辅助batch；没有旧槽位时为0。筛选只决定辅助项，不改变样本出现次数、BC权重、原IFA公式或任务配对规则。

潜在风险必须保留：
- 参考模型仍可能错误；贴近某个专家动作也不代表其余可行动作错误。
- 过强保留会妨碍学生纠正教师，或牺牲新任务学习。
- 最相近分量可能切换，需在真实batch检查梯度连续性、路由抖动和均值/尺度塌缩。
- 原生输入校验与跨demo验证降低自证风险，不能保证跨状态泛化。

## 4. 为什么互补及成本

不增加推理参数、残差分支、路由器或每步前向；部署动作规则与RNG协议完全沿用原方法。
训练复用学生现有GMM参数，只增加每旧样本5×7量级距离与margin计算。旧buffer成员与顺序固定，避免再次引入Event/SC的成员和排序混合效应。

14个Gaussian参数+1个margin若用float32，核心数值60B/窗口；OBJECT2961条约177,660B，GOAL2381条约142,860B。未计ID、校验状态、JSON和索引开销。这是额外监督元数据，必须计入总记忆而不能称零存储。

入库时需要额外教师/原生图像前向；它可能成为主要固定开销，须单独计时。训练每步开销目标≤10%，加上一次性元数据生成的总训练开销目标≤15%；这是待测准入预算，不是已测性能。不通过预算时优先停止，不用成本估计冒充实测。

## 5. 文献与新颖性边界

- DER（NeurIPS2020）已提出旧输出一致性回放：https://papers.nips.cc/paper/2020/hash/b704ea2c39778f07c617f6b7ce480e9e-Abstract.html
- CLEAR（NeurIPS2019）已结合经验回放与对过去策略的行为克隆：https://arxiv.org/abs/1811.11682
- SPREAD（ICRA2026，arXiv2026-03-09）在LIBERO上提出子空间表征蒸馏与置信度引导GMM策略蒸馏；3C按旧策略采样密度选top-M action samples：https://arxiv.org/html/2603.08763v1#S3.SS3
- R-Drop（NeurIPS2021）为随机子网络输出一致性提供背景，并不能直接证明本机器人方案有效：https://proceedings.neurips.cc/paper/2021/hash/5a66b9200f29ac3fa0ae244cc2a51b39-Abstract.html

因此不能把“RA+蒸馏”宣称首次提出。候选贡献限定为：
1. 以真实专家监督及缓存/原生视图双重校验替代单纯教师自信；
2. 针对argmax分量→Normal的真实执行规则，同时保护分布与选择margin，并允许分量重新匹配；
3. 冻结输出sidecar与原latent replay结合，验证低额外开销。

这是候选研究贡献，不是完成的系统性新颖性证明。若普通功能回放同样有效，EPR应降格为工程组合，不能以新名字掩盖无增量新意。

## 6. 最小、分级验证（均未启动）

### A. 先证实存在可保护问题，零更新零环境

固定GOAL seed42与OBJECT seed41作为两个已充分分析的探索性入口，承认其事后选择；不根据诊断结果继续挑另一个seed。

从已有任务6/7/8学后及后续checkpoint追踪同一旧窗口。按demo与时间均衡固定抽样，避免只选已知失败时刻；并在不同demo的未参与参考拟合窗口上复核。检查：
- 教师贴近专家、学生后来偏离的比例及误差质量；
- 真实执行Gaussian的均值/尺度/赢家margin变化，勿用整体NLL替代；
- 缓存与原生同历史路径的结论一致性；
- 每demo、每旧任务/阶段分层，不将重叠窗口视为独立样本；
- 模块激活率、实际batch中辅助项及梯度可达性。

如果没有明确可保护退化，或可保护样本主要只存在于缓存/单一demo，停止本方向。不能用“父标签准确率高”替代“后续发生可保护退化”。

只读阶段允许模型前向及诊断梯度但optimizer调用0；未来执行时须明确实际资源上限。不能把看过全部演示的父模型称为跨demo从未见过。

### B. 小预算验证是否保旧且不压新

A通过后才申请隔离、可丢弃的更新验证。固定最多40个实际optimizer调用总预算，包含原更新、普通功能回放和EPR三种对照，不是每组40步。比如12个匹配探针×3种更新=36次，余4次仅用于必要恢复测试。

每个探针从同一完整model/optimizer/scheduler/grads/modes/RNG状态出发，用原实际batch；验证用不同demo及原生视图。缺真实中期状态就只做如实标注的阶段入口测试，不能伪造中期moment。

待执行前固定筛选规则，建议：
- 跨demo/原生路径的旧任务专家误差正增量，相对原更新减少至少10%；
- 新任务原本为正的净进展保留至少95%；原本无进展时单独判定，不能除零；
- 同时报告修复/新增损害、分量选择与尺度变化；EPR应相对普通功能回放有额外价值；
- 满足第4节实测开销预算。

这些是机制准入阈值，不是统计显著性或闭环效果证明。不能仅在保护点或构造batch上通过。

### C. 首轮正式只新增GOAL seed42一组

A/B通过并获授权后：RA+IFA+EPR，任务6–9各100epoch，400epoch/76,100step，batch10，原state/调度/BC+IFA/RA成员和顺序不变。200条原协议闭环，所有10个有效cell；原RA基线只读复用，不重评或重训。不是40epoch冻结父模型校准。

Task6没有旧记忆，辅助项为0，因此必须验证该阶段无额外优化、RNG或模式泄漏；不要用跨硬件逐元素相同作唯一准入条件。

预先冻结建议通过条件：完整工程验收；AUC严格超过对应RA；OldFinal及FWT不低于RA；全部任务含负结果公开。未通过不调λ/门槛或增加预算。

通过后再申请跨seed/套件扩展及针对性消融。要主张新颖机制，最终至少需要一次计算预算匹配的普通功能回放对照；低成本首轮胜过RA不能单独证明所有设计细节有效。
