# 设计推导与边界

## V2中的隐式折中

固定教师权重w和一个分量，忽略网络参数耦合，均值部分是：

`J(mu) = ((mu-y)^2 + w*(mu-muT)^2)/(1+w)`。

其独立最优均值为`(y+w*muT)/(1+w)`，而非专家动作y。学生已经到达y时，若w>0且
教师muT!=y，教师锚仍可能产生离开y的梯度。这是目标的结构事实，不是闭环差距的因果证明。
整个训练仍包含BC/IFA，因此不能把这个辅助项最优点称为网络真实收敛点。

## 归一化输出坐标

对分组g（3平移、3旋转、1夹爪），每维缩放`1/(sqrt(d_g)*s_g)`。
把缩放后的均值、标准差拼为14维向量z。专家端点e=(scaled action, 0)，
教师端点t=(scaled teacher executed mean, scaled teacher executed std)。

原C的专家cost恰好为`c=||z-e||^2`。

定义固定线段`S={t+alpha*(e-t): 0<=alpha<=1}`，新增锚为：

`R(z)=min_{v in S} ||z-v||^2`。

投影系数为`clip(dot(z-t,e-t)/||e-t||^2,0,1)`。端点相同时退化为单点距离，
无行为epsilon或手工危险阈值。投影系数在反向时detach；距离的正确输出梯度为
`2*(z-proj_S(z))`。

## 可推导的不变量

- 教师点、专家点及中间纠错路径的新增锚均为零。
- `0 <= R(z) <= c(z)`，因为专家端点在S中。
- w∈[0,1]且rho=1时，`c <= c+wR <= 2c`。
- 固定输出坐标下，`<grad R, grad c> >= 0`。证明：令p=proj_S(z)，由于e∈S，
  投影性质给出`<z-p,e-p> <= 0`，故`<z-p,z-e> >= ||z-p||^2`。
- 该性质仅属于独立输出坐标。经神经网络雅可比、共享参数、多任务混合、AdamW及
  参数裁剪后，不能推出参数梯度无冲突或旧任务风险不增加。

## 路由

路由恢复原C：以专家cost最小分量为目标，只在logit间隔不足时产生hinge惩罚。
不再以教师混合J排序，不再按每个分量的cost-gap连续放大softplus。
极端误选仍可能存在；训练损失不是部署硬筛选。精确cost并列保留C的first-index规则。

## 不能忽略的限制

线段在分布参数空间中，只是一种训练正则假设，不是控制器的安全动作集合。
例如开/合夹爪两个动作之间的均值，不一定具有有用的物理含义；本方案不会在推理时
强迫沿线段执行，但学习过程仍可能受这个几何假设限制。

专家动作并非唯一可行动作，非专家方向的有益迁移也可能受到惩罚。任务获取时教师
可能保留较早错误，滚动教师可能保留较晚漂移，两者需独立对照，不能依据测试成功率
逐窗口挑教师。仅回放分布上的约束不能覆盖闭环访问的全部状态。

V2中N弱于C支持先回退路由作为实验策略，但单seed数据未证明softplus一般有害。
本方案是按现有代码与实验重设计的候选，不声明首次提出、不承诺性能改善。
