使用原作者发布的 `goal_multitask_model_ep96.pth`。本地下载副本和 rlmi 上实际加载的文件均为 695,772,296 字节，SHA-256 为 `241d3370acfc04d694df04256956a97aa13cfdc2e651cf258d338f8e72988be7`。沿用官方 CLIP 视觉、文本编码器、已有的 LoRA 更新、视觉投影、FiLM 及 GPT-2 时序参数。为 PiPER 新建七维状态输入层和五分量混合高斯动作头。时序网络读取当前帧排在两路视觉之后的状态 token，使两幅当前图像都在因果注意力的可见范围内。[作者仓库与权重入口](https://github.com/yfqi/lifelong_mlr_ifa#pretrained-models)

双相机图像保持完整视野，缩放并填边到 224 × 224。三条固定英文任务指令使用原模型配套的 CLIP 分词表。冻结视觉和语言前端，将逐帧双视角特征缓存到 rlmi 的实验私有目录。策略输入含从臂六轴反馈（弧度）和夹爪反馈（毫米）。监督目标来自实际的关节和夹爪指令。内部拟合目标相对同帧反馈的差，并还原为绝对目标。状态和目标差的标准化统计量均来自训练划分。

每项先用两条不同训练示范各取一个八帧窗口，分别验证损失、梯度及动作头参数更新。正式训练使用单张 RTX 3090、AdamW、学习率 0.0001、批量 128，按各任务有效行数的倒数对损失加权。训练最多 30 轮，验证指标连续 6 轮没有改善时停止。选模指标是三个任务等权的标准化绝对误差。验证还记录每项的六轴平均绝对误差、夹爪平均绝对误差，并与直接保持当前反馈的预测作同口径比较。

复现时将已校验的 GOAL 权重和配套的 `clip_tokenizer_goal.json` 放入运行目录，在带 CUDA 的离线 PyTorch 环境中执行下面的命令。`DATA_ROOT` 指向包含 `expert_sets/` 和 `recordings/` 的数据目录。`RUN_DIR` 用于存放运行配置、划分、归一化参数、逐轮验证记录及检查点。

```sh
python -u scripts/piper_base/piper_base.py "$DATA_ROOT" "$RUN_DIR"
```
