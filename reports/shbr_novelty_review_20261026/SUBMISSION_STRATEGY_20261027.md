# RA + TASA + SHBR：论文定位、投稿选择与最小补实验

日期：2026-10-27（Asia/Shanghai）。这是基于现有已验收结果的研究建议，没有启动训练、重评或采集，没有改变任何科学协议和旧停止条件。投稿优先级是作者判断，不是录用概率或期刊官方质量排序；分区需核学校采用的年份与体系。

## 1. 建议主线

建议题目：**Demonstration Coverage and Execution Retention for Lifelong Robot Imitation Learning**（面向机器人终身模仿学习的示范覆盖与执行行为保持）。

核心问题：有限示范回放需要兼顾代表性和覆盖；正确示范监督仍未必保持机器人实际执行时的行为。因此，把示范记忆和成功执行历史记忆作为互补信息来源，并使输入历史、动作标签和部署行为语义一致。双记忆是组织问题的框架名称，不宣称其概念首次。

- RA：任务结束时批量无放回随机硬锚＋K-Center最小覆盖损害交换；不是在线reservoir算法。视觉/动作距离沿用既有实现，须区分继承部分与新增选择规则。
- TASA/ALIGN：本项目post-action导出观测的下一动作监督修复，含唯一身份和有效mask。应作为共同正确性协议与复现贡献，不能把所有数据统一加1作为通用算法，也不能故意让主要对照继续使用已知错位标签。
- SHBR：独立有界成功短历史，固定任务获得时的执行高斯，后续执行分量保持＋选择监督。它继承C的专家cost与margin主干；RA+TASA不等于C，不能隐藏该辅助项。

建议强调两项互补学习设计与一套可审计时序协议，而不是三项全新基础算法。总体图可画两路：示范→RA→正确时序监督；任务获得时有限执行→成功历史→固定行为目标；两路联合训练原时序GMM，部署结构保持原规则。

## 2. 现有数据的可用主张

GOAL与OBJECT分别是LIBERO的两个任务套件，不是两个独立机器人基准。各三个seed已验收。S对历史RA+ALIGN的AUC增益为1.6667/4.8611pp，OldFinal为7.2222/7.7778pp；相对原复现MLR+IFA的AUC增益为6.4236/16.7361pp。它们支持完整系统的有限实证价值。

同时GOAL对RA平均AUC仅+0.7986pp；OBJECT seed41新任务55%对历史ALIGN90%；GOAL seed41 S-C原预登记门不通过。S比纯离线基线增加训练交互和额外计算，历史动作噪声也不同。不能用平均提升改写原负结果，或将S−RA+ALIGN全部归因于成功筛选。

共同专家窗口上误差与regret改善仍可能伴随闭环退化，适合成为问题动机和失效边界，不是已经证明某次动作导致失败的因果证据。

## 3. 最优先补充的主比较

先解决公平性和最邻近基线，再扩大套件与模型；此处全部为建议。

| 组别 | 主要问题 |
|---|---|
| 正确时序MLR+IFA（原Random配置明确列出） | 相对正确实现的基础方法是否仍改善 |
| 正确时序纯K-Center | RA是否优于已有覆盖选样 |
| RA+TASA | 回放选择本身的增量 |
| C：RA+TASA+专家cost+margin | SHBR继承的辅助项贡献多少 |
| C+普通固定教师蒸馏／完整GMM KL适配 | 最接近的已有保持机制能否解释收益 |
| 完整S | 成功执行历史保持的新增价值 |

只适配M2Distill的policy KL应明确命名为loss适配，不称完整M2Distill复现。最紧迫的缺口是RA+TASA→C→S；当前没有GOAL C42/43和OBJECT同协议C三seed。

新增主比较按同一冻结协议固定初始化、数据流、训练步、任务顺序、正式初态及逐轨迹噪声。已有结果保留历史比较标签；不用重跑全部历史队列才开展每项分析。训练交互、总记忆字节（原RA＋新增历史）、前向/反向次数和耗时单列；给普通蒸馏或增加数据BC方法相同额外交互/缓存机会，形成资源匹配对照。只匹配窗口数不代表短历史字节与计算相同。

## 4. 有限机制分叉

另设一个事前固定的共同阶段起点、候选rollout池、教师输出与后续训练样本流，不替代完整序列主比较，也不使用正式测试失败来挑池。

1. 同候选池：未筛选历史与成功筛选；匹配可行的样本数、配额及复用次数，另保留原完整策略实际缓存量分析。
2. 同成功历史：普通固定高斯KL/W2或完整GMM KL，与当前执行高斯保持比较。
3. 同执行高斯保持：有／无最近分量margin，隔离保持路由。

完整GMM对照需要缓存或重算源教师的全部混合参数，成本必须计入；不能拿仅执行高斯摘要假装完整GMM。共同池分叉改变的是诊断协议，须另冻结，不能回写现有O/S为因果消融。

RA建议补随机、纯覆盖、当前RA的同记忆预算对比。若需证明RA和SHBR互补，可在正确TASA与固定C主干上做RA开关×保持开关的2×2；在此前主表已覆盖对应单元时复用，不机械启动全8组合。

若预算紧，先补C和一个最近邻普通蒸馏，再做去保持路由与共同池成功筛选。若普通蒸馏已解释收益，则收窄贡献或采用更简单方法，而不是继续更换名称或扫描权重。

## 5. 广度、确认和展示

- 冻结方案后，关键方法增加未参与选型的种子或任务顺序；已有41–43不能事后称独立确认集。建议先追加2个新种子用于完整方法、C和最近邻蒸馏，具体有限预算另冻结。
- LIBERO-SPATIAL可检验额外空间变化；优先级低于最邻近公平对照。三个LIBERO套件仍属于同一基准家族。
- 真机可选3–4技能顺序，对完整方案与2个关键对照重复学习序列并使用预固定测试配置；数量依据资源预登记，不只展示一个成功视频。没有真机时明确仿真范围，不宣称实际部署验证。
- 使用新固定评估初态，并在环境库存许可时增加每格回合数。增加episode减少评估噪声，不能代替独立训练seed；按seed/任务层级报告不确定性，不把全部episode视为独立训练重复。
- 报告AUC、OldFinal、FinalAll、末阶段新任务、全矩阵、负单元、同初态噪声SF/FS、存储和计算开销；AUC具体平均口径、项目FWT与标准迁移定义区别必须写清。
- 视频/双相机关键窗口用于说明成功与失败现象；没有动作干预就不把视觉叙事写为已证因果。

建议正文图表：双记忆总图；全序列闭环矩阵与曲线；主比较表；机制消融表；记忆/交互/耗时成本表；少量配对真实rollout窗口。重复工程调试历史放复现记录，不作为主叙事。

## 6. 投稿选择（2026-10-27核官方范围）

| 目标 | 当前建议 | 理由与条件 |
|---|---|---|
| Robotics and Autonomous Systems | 相对务实的首选候选 | 官方覆盖机器人控制、学习及理论/计算/实验系统模块，适合完整系统实证；仍需公平强对照和清楚增量 |
| Journal of Intelligent & Robotic Systems | 较保守的备选候选 | 官方覆盖机器学习、自治与机器人系统理论实践；学校认可分区及当前OA政策另核 |
| RA-L | 补齐关键对照后的进取目标 | 官方要求创新研究与应用结果，6页通常篇幅、最多8页；核心证据需正文紧凑闭合，不能把必要文字图表藏在额外附件 |
| ICRA | 有明确机制差异后的进取目标 | CCF官网人工智能会议列表列B，但不能把B当易投；ICRA2027已明确投稿关闭，不能按当前可投安排 |
| IROS | 机器人会议路线候选 | 学术范围匹配；学校目录归类需单独核，不能自动按用户的B会要求视为等价 |
| Autonomous Robots | 有真机或可信落地路径后再考虑 | 官方明确优先真实机器人性能，纯仿真需充分说明现实迁移路径；不是当前更容易的备选 |

没有基于稿件的可靠个体录用概率，因此不编造60%/80%等数字。上述相对路线是基于主题匹配、篇幅和当前证据缺口的判断，不是各刊录用率比较。中科院二区和JCR Q2不是同一体系，本轮没有给这些期刊未经核实的二区标签。

当前建议：先按RAS长度写完整系统稿，把正确时序基线、C和普通蒸馏对照补齐；关键隔离与新种子结果稳定且有真机时，再考虑RA-L/ICRA更集中的方法稿。正式提交只能选定一个渠道，不同时投稿。
