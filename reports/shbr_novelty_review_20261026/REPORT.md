# SHBR 方法级查新与创新边界核查

文献检索截止：2026-10-26；实验结果核对更新：2026-10-27（Asia/Shanghai）。对象是代码中 CCBP-v4 的 S 分支，汇报名 SHBR；ALIGN 汇报名 TASA。此轮只做文献、本地方法代码与已验收结果核查，不运行训练、环境或远程实验，不更新任何实验完成状态。本文不是专利法律意见，也不是证明全球不存在先例的查新证书。

## 1. 核心判断

**旧执行经验回放、任务末固定教师输出和策略蒸馏均有机器人持续学习直接先例；成功筛选在机器人学习中也已有先例。SHBR目前仍可讨论的是面向实际部署行为的具体组合与适配，不能单凭加入成功筛选就认定新的核心范式。** 尚未检到完全同构的“严格任务序列中终局成功筛选+固定执行高斯保持”组合，不能用邻近但不同设置的论文直接否定这一窄组合，也不能反过来宣布它首次。

本次没有找到一篇已核验论文与当前完整实现逐项相同，但这只表示本次检索未发现，不能推出首创。反过来，已有相同基础思想，也不等于当前代码就是照搬某一篇论文。应把三件事分开：基础机制是否已有、完整实现是否相同、剩余差异是否带来可重复价值。

最需要修正此前叙述的是：**GMM行为蒸馏在机器人终身模仿学习里已经存在。** M2Distill和SPREAD都直接在LIBERO上研究这一问题；M2Distill还被MLR+IFA原论文列为相关方法与实验对照。因此，“只是把强化学习里的方法迁到机器人模仿学习，领域里还没有”不成立。[M2Distill](https://arxiv.org/html/2410.00064#S4.SS2)、[SPREAD](https://arxiv.org/html/2603.08763v1#S3.SS3)、[MLR+IFA §2及表1](https://arxiv.org/html/2603.10929#S2)。

## 2. 先固定实际方法，避免对名字查新

本地核对对象为`execution/20261025_ccbp_v4_full/PROTOCOL.md`、`losses.py`、`legacy_losses.py`及相关实现说明。文件SHA在`LOCAL_METHOD_AUDIT.json`记录。

| 部分 | 当前实现 | 不应混淆的概念 |
|---|---|---|
| 学习主干 | 原RA示范成员与顺序、ALIGN有效标签、BC+IFA不变；额外保留C的专家cost与margin路由 | SHBR不是重新发明RA，也没有替换原样本库 |
| 数据取得 | 每任务完成固定训练后，有限次数自身执行；只访问当前任务环境 | 不是训练时无限补采直到成功，也不是使用正式测试轨迹 |
| 成功筛选 | 仅最终成功的整轨迹可以贡献候选历史窗口 | 轨迹成功不表示每个动作正确或必要 |
| 缓存输入 | 部署时真正出现的1–8帧冻结前端特征历史；额外有界缓存 | 不是只保存一张图片，也不是存所有轨迹 |
| 教师标签 | 当时最高logit高斯分量的均值、标准差，采样前保存；按任务获得时冻结 | 不是保存一次随机采样动作，也不是每阶段刷新全部旧标签 |
| 保持目标 | 当前最高logit分量对历史执行高斯的分组归一化W2平方距离 | 不是完整GMM KL，也不是强制相同分量编号 |
| 选择目标 | 找到离历史高斯最近的学生分量，用margin提高其logit | logits原模型已有；新增的是其监督约束，不是新选择网络 |
| 使用方式 | 后续训练额外抽取均衡旧任务锚槽；与原示范学习并行 | 不是回放旧环境或在部署时查询教师 |

D/O/S使用同一保持算子；S相对O的核心差别是整轨迹成功筛选。因此执行分量保持不是S专有于O的新设计，也不能把S-O差异解释成路由改进。

## 4. 公式层面还剩什么区别

记历史执行高斯为`T(h)=Normal(mu_T,sigma_T)`；学生GMM分量为`(mu_m,sigma_m,z_m)`。当前实现的分组距离是

\[
d_m=\sum_g\frac{\|\mu_m^{(g)}-\mu_T^{(g)}\|_2^2+\|\sigma_m^{(g)}-\sigma_T^{(g)}\|_2^2}{n_g s_g^2},\quad
k=\arg\max_m z_m,\quad j=\arg\min_m d_m,
\]

\[
L_{retain}(h)=d_k+\beta\left[\delta+\max_{m\ne j}z_m-z_j\right]_+,
\qquad\beta=0.1,\;\delta=0.1.
\]

仅用于确定k、j的离散选择不反传；在该保持辅助项内，d_k对选中分量的均值/标准差反传，margin对logits反传；原BC等主损失仍正常训练共享参数及输出。并列时实现选首编号，因此不要把一般“编号不绑定”夸大成包含全部并列情形的严格置换等变性定理。

在已核文献中，较具体的差异是：**回归当前实际被部署规则选中的高斯，而把最接近历史执行高斯的分量作为选择监督，再把这项保持用于任务获得时的成功执行历史。**

这和M2Distill的完整混合分布KL不同，也和“只回归最近/最优分量”不同。但是：

- 高斯W2本身是已知距离，分组归一化属于任务尺度设计；[FAME §3.2.1](https://arxiv.org/html/2603.00903v1#S3.SS2.SSS1)已把Gaussian W2用于连续策略知识整合并在机器人持续RL上测试。
- 缓存高斯均值/标准差已有RECALL先例。
- 最小距离选模式与margin排序已有跨领域先例。
- 完整GMM密度本身对分量重编号不敏感，不能说只有本方法摆脱分量编号对应。
- 软margin与选中分量回归不保证所有输入执行同一行为，更不保证闭环成功。

因此最稳妥的是**部署规则相匹配的历史行为保持组合**，而不是“全新蒸馏理论”或“新路由网络”。是否值得作为独立方法贡献，要看这个具体区别相对直接蒸馏的必要性，而不是仅看公式写法不同。

## 5. 三种层次的创新判断

| 主张层次 | 本轮判断 |
|---|---|
| 新基本思想：成功回放、固定教师、分布保持 | 已有充分先例，不能主张 |
| 首次应用于机器人终身模仿/GMM | M2Distill、SPREAD及机器人持续蒸馏直接削弱/否定这一宽泛说法 |
| 完整代码与某篇方法完全相同 | 本次没有找到完整同构，不据此指控照搬 |
| 一种有价值的适配/组合创新 | 仍有可能；需要证明具体适配有效且不是额外数据/计算解释 |
| 已经建立强方法新颖性或可保证论文录用 | 当前查新和现有对照不足以支持 |

“求同存异”是合理标准，但相同部分需要承认并引用，差异部分需要有问题动机和独立证据。把已有算子集成到明确部署约束里可以成为贡献；只是把RL改叫IL、换任务或换名字，不能自动完成这个论证。

## 6. 当前最需要的对照，而非继续改公式

这里只列研究建议，不构成新实验授权，不自动启动。

1. **最接近的直接蒸馏对照。** 在相同主干、旧输入和额外前向预算下比较M2Distill式完整GMM KL与当前执行高斯保持；完整复现M2Distill与只适配其policy loss必须分别命名。
2. **固定目标的普通克隆对照。** 使用同一成功缓存，比较实际采样动作BC、缓存均值MSE、缓存高斯KL/W2。这样检验保存方差和执行分布是否必要。
3. **路由独立必要性。** 保持距离不变，对比有无最近分量margin；报告实际选择变化与闭环，不以离线regret下降代替成功率。
4. **成功筛选的共同数据池对照。** 相同候选rollout池、缓存数、旧任务配额、复用次数和环境权限下比较随机/未筛选与成功筛选。现有O/S随学习轨迹分叉，检验的是整条方案，不纯粹隔离成功标签。
5. **固定与滚动教师。** 这是已知设计的可验证取舍，不能先验写成固定教师必然解决累积遗忘。

旧C没有新增有限采集，与SHBR不是等交互资源；D虽然有匹配采集预算但不使用在线历史，其对照回答的又是另一问题。S成功窗口较少和任务空槽为零，可能同时改变有效约束样本与强度。以上都需要在创新有效性论证中说明。

## 7. 对RA、TASA和整套方法的边界

本轮主要深查SHBR，并非完成RA所有coreset算法或TASA所有时序监督文献的全面检索。不能把SHBR查新结论自动推广成整个RA+TASA+SHBR已通过原创性审查。

可以组织成三层互补问题：RA决定示范回放覆盖，TASA保证历史输入和动作监督的时间语义，SHBR保持曾在实际执行历史上产生的行为。这个问题分解可以帮助解释系统，但模块名字和叙事本身不创造新颖性。

尤其TASA在当前实现中针对已核数据时间约定修正有效动作监督；如果解决的主要是复现管线错位，应清楚区分数据/复现贡献与一般算法贡献。不能把必要的正确性修复全部包装成新的学习原理。RA的具体样本预算与取舍需要另行与现有coreset、干扰选样、Memory Anchors等比较。

## 8. 建议论文表述

可用的定位草案：

> 基于已有经验回放与行为蒸馏思想，我们面向采用确定性分量选择、分量内随机采样的时序模仿策略，构建有界的成功执行历史记忆。记忆固定任务获得时的执行高斯输出，并在后续学习中联合约束当前执行分量及其选择分数。该设计保留原示范学习目标，研究成功执行历史与部署分布保持对持续技能保持的增量作用。

这是待实验支撑的贡献表述，不包含“首次”“保证不遗忘”或“已证明每步正确”。如果最接近基线已解释全部收益，应把结果定位为有效工程整合/实证研究，而不是继续扩大原创性措辞。

## 9. 检索范围与剩余不确定性

S-O最终旧任务+5pp、FinalAll+5pp，预登记S-O门通过；O-D门也通过。这提供了有用的单seed探索线索。但S相对C的AUC低0.625pp，而且早期旧任务保持没有通过原预登记门，原`S-C=false`须保留，不能只用最终结果改写成全面成功。

D/O/S的保持距离、固定教师时点及margin算子相同；C也有专家路由。故这些比较不独立检验固定教师或新增路由。O/S是各自执行采集，保存历史并不逐窗相同；后续参数和访问状态也会分叉。即使配对初态与噪声一致，也不等于在共同数据池上只切换成功标签。现有42/43和OBJECT没有C/O同预算消融，所以目前只能说“完整S方案的跨种子、跨套件实效有支持”，不能说“成功筛选的机制已被多seed证明”。详细限制见`MECHANISM_EXPERIMENT_EVIDENCE.md`。

进一步核查发现：O/S在Task7采集均10/10成功、各128窗口，此时没有剔除失败轨迹，但相同轨迹–时间键已有7个feature SHA和5个教师均值SHA不同。前200个epoch非计时字段相同，下一阶段第一轮才出现训练记录差异。因此，中期闭环差异不能倒推为之后Task8采集筛选所致；哈希只证明字节不同，不证明差异大小或具体原因。S-O中期Task6下降40pp、最终Task8提高15pp也必须同时保留。

### 10.4 最新离线证据进一步限定了故事

OBJECT seed43 Task6在Stage8→9的761个相同专家窗口上，统一到同一Stage9尺度后，执行专家成本0.00422553→0.00210330，路由regret 0.00217411→0.00025497；闭环却75%→20%，同初态/噪声下11条成功转失败、0条反向改善。这是实际的反例：离线纠错与选择统计改善，仍不足以保证闭环保持。

相同seed固定Task6缓存上的保持距离0.00854116→0.01011955，与漂移相容；但其Task7保持距离0.01427629→0.05952016，闭环反而80%→100%。因此距离变大不能自动标记为有害变化，距离变小也不能自动证明保护有效。这里比较的是已有缓存输入，未重演正式失败轨迹的物理历史，更没有教师动作替换干预。

成功缓存覆盖也有具体边界：OBJECT seed41/42的最早任务各仅1条训练成功轨迹、13窗口；seed43有63窗口却仍严重遗忘。少量成功缓存可能不覆盖后续关键输入，但“窗口少”并非已证明的唯一原因。固定任务获得时教师可避免目标滚动，却也可能固定早期不充分的能力。上述现象支持研究部署历史与任务成功的关系，不支持把当前W2或路由损失宣称为任务成功保证。

### 10.5 查新与结果合并后的定位

**实证价值比单seed阶段更强，基础机制的新颖性仍受直接先例限制。** 两套LIBERO任务、三seed的平均增益，使SHBR不再只是未验证构想；它们不改变M2Distill、RECALL、MILI等已经存在的事实，也没有完成相对这些近邻方法的受控比较。

现阶段合理贡献是：围绕特定时序GMM部署语义，把有限成功执行历史、任务获得时行为摘要与执行分量/选择监督结合起来，并提供完整序列的多seed验证及失效边界。要上升为更强的方法贡献，优先比较同缓存、同预算下的普通固定教师蒸馏与完整GMM蒸馏，并隔离成功筛选/执行分量/路由的必要性。这里提出的是研究建议，本轮不启动任何追加实验。
