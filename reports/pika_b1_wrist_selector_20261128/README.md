- 第 1.94 秒，模型开始给出收爪意图，此后 131 帧意图有效。同期腕部均未检出完整木块框。末段录像显示木块局部仍在画面下缘。整轮夹爪反馈约 66.80 mm，软件发出的收爪指令为零。
- 第 4 秒后，原版 8 个规划中 5 个水平位移为零，另 3 个沿画面下缘可见木块方向的分量均为负。衰减前该方向的中位数为 −6.11 mm，仅放大原纠偏量仍会朝相反方向走。俯视估计的水平残差中位数为 14.37 mm。下发目标与预测水平位置相同，目标与发送前反馈的水平距离中位数为 0.35 mm、最大 0.97 mm。同期夹口反馈净移动约 1.66 mm。
- 第 6.305 秒程序按设置发起 STOP，收到从臂 STOP 反馈和夹爪失能反馈。时间限制决定何时停车；腕部始终未确认对准，直接导致这轮没有收爪。

在当日记录的每个原规划起点重算昨天冻结的候选算法，末段 8 次均朝腕部观察到的木块方向修正，每八步的有符号分量为 +0.86 至 +2.00 mm，中位数 +2.00 mm。方向评价采用另一组示范的相机标定。该数值来自固定历史观测上的计划对照，实际闭环修正与抓取效果尚待现场测量。[复算程序](analyze.py)

## 现场权重选项

rlmi 桌面的「PiPER 通用策略测试台」使用原有三栏选择器。已打开的窗口在退出并重新打开时读取新的权重列表。任务选 **B1**，模型选 **ODE**，权重选 **11-27 腕部纠偏**。选择后、进入预览前，详情栏显示版本指纹 **27fca3b2b325**。原版仍为默认选项，指纹为 **4e995bc1fdc9**。

进入「只读预览」后可检查双相机、反馈与预测。现场就绪并决定运行时，按「现场执行一轮」和确认栏里的「确认执行」。两个选项沿用原开度门控、启动反馈检查、关节跟踪保护、100 ms 预测新鲜度检查、500 ms 心跳和 6.3 秒结束 STOP。两个版本共用原 ODE 网络权重，新选项切换的是腕部视觉纠偏算法。
