# B1 双相机独立对照协议

比较对象为 11 月 23 日 B1 ODE 的原始 EMA50、提高俯视分辨率、共享时间窗裁剪。两组重新从同一种子初始化，使用原训练器、同一份 50 条专家示范清单、9,731 行动作、每轮 305 次更新、50 轮训练及相同的 EMA 取权重方式。所有操作只涉及归档文件。网络的视觉编码器结构、状态输入、动作归一化、训练损失和腕部图像分辨率相同。

| 条件 | 俯视输入及裁剪 | 腕部输入及裁剪 | 同视角的 8 帧历史 |
|---|---|---|---|
| 原版 | 128 → 112 | 128 → 112 | 每帧单独随机裁剪 |
| 提高俯视分辨率 | 256 → 224 | 128 → 112 | 每帧单独随机裁剪 |
| 共享历史裁剪 | 128 → 112 | 128 → 112 | 窗口内使用同一偏移，两个视角各自抽取 |

高分辨率组直接从原始 640 × 480 的 JPEG 生成新输入。先上下补边再缩放，裁剪的归一化视野、中心、随机位置网格与原版一致。共享裁剪组沿用原图像缓存，每一视角抽取与原版相同数量的随机数，再把本窗口第一帧的偏移用于其余七帧，从而保持后续随机数序列一致。所有组评估时均使用中心裁剪。

## 摆位、几何与动作目标

先从每条示范接近阶段前的原始俯视图定位木块，目检所有 84 条，人工修订 8 个中心点。只用 50 条训练示范拟合从图像位置到基座桌面平面坐标的仿射映射，采用 Huber 损失，其标定参考为专家反馈夹爪连续三帧不超过 49 mm 时的夹口中心。夹口位置使用六轴正运动学和归档的夹口中心相对法兰偏移。整条留出示范的专家夹口仅用于事后校验。标定的精度会受到夹持偏心和遮挡影响。

未入训的 34 条成功示范中，有 33 条满足开局指令大于 55 mm、有首次向下跨越 55 mm、具备完整 8 帧历史与 8 步真实目标的条件。主分析窗口以首次跨越前 18 帧为最后观测，辅助窗口以跨越前 3 帧为最后观测。评估使用真实观测和上一条专家目标，预测八步绝对关节指令，并将第八步转换为桌面平面上的夹口中心。主要推理条件固定 ODE 随机扰动为零，另用与实机相同的混合分量采样方式、在每次 CPU 回放时设定种子 42，检查结论是否对推理采样敏感。

## 方向性

先按木块间距至少 20 mm、夹口起点相距至多 55 mm、各关节差不超过 25°、开度差不超过 20 mm 建立候选配对。通过最大数量、最小姿态差的匹配，得到 16 对互不重复的示范。每对都从 A 和 B 两个方向各测一次。固定接收方真实关节反馈、上一目标和腕部图像，把俯视 8 帧换为对方同阶段的 8 帧。将替换前后的夹口终点差投影到从原木块到另一木块的方向，再取两个方向的平均。正值代表预测朝新木块偏移。除方向正负，还统计超过 1 mm 的正向和反向修正及相对原版的配对差，以避免把数值噪声理解为有效修正。

辅助检查包括只替换俯视图中两个木块坐标附近的小片图像、同时替换双视角、使用专家实测闭合位置定义方向，以及木块相隔至少 30 mm 的子集。局部替换区域可能含阴影或部分夹指。整幅换图会带入示范间的姿态差异。自然回放在每条示范自身的真实双相机画面上衡量预测是否缩短夹口与木块的距离，并同时报告专家和保持静止这两个参照。按每对示范重采样 10,000 次计算配对中位变化的区间；一对的两个方向及同一窗口的八步不会被当成独立样本。

## 离线复算入口

在保有原始数据和 11 月 23 日训练环境的主机上，将本目录的 Python 文件和 `annotations.json` 放入独立实验目录 `OUT`。`WORK` 为包含 `batches` 与 `offline_diagnostics` 的原归档根目录。原始清单摘要由训练脚本校验。

```sh
python "$OUT/annotate.py" "$WORK" "$OUT"
python "$OUT/assess.py" "$WORK" "$OUT"
python "$OUT/driver.py" "$WORK" "$OUT"
python "$OUT/evaluate.py" "$WORK" "$OUT" baseline
python "$OUT/evaluate.py" "$WORK" "$OUT" high
python "$OUT/evaluate.py" "$WORK" "$OUT" shared
python "$OUT/evaluate.py" "$WORK" "$OUT" summary
```
