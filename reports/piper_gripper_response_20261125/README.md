# 已发目标与 PiPER 夹爪响应

比较了 11 月 21–22 日存留的独立 SocketCAN 记录和 11 月 25 日四轮 B1 的执行记录。以下时间均为北京时间。以目标之后的实测开度和反馈力矩判断夹爪响应，所有数值都来自现有记录。11 月 25 日 17:38 检查时，主机没有枚举到 CAN 网口，因此本次没有取得新的手动滑块样本或发出运动指令。

## 同样从 9.8 mm 收爪，250 ms 后有两种结果

11 月 22 日的两段原始记录均来自普通 CAN 策略执行。首条本机 0x159 宽度指令之前的 100 ms 内，开度均稳定在 9.8 mm。以下各点按同一内核时钟取该时刻以前最近的目标与反馈。两段目标都是连续变化的收爪指令。

| 首条目标后 | 13:55:50 目标 / 实测开度（mm） | 14:33:46 目标 / 实测开度（mm） |
|---|---:|---:|
| 0 ms | 8.092 / 9.8 | 8.050 / 9.8 |
| 100 ms | 5.014 / 9.8 | 4.665 / 9.8 |
| 250 ms | 0.575 / **4.3** | 0.581 / **9.8** |
| 500 ms | 0.066 / 3.6 | 0.073 / 9.8 |
| 1,000 ms | 0.016 / 3.6 | 0.016 / 9.8 |

第一段在 143 ms 处反馈力矩降至 −0.506 N·m，153 ms 时首次观测到至少 0.3 mm 的闭合。另一段近似起姿的记录从 9.9 mm 开始，力矩在 109.5 ms 首次达到 −0.2 N·m，119.3 ms 时观测到闭合。0.3 mm 和 −0.2 N·m 仅用于本次量取变化时刻。

14:33:46 的停滞段在最初 250 ms 内仅报告 −0.025 至 +0.005 N·m。在 6.85 秒、190 条目标和 1,370 条反馈内，每次反馈都是 9.8 mm，最大反馈间隔 5.86 ms；其中连续约 6.75 秒开度与目标相差至少 4 mm，反馈力矩中位数 −0.011 N·m。在这两段内，夹爪使能码、宽度模式、指令力度字段相同，反馈状态均为 0x40，两段中间都未观测到 STOP、使能切换或 CAN 错误帧。首条至末条目标均位于 STOP 之前。

同一 SocketCAN 接口上的独立监听记录了本机目标回显和来自设备的 0x2A8，时间戳可以直接比较。本机回显无法证明控制器逐帧采纳了目标。反馈力矩只表示设备上报的值，未独立测量电机电流或夹指输出力。[松灵 SDK 字段定义](https://github.com/agilexrobotics/piper_sdk/blob/master/piper_sdk/interface/piper_interface_v3.py)

## 11 月 25 日四轮的响应

以每轮进入收爪等待之前、最后一次连续进入“实际开度超过已提交目标至少 4 mm”的首条提交为起点。按发送完成单调时戳与夹爪原始反馈时戳配对，对同一条反馈去重。取 100、250、500 ms 时刻以前最近的反馈，正值表示继续收小。期间程序还会提交后续目标，各栏反映整段跟踪过程。末段以最终等待反馈开度中位数 ±0.1 mm 定义，取最后一次连续进入这个范围的时刻。

| 开始时间 | 起点目标 / 实测（mm） | 100 / 250 / 500 ms 后已闭合（mm） | 进入等待前，开度已在末段范围内多久 |
|---|---:|---:|---:|
| 13:29:31 | 53.759 / 58.2 | 0 / 6.9 / 16.5 | 0.205 s |
| 13:33:11 | 50.726 / 55.3 | 0.1 / 0.1 / 0.1 | 0.288 s |
| 14:22:15 | 52.811 / 57.5 | 0 / 6.0 / 8.1 | 0.416 s |
| 14:24:20 | 60.562 / 64.8 | 0 / 0 / 0 | 0.860 s |

14:24 的实测开度在 64.7–64.8 mm 共持续 2.825 秒，刚进入这段时已发目标约为 63.85 mm，后来收到的夹爪反馈仍持续更新，等待期间的提交目标为 51.70 mm。14:22 曾有明显闭合，最终开度停在 49.4 mm 附近。11 月 25 日缺少这四段完整的独立 CAN 抓包，表中目标取自执行器成功提交记录。[11 月 25 日末两轮的日志核验](../piper_b1_alignment_gripper_20261125/README.md)

## 判断与可辨别的下一项

相近的指令序列下，能动时先观测到明显的闭合方向力矩，随后反馈开度下降；停滞时反馈仍更新，而且力矩长时间很低。优先核查夹爪控制器是否采纳目标、驱动有没有产生闭合力矩。抓拍不到内部目标、电机实际电流及接触状况，尚不能确定是控制器、驱动、测量还是机械阻力。两段初始开度相同，现场负载和接触条件未知。

独立归档保留的约 16 小时里可见 2,790 条本机宽度目标，分为 9 段，均与策略执行重叠。没有可归属手动滑块的单发样本。要判断某次手调，应在现场原本要调夹爪时同步保存滑块目标、0x159、0x2A8 开度和力矩；若松灵可读取内部目标及实际电流，这两项能进一步区分接收与驱动环节。无需为取得这组证据再跑整轮 B1。

可用 Python 3.10 及以上离线复算。运行 `extract_archive.py <归档工作目录>`，将标准输出保存为私有中间文件，再运行 `response.py <中间文件> <四份执行日志>`。前者只读取历史文件。公开的统计按控制会话汇总，原始 CAN 及机械臂运行日志留在本地。[汇总数据](outcomes.json)
