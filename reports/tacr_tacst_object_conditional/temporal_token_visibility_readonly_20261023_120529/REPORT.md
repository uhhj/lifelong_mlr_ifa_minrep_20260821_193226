# Temporal输出token是否限制物理信息：只读审计

结论：存在已经证实的最新帧可见性限制。当前不是读取展平序列的最后token，而是读取最后时刻第0模态token。六层实际GPT均采用序列级因果注意力，同帧排在其后的视觉和状态信息没有路径进入这个读出。

## 实际路径与token顺序

已核当前TACR41冻结源码、实际resolved配置和训练后Task9检查点，未依据旧本地参考文件的相似代码推断活动文件相同。source_capture保存实际函数和源SHA；配置use_language/use_vision/use_state均True。空间编码每时刻四token顺序为语言、语言调制的agentview、语言调制的eye_in_hand、语言调制的joint+gripper状态。

```python
# 语义等价的索引展开，B×8×4×512
Y = Temporal(x.reshape(B, 32, 512)).reshape(B, 8, 4, 512)
h = Y[:, 7, 0, :]       # 全序列0起索引28，不是31
c = R(h.detach())
```

活动BriefPolicy.temporal_encode先返回`out[:, :, 0, :]`，新分支hidden再取`[:, -1]`；活动CompletePolicy闭环同样先取模态0再取最后时刻。OfficialGPT2Decoder未设置同帧块级双向mask，实际transformers4.26.1的GPT2Attention._attn在六层均执行下三角因果遮罩。

|最后时刻token|展平0起索引|能否进入当前h|
|---|---:|---|
|语言|28|能，且可融合此前历史token|
|外部视角|29|不能|
|腕部视角|30|不能|
|关节与夹爪状态|31|不能|

因此`h_t`可依赖`x[0:t-1, 全部模态]`与`x[t, 语言]`，不能依赖`x[t, 视觉/状态]`。窗口仍是八步；最新可用物理观测的直接依赖却最多到前一时刻。不能把token数量的29/32换算成物理信息保留比例。它也不是只读到纯文本：前七时刻的视觉/状态可以进入最后语言位置的输出。

## 对物理分支的含义与边界

TAC-R的R只读stopgrad(h)，TAC-ST当前query和冻结历史teacher也沿用同一hidden。因此它们继承该可见性限制。效果损失不更新Temporal，R只能重组当前h已有的信息；给R更多层或更强监督不能建立原来被因果mask切断的最新视觉/状态依赖。128维压缩是另一潜在限制，但本次没有证明它损失多少物理信息。

这套主策略读出沿自原RA/ALIGN，不是TAC-R新增索引与训练/部署不一致。保留共同主策略路径有对照意义。已证明的是信息通路受限，不是TAC-R/ST一定无效、R完全没有物理知识、最新帧一定决定任务成败，或任何当前性能差异已经归因于此。历史观测仍可能支持有效预测，跨任务图也不会因为此结论自动失效。

本次没有训练读出探针、比较真实demo留出效果误差、评估更换token后的BC/闭环收益，不能声称改成31或平均池化就必然更好。现有GMM和预训练权重针对原读出训练，直接替换主读出会改变整个控制策略及对照定义。
