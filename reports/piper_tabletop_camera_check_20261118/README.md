# PiPER 桌面与相机静态核查

观察时间为 2026-11-18 13:32（北京时间）。通过只读相机预览核查六项任务的布置。两轮相机核查均正常退出，确认三台相机和五个可读视频通道。

| 相机 | 通道 | 观察 |
|---|---|---|
| RealSense D435i | `/dev/video4` | 彩色俯视覆盖工作区，碟子和两张彩纸在曝光稳定后可区分。左碟靠画面边缘，左侧夹爪遮挡黄纸一角。 |
| RealSense D405 | `/dev/video10` | 低角度近景能看到夹爪前方，部分台面目标受前景遮挡。 |

重新解码验证了上述帧均为 800 × 600。D435i 俯视帧在启动后约 2.5 秒复读，8 位平均亮度由早期预览的 33.1 升至 127.1。

画面确认蓝、粉、浅色三只碟子，黄色左推移区、紫色右推移区和木块。三个入碟目标与两个推移终点已具备试采布局。第六项需要补一个独立的精确放置框，可试放在木块下方、两张色纸之间靠机械臂的一侧。试采前给左碟留出画面边距，并确认夹爪撤开后可完整看到黄纸边界。动作可达性、推移时纸边稳定性和连续采集同步待试采验证。
