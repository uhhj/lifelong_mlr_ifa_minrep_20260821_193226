## 现场操作

红色 STOP 下方有独立的“解除软件急停（复位）”按钮。现场使用复位前，应按设备流程隔离主臂的 CAN 连接，让上位机单独连接从臂，可靠支撑从臂并清空其运动范围。复位可能使从臂失去保持力并下落。[松灵双臂直连说明](https://github.com/agilexrobotics/piper_sdk/blob/b847e5393a7ce6ff8508d713eca7bdd3a42421b4/assets/double_piper.MD#L99) · [官方复位说明](https://github.com/agilexrobotics/piper_sdk/issues/20)

在已核实身份的可收发接口上，收到新鲜的从臂急停反馈且没有其他错误时，点击复位，核实并勾选现场条件，再点击“确认复位”。物理隔离和支撑情况由现场人员确认。窗口观察到控制报文时会撤销确认，短时总线安静不能证明已隔离主臂。接口只听或与既有绑定不符时，两个发送按钮都会禁用。

窗口仅提交一次厂家 `ResetPiper` 对应的复位帧。反馈必须来自提交之后的从臂状态帧，且机械臂状态为正常、错误位为零，窗口才显示急停解除。超时显示结果未知。复位不发送使能、回零、角色设置或跟随目标。STOP 保持直接触发，可以取消待确认复位或打断对应答的等待。已经提交到总线的复位帧无法撤回。

## 离线验证

Windows 通过 11 项 Qt 内存测试。现场 Linux 使用 Qt 离屏、内存假设备和本地 Unix 数据报，通过全部 12 项测试，包括内核接收时间戳核对。测试覆盖重新连接、反馈过期、排队的主臂指令、重复点击、错误反馈、STOP 优先、发送失败和超时。原 STOP 回归同时核实了有限重发、接口身份检查及录制进程识别 STOP 回显。现场 CAN 套接字未用于这些测试。
