# RA-Coreset 完整方案交付

- `PROTOCOL.md`：科学目标、原消融证据、RA选样公式、稳定样本槽位、统一E1评价、任务协议、可执行步骤、失败条件、预算与新颖性边界。
- `spec.yaml`：预注册参数、GOAL/OBJECT实际任务规模、阶段门槛与待开发接口。
- `selector_reference.py`：纯 NumPy/Python 的最小换样和稳定槽位参考函数。须接入冻结的真实 `Distance`、缓存和路径绑定才能用于完整实验。
- `test_reference.py`：8项合成CPU测试，覆盖最少换样、精确删除代价与batch位置恒等；这不是机器人成功率实验。
- `TEST_LOG.txt`：离线测试结果。
- `MANIFEST.json`：交付文件 SHA256。

参考选择器及计划能直接供代码实现者使用，但 `ra_exp.*` 所列命令是接口合同，不是上游仓库已实现的模块。本次不会自行创建实验、GPU训练、闭环评估、远端提交或自动化。

本轮只改变**记忆选择的科学变量**；实验控制方面统一采用稳定训练位置与独立逐轨迹动作噪声，必须明确这种评估协议与历史报告不同，旧 C 的 checkpoint 应重新 E1 评估，旧模型不必重训（先满足loader完全等价的硬性前提）。
