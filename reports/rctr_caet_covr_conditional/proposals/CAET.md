# RA-Coreset + CAET：OBJECT seed42 闭环实验完整执行方案

结论：建议以已经完成的 OBJECT seed42「RA-Coreset＋IFA」实验为唯一直接对照，保留原论文的四阶段训练与闭环评估协议，仅增加 CAET 动作效果学习和跨任务效果迁移机制，先验证单 seed 的闭环 AUC 是否获得净提升。

但根据当前代码，必须解决一个关键问题：现有 MLR 回放文件只有潜在特征与专家动作，无法直接得到目标物体在执行动作后的实际变化。 因此，本实验必须包含真实效果标签的构建与验证，不能用动作变化冒充物理效果。

下面给出以实际 `MLR` 分支为基础的可执行方案，目标是一次完成算法实现、工程准入、四阶段训练、200 次正式闭环评估及独立结果审计。

## 二、CAET 必须针对 OBJECT 的实际任务设计

当前仓库的 `LIBERO_OBJECT` 中，Task 6–9 并不是四个推方块任务，而是四个抓取不同物体并放入篮子的任务。

| 任务     | 实际操作对象            | 共同的控制过程           |
| ------ | ----------------- | ----------------- |
| Task 6 | Butter            | 接近 → 抓取 → 搬运 → 放置 |
| Task 7 | Milk              | 接近 → 抓取 → 搬运 → 放置 |
| Task 8 | Chocolate pudding | 接近 → 抓取 → 搬运 → 放置 |
| Task 9 | Orange juice      | 接近 → 抓取 → 搬运 → 放置 |

因此，本次 CAET 的跨任务知识应当围绕抓取、抬升、携带和释放物体的真实状态变化构建，而不是围绕抽象的动作相似度。

本次不修改：

- 半配额 Random 锚点与最小交换策略。
- 任务配额及原始 `.pt` 文件内容。
- 当前任务数据与旧任务 Buffer 的拼接、排序和采样规则。

最稳妥的实现方式是：直接复用 RA seed42 已有的四份有序选样清单和源文件哈希，在每个任务训练结束后，按照原有流程将相同成员写入独立的新 Buffer。

这既避免重新选样的随机差异，也能将实验变量集中在 CAET。

### 2. CAET 的真实效果标签

建议第一版只使用三类直接可核验的信息：

\\[ e_t = \left[ \Delta p\_{\mathrm{target}}, \Delta r\_{\mathrm{target}}, \Delta p\_{\mathrm{eef}} \right] \\]

分别表示目标物体的位置变化、姿态变化和机械臂末端变化。

其中真正体现 CAET 新信息的是目标物体变化。末端变化主要作为辅助上下文，不能代替物体效果监督。

数据来源必须是原始 HDF5 演示中记录的真实物理状态。 不允许根据专家动作积分出“假定的物体移动”，也不允许直接把机械臂移动当成物体移动。

已有 RA 代码提供了一个有利条件：

`ra_exp/prepare.py` 已经通过完整 `8×7` 专家动作窗口建立了缓存样本与原始演示之间的候选时间绑定；这可直接作为 CAET 标签构建的起点。

但每个绑定都必须先验证 `demo_id` 和监督时间索引唯一，时间身份不确定的样本不能被强行分配物理效果标签。

### 3. 避免仿真历史恢复陷阱

最新 RCTR 诊断已发现：当前环境对历史演示状态的完整恢复仍存在未解决差异，包括物理版本、接触演化和隐藏控制器状态问题。

因此本次 CAET 不通过恢复旧演示 MuJoCo 状态，再执行一次动作来生成效果标签。

直接从同一原始 HDF5 演示中读取相邻已记录物体状态，计算真实观察到的变化。这样不依赖历史仿真能否精确重演。

仍需做状态索引与动作时间对齐检查：先确认数据中的动作对应哪两个相邻记录状态，再计算该动作的效果。若不能证明标签时序正确，该样本不能进入效果监督。

## 三、CAET 算法的最终实验实现

建议采用共享效果预测器＋跨任务效果对齐＋效果一致性训练，不增加残差策略，不修改推理动作选择。

### 1. 输入与输出

当前缓存样本已经包含：

```
sample = {    "feature": Tensor[1, 8, 4, 512],    "actions": Tensor[1, 8, 7],}
```

CAET 读取相同的特征和专家动作，额外读取独立存储的真实物理效果标签。

物理效果建议使用六维表示：

\\[ e_i^\*= \begin{bmatrix} p\_{\mathrm{obj},t+1}-p\_{\mathrm{obj},t}\\\ \mathrm{Log}(R\_{\mathrm{obj},t}^{-1}R\_{\mathrm{obj},t+1}) \end{bmatrix} \in\mathbb R^6 \\]

其中上半部分为物体实际平移，下半部分为物体实际旋转。

这里 \\(t\\) 必须是经过动作—观察时序校验后的索引。如果 HDF5 记录采用动作执行后保存状态的方式，需要按真实数据契约修正配对，不能机械使用数组下标 \\(t+1\\)。

### 2. 效果预测器

新增：

```
class CAETEffectModel(nn.Module):    ...
```

建议采用轻量网络，避免另造一套完整策略。

| 组件   | 设计                  |
| ---- | ------------------- |
| 输入   | 原始冻结潜在特征＋7维动作       |
| 时序特征 | 8步视觉、状态 token 的池化表示 |
| 特征维度 | 3 × 512             |
| 隐层   | 256 → 128           |
| 效果输出 | 6维                  |
| 额外表征 | 128维归一化效果嵌入         |
| 推理用途 | 不参与机器人部署推理          |

这里使用冻结的原始潜在特征，而不是持续变化的 Temporal Transformer 输出作为效果模型的输入，有助于避免动作效果预测器跟随策略更新发生表示漂移。

### 3. 先让模型学习真实物理效果

使用专家动作监督效果预测器：

\\[ \mathcal L\_{\mathrm{physical}} = \operatorname{SmoothL1} \left( F\_\phi(x_i,a_i^\*),\bar e_i^\* \right) \\]

其中 \\(\bar e_i^\*\\) 是按训练阶段可访问数据统计量归一化后的真实物理效果。

需要按物理量分别归一化，避免位置单位为米、旋转单位为弧度造成损失权重失衡。

效果预测器使用当阶段可访问的数据：

\\[ D\_{\mathrm{effect}}^t = D\_{\mathrm{current}}^t \cup M\_{\<t}^{RA} \\]

不读取已经丢弃的旧任务完整演示。

### 4. 增加跨任务效果对齐

以 Task 7 为例：

- Task 6 Buffer 中存在一些真实抬升物体的操作。
- Task 7 当前数据中也存在一些抬升物体的操作。
- 虽然物体不同，但可以基于真实位移和旋转效果建立对应关系。

对满足物理效果相近的跨任务样本，约束效果嵌入一致。

\\[ \mathcal L\_{\mathrm{transfer}} = \mathcal L\_{\mathrm{SupCon}} \left(h\_\phi(x_i,a_i^\*),h\_\phi(x_j,a_j^\*)\right) \\]

具体配对规则预先冻结：

- 仅在不同任务之间建立正样本对。
- 排除目标物体几乎没有发生位移、旋转的静止样本作为跨任务正对。
- 对真实位移方向、幅度和旋转差异进行归一化比较。
- 效果相近为正对，明确不同的效果为负对，中间不确定的配对忽略。
- 不使用动作相似度或语言相似度替代实际效果匹配。

第一版建议固定：物体位移有效阈值 1 mm、旋转有效阈值 1°；归一化效果距离不大于 0.5 为正对、不小于 1.0 为负对，温度系数 0.1。它们只是预先指定的探索值，不是已验证最优值。

辅助网络训练目标：

\\[ \mathcal L_F = \mathcal L\_{\mathrm{physical}} + 0.1\mathcal L\_{\mathrm{transfer}} \\]

必须验证确实存在跨任务有效配对。 如果只有大量静止状态被错误匹配，就没有真正实现 CAET 的核心机制。

### 5. 利用效果预测器训练原策略

辅助网络拟合结束后，将其冻结。

从原策略 GMM 选择与部署一致的最大 logit 分量，并在该分量下重参数化采样动作：

\\[ \tilde a_i=\mu\_{k^\*}(x_i)+\sigma\_{k^\*}(x_i)\odot\epsilon_i \\]

其中 \\(k^\*=\arg\max_k \ell_k\\)。

采样使用与原训练全局 RNG 隔离的随机数生成器，不能改变基线的 DataLoader 顺序或正常训练 RNG 流。

将预测动作送入固定效果网络：

\\[ \mathcal L\_{\mathrm{CAET}} = \operatorname{SmoothL1} \left( F\_{\bar\phi}(x_i,\tilde a_i),\bar e_i^\* \right) \\]

冻结效果预测器参数，但不能切断从效果输出到预测动作的梯度。否则 CAET 不会真正修正原策略。

原策略最终目标：

\\[ \boxed{ \mathcal L\_{\mathrm{total}} = \mathcal L\_{\mathrm{BC}} +0.1\mathcal L\_{\mathrm{IFA}} +0.05\mathcal L\_{\mathrm{CAET}} } \\]

这里 0.05 是第一轮建议冻结的探索系数，不能根据 seed42 正式闭环结果再调整并把重跑当成同一次独立实验。

需要强调其能力边界：效果预测器是用专家数据训练的观察性模型，不能因此认定它在任意非专家动作上具有正确的因果预测能力。前置验证必须检查它在未见演示上的预测，以及效果损失对动作输出是否产生有效且有限的梯度。

## 四、完整四阶段训练流程

我建议做一个重要调整：Task 6 只建立效果记忆，不让 CAET 改动其策略训练；从 Task 7 开始激活跨任务效果迁移。

这样 Task 6 可以严格复现已有 RA-Coreset 基线，将后续性能变化更明确地归因于新增模块。

Task 6：建立初始经验

原 RA-Coreset＋IFA 训练100 epoch → 选出781个样本 → 计算并保存对应真实物体效果

Task 7：首次跨任务迁移

Task6历史效果＋Task7真实效果 → 训练 CAET 预测器 → 冻结预测器 → 联合训练策略100 epoch → RA入库740个样本

Task 8：持续迁移与保持

Task6/7历史效果＋Task8真实效果 → 重新拟合当阶段共享预测器 → 联合训练策略100 epoch → RA入库780个样本

Task 9：最终持续学习阶段

Task6/7/8历史效果＋Task9真实效果 → 训练当阶段预测器 → 联合训练策略100 epoch → RA入库660个样本

建议每阶段效果预测器从固定独立初始化开始训练，不继承前一阶段的预测器权重。这样可以避免引入一个额外的、持续累积旧任务信息的参数记忆库。

效果预测器只利用当前任务和实际 RA Buffer 拟合，训练结束后可保存审计权重，但不作为下一任务的输入，也不参与正式闭环推理。

### 必须特别处理的四个代码问题

第一，样本身份绑定。 原始 `FileTrajectoryDataset` 返回样本和任务ID，CAET还需要用来源文件名查找效果标签。建议使用数据集包装器附加 `effect`、`effect_mask`，不改变 `.pt` 字节及样本顺序。

第二，GMM动作路径。 原策略训练损失是专家最后一步动作的混合高斯负对数似然；新增效果损失不能改掉这一行为，也不能将GMM替换为确定性动作头。

第三，梯度隔离。 训练辅助预测器时不允许更新原策略；训练主策略时冻结辅助预测器权重，同时保留效果损失到策略预测动作的梯度。不得意外训练冻结的空间前端。

第四，Task6完全一致性。 由于建议从 Task7 才激活CAET，Task6 完成后的模型张量应与已完成 RA seed42 Task6 checkpoint 逐参数一致。若不一致，停止进入 Task7。

效果预测器的留出验证应按完整演示划分，不能将同一演示的高度重叠窗口同时放入辅助网络训练与验证集合。该划分只用于检查效果预测器，不改变原策略的10条示范训练协议。

真实效果标签需设置明确的 `valid` 标志。遇到未记录物体状态、时间无法确定、轨迹边界没有合法下一状态等情况，只能屏蔽对应标签，不能生成零效果假标签。

若动作—状态对齐、真实物体位姿提取或跨任务有效匹配不成立，状态记为 BLOCKED，不自动改成机械臂动作差分继续训练。

## 七、正式闭环评估协议

四阶段训练完成后，使用原有 `coreset_exp.evaluate` 和 `eval_metric.py` 的闭环评估逻辑，在新实验分支中仅修改模型路径与方法名称。

每个阶段只评估已学习过的任务：

| 阶段      | 测试任务         | 正式 episode 数 |
| ------- | ------------ | ------------ |
| Stage 6 | Task 6       | 20           |
| Stage 7 | Task 6、7     | 40           |
| Stage 8 | Task 6、7、8   | 60           |
| Stage 9 | Task 6、7、8、9 | 80           |
| 合计      | 10个有效单元      | 200          |

保持下列评估条件完全不变：

- 每单元使用既有20个初始状态，索引0–19。
- 10路向量环境，2次vector尝试/单元，共20次。
- 环境seed使用原有42、43设置。
- 每次开始执行5步零动作。
- 每次最多执行600个策略步。
- GMM选最大logit分量，再从对应Normal分布采样。
- 保持原阶段global动作RNG重置规则，不额外引入轨迹级Generator。
- 使用epoch99 checkpoint，不依据途中成功率选模型。
- 不执行在线恢复、动作重排序或成功率反馈训练。
- 正常失败算失败，不补跑有利初态。

CAET辅助网络完全不参与闭环推理。 因此其作用只能通过训练后策略自身的行为变化体现。

另外，原始评估中的公共空间前端和当前阶段下游模型需要严格加载。不能只加载新下游权重而遗漏官方前端，也不能使用 `strict=False` 隐藏缺失参数。

## 八、指标计算与判定标准

按照此前论文对齐协议，令 \\(r(i,j)\\) 表示完成阶段 \\(i\\) 后在任务 \\(j\\) 上的闭环成功率。

主指标：

\\[ \mathrm{AUC} =\frac14\sum\_{j=6}^{9} \frac{1}{10-j}\sum\_{i=j}^{9}r(i,j) \\]

其他指标：

\\[ \mathrm{FWT}=\frac14\sum\_{j=6}^{9}r(j,j) \\]

\\[ \mathrm{NBT} =\frac13\sum\_{j=6}^{8} \frac{1}{9-j}\sum\_{i=j+1}^{9} \left[r(j,j)-r(i,j)\right] \\]

此处 NBT 使用此前报告的有符号定义，正值代表相对于首次学习结果的平均退化，负值代表平均提升；不能随意反转符号。

最终两个成功率：

\\[ \mathrm{OldFinal} =\frac{r(9,6)+r(9,7)+r(9,8)}3 \\]

\\[ \mathrm{FinalAll} =\frac14\sum\_{j=6}^{9}r(9,j) \\]

### 第一轮结果判定

| 指标           | RA seed42 基线 | CAET第一轮判断      |
| ------------ | ------------ | -------------- |
| AUC          | 71.5625%     | 严格高于基线才算主指标正向  |
| FWT          | 70.00%       | 报告变化，不能隐藏新任务损失 |
| NBT          | −3.0556 pp   | 判断是否加剧遗忘       |
| OldFinal     | 65.00%       | 优先关注旧任务最终保持    |
| FinalAll     | 63.75%       | 检查最终总体性能       |
| Stage9 Task6 | 10.00%       | 重点分析该旧任务是否得到改善 |

建议将结果分为三个类别：

- 正向且有持续学习价值： AUC提高，OldFinal和FinalAll不下降，并通过全部工程审计。
- 混合结果： AUC提高，但旧任务保持或最终总体成功率明显下降。可以报告正向AUC，但不能宣称全面改善持续学习。
- 负向： AUC未超过71.5625%，或出现实质性训练/物理监督问题。

只跑一个seed不能证明统计显著性。若结果正向，后续需要其他seed及消融验证，但本次不自动执行。
