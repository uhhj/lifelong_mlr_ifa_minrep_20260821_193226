# PiPER 同步录制接入

已在实机桌面安装独立的 **PiPER 同步录制** 入口。录制器通过 V4L2 读取 D435i 俯视 RGB 和 D405 腕部 RGB，读取已绑定运行的 `can_timeline.jsonl`，由从臂发送回显确认关节和夹爪目标。程序不打开 CAN 套接字、不启动遥操进程。已有遥操程序和 STOP 通路不受影响。

每条轨迹包含两个图像序列、从臂反馈、当时生效的回显目标、带真实发送时间的原始动作、主从报文片段，以及任务、初态与结果。图像记录主机接收时刻，用同一单调时钟对齐。持位沿用已确认的关节和夹爪目标并保留原始时间戳。基底三项和增量三项的任务文字已按固定桌面布置录入。

录制台默认使用“试采”，在选定任务和起点、完成现场绑定并收到有效关节及夹爪目标后可开始。撤爪并确认终态后选择结束结果，等待保存提示。试采和专家示教写入各自的目录。每条记录保存同步覆盖检查与 SHA-256 文件清单。

2026-11-18 的离线验证通过 6 项测试，覆盖高跟随回显、跨组隔离、持位、断续文件写入、双相机配对与 episode 清单。使用已完成运行重放 136,976 条发送回显并检查 4,437 组状态—目标对应，其中 2,234 组为超过旧鲜度阈值的真实持位。两台实机相机同时输出 640 × 480 彩色帧，连续一秒配对 30 组。部署后验证了文件哈希、入口权限和依赖导入。移动中的图像—状态—动作同步仍待现场试采。本次未采集或发布专家示教。
