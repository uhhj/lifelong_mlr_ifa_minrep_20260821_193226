## 按钮行为与验证范围

[窗口](resume_preview.py)复用既有急停面板，接入内存模拟总线。用安装了 PyQt5 的 Python 执行 `python resume_preview.py` 可查看当前直连条件下的提示。使用 `python resume_preview.py --simulate-handoff` 可演练假设控制权已可靠交接后的流程。两种方式都使用模拟输入，模拟按钮不会操作硬件。

演练从点击 STOP 并收到新反馈开始。操作者先确认操作臂已得到支撑，再模拟复位。收到正常状态和六轴失能反馈后，操作者单独确认重新使能。六轴反馈齐全时显示模拟使能结果。新的 STOP 可中断演练。控制权交接、姿态对齐和六轴反馈均由模拟器提供，现场设备目前没有接入这些恢复条件。程序没有定义实机复位或使能的报文序列。

[离线检查](verify_resume.py)使用 Qt 按钮信号覆盖重复点击、旧急停状态、反馈中断、接口断开、故障、姿态偏差、交接未确认、部分轴应答、等待超时及 STOP 抢占。复跑命令为 `python verify_resume.py`。现场测试使用已部署面板的临时副本、Qt 离屏模式和禁用 Python 套接字的测试进程。

厂家双臂说明指出主臂持续发送目标，另用上位机单独控制从臂时需要断开主臂。单臂上位机文档列出的复位和重新使能步骤尚缺在该固件、双臂在线条件下的适用依据。现场接入还需确认该模式支持的暂停主臂输出、解除急停及交回跟随控制的顺序和对应反馈。此前主臂静止时操作臂抽动的原因也仍待排查。[官方双臂直连说明](https://github.com/agilexrobotics/piper_sdk/blob/master/assets/double_piper.MD) · [官方上位机功能表](https://github.com/agilexrobotics/Piper_sdk_ui#22-功能)
