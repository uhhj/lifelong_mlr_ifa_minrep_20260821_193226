# 实现边界

新模块 caet_v3_exp，复用冻结v2完整环境源码中的 coreset_exp/ra_exp 与原评估入口，不覆盖旧版本。三个ENTRY独立目录、合同、输出、预检及完整预算。EFTR不使用对齐标签参与训练；共享标签审计只是数据身份材料。

TAC的独立性意味着本轮没有EFTR候选检查，不能宣称具备组合模型的塑性保护。对比负对与额外读取规则在PROTOCOL先冻结。辅助头梯度采用与主路径相同loss_scale，梯度裁剪阈值沿用原cfg但独立裁剪头参数，头状态跨阶段保存。无额外10epoch效果拟合。主模型仅100键，额外头单独导出。

EFTR用PyTorch optimizer.step实际生成三候选，保存/恢复参数、梯度和完整AdamW状态；候选评分eval/no_grad，非选中候选不推进scheduler；提交后一次scheduler.step。teacher严格为本run各任务ep99，不是上一个任务统一教师，不是混合阶段最优NLL。旧检查批固定分任务交织轮换，每步最多32；执行KL评分使用当前实际argmax分量，训练KL针对教师模式索引，二者区别明确记录。无旧样本严格原RA路径。

零训练审计：5921窗口，5601合法下一动作，5561合法下一效果；Task7/8/9支持0/178/206。动作与效果mask分离；尾部仅缺效果的40个窗口仍参加对齐BC。原padding和身份歧义窗口不造标签。仅当前task扫描原始示范，旧数据只保留选样侧车。已看过历史结果，探索性设计披露。

TAC/ALIGN Task6模型可能因监督改变而与父RA不同，此差异记录不当工程失败。EFTR Task6仍要求实际tensor精确同父。三组初始tensor和RNG必须同父，四阶段IFA/成员原载荷仍须一致。

预检是隔离真实GPU优化与构造测试，无环境；通过只表示功能及恢复正确，不代表闭环性能。正式结果须独立全矩阵验收。目录仍PARTIAL，未准入前不称训练启动。
