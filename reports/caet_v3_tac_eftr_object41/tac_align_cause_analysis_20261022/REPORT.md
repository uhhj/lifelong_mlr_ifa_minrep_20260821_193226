# TAC 与 ALIGN：证据支持的解释及尚未证实的机制

2026-10-22，本地只读复算。依据已验收的 OBJECT seed41 完整矩阵、105500步辅助账目、冻结设计及实现。未训练、未模型前向、未运行环境、未改变服务器。脚本 `../analyze_tac_align_causes.py`，原始复算 `LOCAL_ANALYSIS.json`。

当前最有依据的解释：BC时间目标修订与TAC辅助任务要分开看。ALIGN的总体收益集中在Task9；TAC额外监督未把效果预测和跨任务相似性转化为稳定的控制收益，并伴随更差的新任务学习及最终旧任务表现。不能把具体原因已确定为梯度冲突、过拟合或错误物理标签。

## 1. ALIGN的提升不是所有任务都因时间对齐而变好

|对AUC差值的贡献 pp|-1.5625|-1.25|0|+11.25|+8.4375|

Task9从45%到90%，足以抵消其他任务损失。Task6刚学完反而从60%降至35%。这支持“本seed总体分数提升且任务间得失明显”，不支持“所有任务的时序错位问题均被修复且性能均提高”。ALIGN还改变合法mask及有效监督量，不能把结果单独归因于索引移动；稀疏20episode/格及单seed也限制泛化结论。

Task7对比锚点与cross_loss逐步均为0，但刚学完已经75%对95%。因此“仅Task8/9跨任务正负对导致全部退化”的解释不成立。早期效果回归以及此前累积的参数差异需要被考虑。Task6两组闭环同为35%不代表参数相同；不能据此把Task7差值全部归于Task7当阶段回归。

已逐步核对两组105500次batch_ids、step、BC有效/无效及当前任务有效数完全一致，样本身份及hash、mask一致。原最终验收也核RA成员载荷、IFA、初始化、预算与评估协议。当前证据不支持少训练、BC样本不同或7步输入导致这次TAC−ALIGN差值。

## 3. 实现允许辅助目标改变控制表示，但没有控制收益门

TAC将BC+.1IFA+.03效果回归+.02跨任务对比联合反向更新共享Temporal。效果头输入共享隐藏表示与真实专家下一动作；正式GMM直接收到BC梯度，仍依赖被辅助任务改变的共享表示。`observe.py`没有本轮TAC的BC冲突门、候选更新检查或旧任务保护；这符合冻结协议，不是EFTR机制失效的复用。

因此，辅助任务与控制任务存在表示需求冲突，是合理但未实测证实的解释。效果预测要求描述“动作之后发生什么”，BC要求决定“现在应选择什么动作”；前者的训练误差下降不等于后者改善。专家动作可能让预测头更容易利用动作信息，是否形成捷径仍需动作置换/消融或留出验证，当前不能断言。

无直接GMM辅助梯度并不意味着不影响GMM输出。共享表示变化足以影响其输出；主参数共同梯度裁剪也可能间接改变实际更新尺度，但未测定本轮此效应。正式账目只保存损失标量，没有分项梯度夹角/范数，不能凭.03/.02系数或预检梯度非零断定辅助梯度压过BC。

## 4. 跨任务效果相似不必然等于策略表示应相似

对比投影建立在共享Temporal表示之上。匹配的物理效果可以来自不同物体位置、接触状态和专家动作；将相关投影拉近，是否仍保留当前任务控制需要的差异，并未由支持图证明。投影头有缓冲能力，因此也不能直接断言共享表示已经坍塌。

实现会向正负伙伴的Temporal表示反传；这些额外伙伴没有额外配套BC项，原主batch的BC仍正常存在。它为旧表示提供了辅助变化通道，解释了为什么“加入旧任务伙伴”不是旧任务保护保证。这是代码允许的机制，不是已测得其造成遗忘的结论。

Task8只有178/1470（12.11%）、Task9只有206/1229（16.76%）合法当前独立效果时刻有对比支持。17800/20600锚点曝光是各重复100次，不是新增独立经验。覆盖少且反复使用可能产生偏向局部操作阶段的表示；当前未做泛化诊断，不能把重复曝光直接叫作已证实过拟合。

## 5. 更低NBT掩盖了较低的初始学习锚点

Task7：TAC初始75%，后续75%/70%，该任务NBT=2.5pp；ALIGN初始95%，后续85%/85%，NBT=10pp。TAC最终更差，却由于起点更低而显示更小下降。

仅为解释的公共锚点算术：若用ALIGN刚学完分数作为共同锚点、保留TAC实际后续分数，TAC的NBT会从-4.166667变为+2.5，而ALIGN仍为-1.666667。此数不是替代正式指标，也不代表真实反事实训练。正式NBT原值保留，必须与OldFinal和逐任务轨迹一起解读。

## 当前结论与诊断优先级

本seed没有显示TAC辅助组合的总体收益；缺口同时涉及新任务学习与旧任务最终成功率。最值得优先检查的是“效果回归是否提供有用控制表示”及“共享表示更新是否与BC冲突”，而不是直接继续调跨任务阈值或引用旧v2时序矛盾。TAC/ALIGN本轮使用相同八步与下一动作目标，旧的七步或两个动作索引冲突不能作为本轮两组差异的解释。

若后续获得独立诊断授权，可在保存的同一检查点和同一batch上分别测BC、回归、对比的梯度夹角/裁剪前后范数，并按Task7与Task8/9、当前/旧样本区分；再检查效果预测的独立demo验证和动作置换基线。若需要实验归因，则需要效果回归单独/对比单独消融，属于新实验，当前未启动。不能用两组总结果拆出各辅助项的净贡献或给出多seed显著性结论。

EFTR继续保持用户提前终止，不纳入完整闭环比较。监控已经删除，不恢复任何取消实验。
