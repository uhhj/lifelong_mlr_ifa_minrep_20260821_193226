# EFTR 零训练 KL 分解：尺度放大与保护不足同时存在

2026-10-22 18:04 CST 观察。诊断对象为 EFTR OBJECT seed41 Task7 的 epoch64（第65个完整epoch）冻结恢复状态，累计30455个主更新。诊断独立读取完整原子检查点，未改变活动实验。

结论：巨大的历史评分主要来自少数 GMM 模式切换引起的夹爪均值正负号翻转，被约1e-4的标准差放大；但移除夹爪项后依然明显超过0.10预算。因此不能归结为纯尺度问题。候选选择规则实现并实际降低部分历史评分，但本阶段尚未达到冻结的历史保护目标。是否改善闭环遗忘仍待完整正式评估。

## 可加和的历史评分分解

冻结评分为 `R = mean(KL_teacher_exec_to_current_argmax / 7) + 0.1 * mode_switch_rate`。
每一维高斯KL进一步分为均值项 `(muT-muC)^2/(2*sigmaC^2)` 和方差项 `log(sigmaC/sigmaT)+sigmaT^2/(2*sigmaC^2)-1/2`。分解以double计算，逐样本独立校验加和。

|项目|对平均R的贡献|
|---|---:|
|6维机械臂KL / 7|3.589834|
|夹爪KL / 7|292663.500994|
|显式模式切换惩罚|0.007554|
|合计|292667.098383|
|冻结预算|0.100000|

夹爪占全部KL的99.998773%。机械臂贡献中，均值偏移为3.411546、方差变化为0.178288，故机械臂部分也不是单纯方差漂移。

59/781个样本发生模式编号切换（7.5544%）；其中8个夹爪均值正负号翻转，均值差接近2，选中分量标准差约1e-4。单个此类样本夹爪KL约2e8、除7后约2.857e7，因此仅8条即可支配平均分。这是高置信度相反夹爪输出的真实分布差异被连续高斯度量放大，不能把它当成无意义的纯浮点误差。这里只诊断均值符号和Gaussian正号概率，没有新增控制器执行或成功率测量。

显式模式惩罚0.007554很小，但模式切换会间接更换整个执行高斯。固定比较教师原模式编号时，平均KL/7为0.673992；改为实际argmax后，KL/7增加292666.416837。这个差值是两种分量选择的诊断对比，已包含在上表机械臂/夹爪项中，不能重复加到总R里，也不能用固定分量分数替代正式执行评分。

722个未切换样本的平均R仍为0.651841，约预算6.5倍。除去8个夹爪符号翻转样本，其余773条平均R仍为3.343365。没有模式切换并不意味着旧执行行为已保护到预算内。

## 候选机制是否工作

对Task7前65个完整epoch的14755个原始记录独立复算：C容差、R预算优先、词典序选择、三候选/单次提交计数全部通过。仅使用已保存标量，未重新生成候选或调用AdamW。

|检查|结果|
|---|---:|
|正式提交 / 原始候选调用|14755 / 44265|
|选中系数0 / 0.5 / 1|3154 / 2934 / 8667|
|选中R比原生更低 / 相同 / 更高|11318 / 3437 / 0|
|历史预算未满足|14736 / 14755（99.8712%）|
|原生候选平均R|300907.190516|
|选中候选平均R|300544.460771|
|平均R相对降低|0.120545%|
|已选当前NLL相对原生最大增加|0.0199871（容差0.02）|

原生候选始终满足相对自身的当前BC容差，因此流程可继续，但它不保证满足旧任务预算；三个候选都不满足预算时，冻结协议选择其中R最小者并记录失败，而不是回退到一个已满足历史预算的模型。这个机制从定义上就是有限局部择优，不能修复任意已有漂移。

训练保留KL针对教师分量kT，评分针对当前argmax。模式保持项是有限权重的软惩罚，并非模式切换硬约束。本快照显示这一区别确实重要：固定分量分数低很多，实际argmax仍出现59条切换。但固定分量平均0.674也未达0.1，说明不能只把责任归于argmax。

因此，本阶段证据支持“机制有实际局部作用，但保护强度/候选可达范围不足以满足当前预算”，不支持“保护已经成功”，也不能在闭环前断言对最终旧任务成功率完全无效。当前batch的C约束只保证相对同一起点原生候选的局部NLL，不保证与独立RA整段训练的塑性相同。

## 结论范围

逐维分解对应一个确定的已提交模型；历史每个候选的参数和逐维KL没有保存，不能在零更新限制下追溯重建各候选逐维变化。本报告不把当前快照的夹爪占比外推为每个历史候选都相同。候选总R对比来自全部已保存原始记录，两种证据分别报告。

本轮不更改实验参数、不重训、不增加正式评估；继续既定EFTR和后续ALIGN。最终判断仍需200条正式闭环及全矩阵验收。后续版本若要改变夹爪度量或候选规则，须另立协议，不能混入当前结果。
