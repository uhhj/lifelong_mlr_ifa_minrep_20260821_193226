# RA-Coreset 引言表述与实现核对

本次仅核对既有本地协议、选择器和论文方法草稿；没有运行训练、环境、远程检查或新的科学实验，没有改变实验接受状态。

## 结论

此前“在保留一部分随机锚样本的基础上，通过代表性选择补充回放集合”概括了随机性与代表性的结合，但容易被理解成先抽锚点、再填满核心集。这不是实际执行顺序。实际实现以原 greedy K-Center 集合为起点，通过必要的等量交换强制纳入随机锚。

## 实际算法

1. 当前任务原始窗口人口为 U，记忆配额 b = ceil(|U|/2)。先运行原 greedy K-Center 得到大小为 b 的 S0。
2. 按训练 seed 复现原 Random 的大小为 b 的无放回有序抽样，取前 floor(b/2) 个成员为受保护锚集合 A。
3. 按随机名单顺序处理 A 中尚未进入集合的锚；每加入一个锚，必须删除一个非锚成员，保持集合大小为 b。
4. 每次在合法删除候选中优先选择使全候选人口的最大最近距离最小的删除方案；最大距离并列时比较平均最近距离，再按原文件 ID 确定性打破并列。实现容差为 1e-12。
5. 交换次数恰为 |A\\S0|，锚成员不可删除，已有旧任务集合不重新选样。该规则是满足锚纳入要求所需的最少成员交换，不是全局最优核心集求解。

实现没有“覆盖半径不得比 S0 变差”的硬条件。因此不能把“每次合法交换中选择覆盖代价最小者”写成“最终覆盖半径必然改善”。样本单位是原训练窗口，不是完整轨迹。

## 对上一版介绍的逐项判断

- 固定回放配额、保留随机锚、使用代表性/覆盖性准则：一致。
- “先保留随机锚，再通过代表性选择补充”：应改为“以原核心集为起点，纳入受保护随机锚并进行等量覆盖代价最小交换”。
- “兼顾广泛取样与经验互补性”：可作设计动机，但不能等同于严格保存经验分布。
- “降低重复、提高利用效率”：不应写成该选择器逐次保证的性质；代码没有重复轨迹删除或关键事件判别规则。

## 建议用于引言的表述

在专家示范选择方面，本文引入随机锚定核心集 RA-Coreset，以代表性核心集为基础，将随机抽取的示范窗口设为必须保留的锚点，并通过覆盖代价最小的等量交换将缺失锚点纳入回放集合。在保持记忆配额不变的条件下，该机制将随机保留与代表性覆盖相结合，为后续学习提供互补的历史示范监督。

上述表述不引入特征细节，执行方向与实际选择器一致。现有 LaTeX 方法草稿 sec04_method.tex 已按 S0→缺失锚插入→非锚删除描述，无需修改科学实现。
