# B1 原始 ODE 训练端与执行台同窗复算

比对原 16 对摆位及跨批次 20 条示范。52 条共 3384 个滑动八步窗口，互不重叠的窗口有 444 个。按示范 ID 与真正入训清单核对，重合 0 条。训练侧另核对真实的 50 条、9731 行缓存，控制窗使用同样的专家分组和非重叠取窗规则。

采用相同零偏移时，八步中任一步两端的最大夹口差只有 0.0130 mm。原始 ODE 在未入训纠偏和下降窗的错向数为 71/183 和 15/29，两条路径的方向判定分别翻转 0 和 0 个。与实际训练缓存对照，现有证据把主要问题定位到已训练策略在未见示范上的泛化，尤其是较早批次。历史验收与现场的混合分量选择另有可测差别。

## 输入、标签及采样时刻

- 两路相机分别按角色读取。同一源图在训练转换中经 RGB、上下各补 80 个黑色像素、面积插值至 128×128、转 CHW、除以 255。评估时中心裁剪 112×112 并做 ImageNet 标准化。执行台单帧编码并缓存八帧特征，训练评估一次编码八帧。两路最终视觉张量的逐元素最大差分别为 0、0。
- 第 t 帧观测包含 t−7…t 的反馈；起点是 t−1 已下发指令，监督是 t…t+7 八条绝对指令。前六维是弧度，第七维是毫米。用实际训练采样器逐元素比对，状态、锚点、八步标签最大差依次为 0、0、0。按训练源转换重建的图像与真实缓存逐张核对，俯视和腕部 uint8 最大像素差为 0、0。所有训练行的时间戳、状态、指令和锚点都复核过。
- 状态与动作各用其训练集逐维最小、最大值做线性映射。独立重算与两端实际归一化的最大差为 0。反归一化浮点往返最大误差为 0.00000763（各维原单位）。
- 逐一比对帧名与源单调时钟，最大舍入差 500 ns。去重后，双相机时间差中位数／P95／最大值为 14.62／18.22／19.92 ms；相机采样间隔中位数 33.35 ms，六轴目标中最旧分量的年龄 P95 为 73.79 ms。
- 反馈位移取 t 到 t+8；监督位移另按同一实测起点比较 t+7 指令，并把标签终点前后各移动一帧。等效时序筛选要求窗内双相机最大差 <16.67 ms，最旧六轴目标和反馈均 <33.34 ms。

## 解释范围

52 条均以真实示范反馈和实际上一条专家指令为条件。未入训示范的训练侧输入从原始文件按归档导出转换重建，并调用原 TrainingFrames.batch；训练对照直接读取原来持久化的缓存。核对了两种算法路径的同窗一致性、训练缓存的源数据和部署的运行版本。回放没有调用设备接口，也没有重训。离线结果可以定位到输入、推理实现或已学出的预测，但不能凭一个检查点区分训练时长、增强、样本覆盖与损失权重各自的因果贡献。
