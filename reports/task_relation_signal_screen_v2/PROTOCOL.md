**性质：待执行、待冻结的实验协议，不是已完成的实验。**

**核心目标：在训练结果发生前计算信号，检验它是否能预测固定预算下的目标迁移收益和源任务损伤；有效以后才研究门控、正则、回放或更新控制。**

## 1. 目标、符号与“共享/冲突”的操作定义

对源任务s、目标任务t、下游优化seed k：
- theta_b：相同共同基座。
- theta_s：从基座对源任务训练1000个原生调用步后的参数。
- theta_st(K)：从theta_s适应目标任务K步。
- theta_bt(K)：从基座直接适应同一目标任务K步的参照。
- P_t(theta)：官方闭环执行规则下任务t的成功概率；观测成功率不是无噪声真值。

主终点K=300，全部标签使用闭环成功率：

```math
Y_T(s,t,k)=P_t(theta_st(300))-P_t(theta_bt(300))
Y_D(s,t,k)=P_s(theta_s)-P_s(theta_st(300))
```

Y_T>0是固定目标训练预算下的正迁移，Y_T<0是负迁移；Y_D>0是源任务损伤。两者可同时为正，不是互斥标签。该定义不替换LIBERO官方FWT。

辅助量：原面板已有的TRANSFER_0、ACQUISITION_DIFF_300、逐任务绝对成功率、100步与300步离线NLL。新面板不额外要求所有源模型在目标任务上做零步闭环；不据缺失数据声称新面板的TRANSFER_0已测。

决策展示用预先固定的实际效应带epsilon=0.05，即5个百分点：
- 迁移有益：Y_T>0.05。
- 负迁移风险：Y_T<-0.05。
- 旧任务损伤风险：Y_D>0.05。
- 高收益且低损伤可以标为“值得共享的候选情形”，但不叫已发现共享知识。
- 不能把点估计没有跨门限视为确定安全；区间跨带时标记不确定。

所有样本参加连续指标。类别评价附带区间和可辨别覆盖率，不能删除难以分类的任务对来提高准确率。5pp是本实验的实际效应定义，不是自然规律或已验证的机器人安全阈值。

## 2. 两个预测时点，分别比较

### C0：零策略更新

允许：少量源/目标演示、原模型前向/反向、固定表示上的闭式辅助线性模型、LogME。禁止：实际推进策略参数或读取后续结果。

辅助线性读出虽不改变策略，也使用目标标签和计算，不能称为无数据/无计算。

### C1 / C5 / C20：允许有限试学反馈

在原目标训练轨迹上，记录第1、5、20次**有效参数更新**后的前缀。有效更新须同时有非零LR且可读出的实际参数位移不为0。
- 保留原预热步骤、batch顺序、optimizer/scheduler更新顺序；不跳过零LR步骤，不提高LR来制造信号。
- 用k_q表示获得q次有效更新所需的实际调用步数；最大探测前缀为50个调用步。
- 若50步内未达到某q，标记该探针UNAVAILABLE，不用后来的步替代，不阻塞C0。
- 两支theta_s和theta_b使用相同目标训练流、相同调度规则，按同一调用步k_q比较。两支实际更新次数不一致要报告。
- k_q必须小于300。探针就是300步轨迹的前缀，不重置并另起一条轨迹。

C20是主动态时点，C5检验更低成本，C1主要对照原失效探针。不能从三个时点挑最好结果再声称事先预测。C20成功只能说明“少量试学后可预测”，不能据此宣布C0成功。

## 3. 总体安排：开发筛选与完全独立任务确认

### Stage A：现有4任务开发筛选

复用T6–T9、12有向关系、seed45/46/47全部36行和已有闭环终点。补计算候选信号，不重新生成2880次rollout。

重建缺失的前20次有效更新仅从合法源模型及正确目标初始化开始，执行原前缀。保存LR、步数、参数hash、数据序列；不能用中后期起点替代。若原始状态无法重建，可该单元动态缺失，不能把旧终点任意配给新轨迹。

已有标签看过，因此Stage A整体是探索/开发；交叉验证也不能恢复它的独立确认身份。筛选不要求开发集p<0.05，否则可能因只有4任务过早排除候选。所有预登记且技术有效的家族都完成测量，不根据中途相关性删家族。

### Stage B：6个新任务的前瞻确认

默认从LIBERO-GOAL选3个、LIBERO-SPATIAL选3个；必须在实际资源、任务定义与暴露审计后填写canonical IDs，不能凭编号或物品名称推断。

选择规则：
1. 仅纳入当前观测、动作接口和序列长度处理可兼容的任务。
2. 排除共同基座机器人专门预训练任务、旧4任务以及BDDL/演示实质重复的条目。
3. 每个suite从符合条件的任务中，用已有冻结语言编码器对官方任务指令编码；第一个取canonical ID字典序最小者，其余用最大化最小余弦距离依次选取，平局按ID。
4. 选择只使用任务文本、静态接口和暴露信息，不使用成功率、迁移结果或已测关系指标的标签拟合效果。
5. 冻结6个任务后不根据表现替换任务。若不足6个合法任务，在Stage B训练前报告，不能静默借用已暴露任务；另行冻结替代面板。

新任务组成全部30有向对，使用下游seed48/49/50（若已用于相同目的，按预先登记规则改为三个未使用seed并记录），共90个seed×任务对。12个同suite方向、18个跨suite方向分别报告。它们共享当前官方基座，并非3个独立预训练基座。

Stage A结束即冻结预测器、候选、阈值和评估代码；Stage B每条C0预测在训练前封存，Cq预测在其前缀终点封存。之后才读取300步闭环结果。任务描述的存在不破坏盲测；源/目标后续性能不可用于重选模型。

Stage B是否执行由预登记预算与数据可用性决定，不取决于任务对残差显著，也不要求Stage A出现漂亮相关性。

## 4. 数据角色与接口冻结

每任务按完整demo轨迹分为30/10/10：
- A_train：唯一策略训练数据。
- D_signal：唯一关系信号数据，源任务部分作为已存记忆计算成本。
- E_eval：只供独立离线评价，禁止进入信号、归一化、linear probe、候选筛选。

少于50条时沿用60/20/20固定比例，不跨角色补样；大于50条先按固定hash选50条。老任务使用旧划分，不能改变其既有标签对应的训练数据。

D_signal每任务最多128个窗口，按轨迹等额、时间均匀取样。逐样本梯度仅使用其中固定32个窗口。E_eval最多320个窗口。padding、动作标签长度、末状态/动作块等语义完全以现有管线为准，不按文字猜形状。

D_signal再按demo身份固定分成D1/D2，各5条，用于辅助读出的交叉拟合和信号重复性检查。D1/D2都属于可访问的信号预算；不是独立闭环证据。

动作维度统一使用基座预训练训练数据的既有尺度；没有可验证尺度时，按各源/目标A_train的训练部分冻结标准化，不用E_eval。跨任务专家动作不得按任意时间索引一一配对。不同坐标系不能直接做欧氏动作距离。

新旧所有信号必须能在实际部署信息预算下获得。动作相容性只使用目标窗口的同一输入分别送入源模型和基座，不强行让不同任务的输入相等。

### 5.1 S02：结构距离

固定取时序解码器送入策略头的表示，按真实mask进行固定池化。源/目标表示均由相同theta_s生成。
- 每维尺度只从合法D1拟合，D2评价后交换方向取均值。
- MMD使用一个RBF核，带宽用训练侧D1的两任务联合表示距离中位数决定，不用终点标签。
- 不对两个未对齐任务样本集合直接计算配对CKA。

### 5.2 S03：既有Mean-GN

沿用现有输出定义、Wa、policy-head参数顺序、rank16。不同任务基必须在同一个theta_s点估计。
`overlap = ||U_s^T U_t||_F^2 / 16`。
0附近特征值造成rank不足时报告实际有效rank/缺失，不人为补齐。Stage A能复用的资产直接复用。Stage B仅在它进入冻结候选时才需要额外构建，其他方法不能替它负担免费成本。
GN只描述期望动作，方差等完整GMM信息不在其范围；不得称其为“全部旧知识”。

### 5.3 S04/S05/S06：行为相容性

对目标窗口i定义：
`a_i = NLL(theta_b; i) - NLL(theta_s; i)`。
先每轨迹平均，再轨迹等权得到S04。S05同样比较同一目标数据上的标准化期望动作误差和夹爪误差；绝不把不同源/目标示教的动作均值直接当兼容性。

S06：
1. 各轨迹平均a_i的最低20%均值（10条demo时是2条，不假装精确估计连续CVaR）。
2. 归一化时间前/中/后三段的a_i均值之最小值。
3. 标签夹爪指令发生转换的窗口a_i均值。

均值、分布尾部与阶段量单列。时间段不称为reach/grasp/insert；夹爪标签变化不称为接触真值。没有转换窗口时该分量缺失并给出mask，不替成最好值。预测熵/混合尺度只做校准诊断，不把高熵直接解释为危险或低质量。

### 5.4 S07/S08：区分“旧读出不匹配”和“表征不可利用”

S07固定source/base的解码器表示，各自只训练辅助线性头映射到目标专家动作。D1拟合、D2验证，再交换，平均两个验证误差。

令E_s为使用源表示的交叉拟合误差，E_b为基座对应误差：
`S07=(E_b-E_s)/(E_b+tau_MSE)`，tau_MSE为数值稳定项并固定。
岭回归目标为 `mean standardized_action_MSE + 1.0 * ||W||_F^2`；带不惩罚截距；按输出维度平均。标准化在训练半侧完成，验证半侧只应用训练变换。此为预登记变体，不照称原论文的训练集Linear MSE。

S08把输入特征替成源模型预测的期望动作向量，用同样交叉拟合辅助仿射映射。衡量便宜的输出重映射是否足够，不能据此解释成直接行为共享。正式GMM头不替换，策略参数不更新。

### 5.5 S09：LogME

核实并冻结作者代码或等价数值实现的版本，使用回归模式和同样的固定表示/动作标准化。报告source与base原始值及差值。官方定义/算法内部的证据参数估计可以执行，但不按最终迁移结果调整实现。
不加入动作分箱版LEEP、NLEEP、H-score等分类指标；这会引入新的标签空间设计且不是直接适用的机器人信号。

### 5.6 S10：条件匹配而非无条件动作距离

此包是自定义研究假设，不能标成“论文OTCE已验证”。
- 用共同基座冻结的视觉表示与机器人本体状态组成匹配表示，语言不参与匹配距离，但原始任务身份及指令始终保留用于模型前向。
- 用目标窗口到源窗口的5-NN做有向匹配；不以专家动作挑邻居。
- 距离尺度及覆盖阈值由源D1到源D2的跨轨迹近邻距离分布冻结，覆盖阈值取其95%分位。
- 输出目标覆盖比例、被覆盖部分的专家动作不一致度、对应夹爪不一致度。
- 自源跨轨迹动作不一致度作为参照相减，减少任务固有示教分散的影响。
- source→target和反向分别计算，不能把对称距离强行称为有向迁移。

若没有同坐标语义或有效覆盖<10%，标记该动作不一致估计无信息；覆盖比例仍可保留。不能强行补足近邻、使用动作筛选或加模拟器真值。5NN、95%与10%均是本轮冻结工程选择，不据终点调参。

### 5.7 S11/S12：梯度与位移只作信号

S11在同一theta_s用固定D_signal子集的官方NLL得到g_s、g_t，计算带符号cosine。参数载体为同一可训练decoder+policy head，不混head-only与全参数范数。

S12使用真实首个有效目标AdamW更新的位移d。对源D_signal固定32窗口在该更新前参数点求h_i，记录：
- h_i^T d的轨迹等权均值；
- 轨迹/窗口分层的上20%均值（原始值与标准化值都保留）；
- 超过既有数值deadband的正比例。

作为信号的统计量，不把它当损伤真值。不生成半空间约束，不建立Gram求解，不执行QP或投影。原生零LR第一步照常保留并标记无信息；不得拿人为单位化步长冒充原生有效位移。

### 5.8 S13/S14：有效试学关系

定义q有效更新时（真实调用步k_q）的目标进展：
`G_st(q)=L_t(theta_s;D_t)-L_t(theta_st(k_q);D_t)`。
对应无源基座进展：
`G_bt(q)=L_t(theta_b;D_t)-L_t(theta_bt(k_q);D_t)`。
目标相对进展：`G_rel(q)=G_st(q)-G_bt(q)`。
旧损伤：`H_s(q)=L_s(theta_st(k_q);D_s)-L_s(theta_s;D_s)`。

S13为G_rel(5)、H_s(5)、源损伤上20%轨迹均值。
S14为q20的上述3量，加H_s(20)-H_s(5)。

同时存G_st、G_bt和当前源/目标NLL用于诊断。S14增加信息不等于零试学能力；给出每种探测预算的总成本。源task已经训练1000步，目标probe只读A_train，D_signal只评价，E_eval完全隔离。

## 6. 基线、预测器与候选选择

### 6.1 必须超过的基线

B0由三个可得标量构成：
- 基座目标D_t NLL（目标难度代理）；
- 源模型源D_s NLL（源掌握度代理）；
- 基座与源模型在D_s上的NLL差（源学习进展代理）。

此外保留：常数预测、旧IFA预测器、旧A模型。在Cq比较中加入同预算“基座自身目标进展G_bt(q)”作为Bq，防止动态候选仅因得到额外目标可学性信息而显得更好。Bq不含源→目标相对进展或源损伤。

源自任务闭环成功率用于结果分层和损伤可观察性，不免费作为零成本预测输入。任务ID、seed编号、历史目标均值不进入预测器。source/target效应分解最多做附录，不作推进门。

### 6.2 同一低容量预测头

迁移和损伤分别训练，不把二者合成一个二分类。每个候选=B0/Bq+一个包。主预测器为固定强度岭回归：`mean squared error + alpha * ||beta||^2`，alpha=1.0，不惩罚截距。

预处理必须每折只在训练关系拟合：
- 原始有物理界限的余弦/比例按已有界限缩放。
- 其他标量先使用预登记的asinh压缩；尺度来自训练折的非零中位绝对值，至少取数值测量噪声与registry物理尺度下限。
- 再做训练折中心化和方差缩放；低于登记下限的近常数列直接置零。
- 训练变换应用到验证，不重新使用验证集合拟合尺度。
- 新输入超训练范围只记录OOD标记；固定z值限制[-5,5]适用于所有模型。
- 原始预测保存；主预测因标签为概率差，在预测前就固定限制到[-1,1]。这是v2预登记设计，不改v1原始输出。另报不裁剪敏感性。

具体数值尺度由无标签的6个技术单元估计测量重复噪声后写入REGISTRY；冻结前不能看到新增闭环终点。不得为了MSE更好调整方差阈值。数值测试包含近常数特征，避免几十万的外推。

不调十几个回归模型。alpha=0.1和10仅作预登记稳定性附录，不选其中最好值当主结果。没有可靠连续校准时允许只报告排序用途，不强迫输出概率或精确百分点。

### 6.3 开发集留出

对T6–T9做严格留任务：留出t时，训练中同时删除所有source=t或target=t的行。另做留seed稳健性。所有预处理、拟合和任何组合选择都在训练端完成。

本轮有14包，必须完整公布。开发筛选仅选择，不声称验证。

进入Stage B的正式候选最多六个，即对每个终点固定：
1. 既有动作相容性A作为复验候选。
2. 新的最佳C0包；按四折宏平均MSE选择；平局依次按更低计算量、更少维度、ID。
3. 动态C20模型：B20+S14；仅允许在开发中选择是否加一个最佳C0包，额外特征总数不超过6；选择规则同上。

不要求候选在开发集显著，任何“最好”称作开发排序。相同特征的重复模型合并，正式检验数随之减少。其余固定信号可在新面板做描述性检查，但不能在Stage B看完后改成新的主候选。C1/C5是探测成本曲线附录，不从中追加正式胜者。

## 7. 三层评价，不只看全局Spearman

### 7.1 连续预测

主指标：按目标任务宏平均的paired MSE差，候选与B0/B20分别比较；辅以MAE、校准斜率、截距、逐seed/逐目标结果。

同一个y用于比较两个模型，差值为(p1-y)^2-(p0-y)^2，二次y项抵消。这不消除噪声，但强调应比较配对损失而非独立MSE区间。

### 7.2 同一目标下的源排序

固定目标t和seed，比较各source的预测/真实Y_T排序：Spearman、Kendall、pairwise ranking accuracy。目标无源参照共享，所以目标内排序不被不同目标整体难度直接支配。

对损伤另报同一source下不同target的风险排序，以及固定target下不同source的损伤排序。相同率或全部相同的单元标记无排序信息，不能记为满分。目标整体收益方向与目标内源排序是两种用途，不能互相替代。

### 7.3 决策相关指标

5pp效应带下的正迁移、负迁移及损伤判别，附不确定覆盖率。重点报告误放行（预测低风险而实际明显受损）与误抑制（预测负迁移而实际明显有益）。

固定目标下按预测选source或选择“无源基座”；定义选择遗憾：该次真实最优候选性能减所选性能。真实最优只用于评估，不给选择器。基线为无源、均匀随机source期望以及B0选择；既有A选择也列出。

组合选择规则仅作后续门控价值的低成本检查：预测Y_T>0.05且预测Y_D<=0.05时，取预测Y_T最大source，否则无源。冻结point规则不冒充可靠安全概率。迁移和损伤可分别具备价值，不要求同一signal同时赢两项。

## 8. 统计与“存在信号”的裁决

### 8.1 数据依赖

共同base、每源一个theta_s、每目标共享reference、相同环境初态，都形成依赖。不能把窗口或rollout数量当任务关系样本数；三优化seed不等于三独立基座。

每task×seed的同初态索引，在所有受测模型、source自评、target reference中共用重采样索引。同一个共享reference不可为每pair独立重采样。有效迁移与损伤标签每次从原始trial数组重算。

### 8.2 两套区间，明确解释范围

主确认区间：5000次固定任务/固定模型面板的配对初态重采样，预测器已冻结不重拟合，估计在这六新任务及这些模型上的执行评价不确定性。对至多六个正式candidate-endpoint MSE差构造max-T同时95%区间（零方差项单独处理）；实现对人工可解析样例校验。该区间不提供所有任务总体的保证。

稳健性：整seed删除、整任务节点删除（删除与该任务所有相连方向）、按任务等权的描述性node bootstrap。任务只有6个、seed只有3个，区间要标为小面板敏感性而非高精度总体置信。不得通过重采样方案择优。

开发模型的不确定性另用开发seed/无序任务对块的重采样和重新拟合描述；不与主冻结模型区间混成同一个统计对象。

### 8.3 主判定

分别输出：
- CALIBRATED_FORECAST_VALUE
- SOURCE_RANKING_VALUE
- NEGATIVE_TRANSFER_WARNING_VALUE
- OLD_DAMAGE_WARNING_VALUE
- PROBE_INCREMENT_VALUE
- COST_VALUE

可校准预测获得新任务面板支持，需要：
1. 该终点MSE相对对应简单基线的点估计至少降低5%；
2. 主配对同时区间排除零、方向有利；
3. 至少4/6个新目标宏单元改善，逐seed不出现收益完全依赖单seed；
4. 去掉任一任务节点后不能把显著灾难性退化隐藏掉，完整敏感性展示。

5%和4/6属于本轮预登记的实际决策标准，不是普适科学定理。结果区分：SUPPORTED_ON_NEW_TASK_PANEL / PROMISING_NOT_CONFIRMED / NOT_ESTABLISHED / UNINFORMATIVE。

若MSE不支持但排序显著有用，可以单独判RANKING_ONLY；它可支撑后续源选择研究，不能直接支撑按概率调正则。
若仅damage有效，保留损伤预警用途，不要求先证明迁移预测。若只NLL有效而闭环无支持，不能用作行为级共享/冲突结论。

不存在任何结果能证明“所有关系信号都不存在”。负结论限定为所测14包、数据预算、优化协议、任务面板及预测时点。

## 9. 有限的组合、重复性与负对照

每个包在D1/D2分别计算，记录信号值相关/符号稳定性和噪声；不稳定本身是结果。主值取冻结等权合并，不能选更好的半边。

额外检查只允许：
- 动作相容性A与一个readout-learnability包的联合；
- 已有A与C20反馈的联合。

不允许所有包全拼后宣称复合信号成功。若复合进入正式候选，消融“只基线、只A、只新包、联合”在同一任务划分评价。

负对照：
1. 模型/参数未更新时反馈应为0；原零LR探针作为真实负对照保留。
2. 打乱source-target对应的关系包，保留基线特征与任务/seed分组，再评估开发OOF（1000次组块置换描述性）。
3. 人工构造单调可预测标签，确认评估管道能检出而不是处处INCONCLUSIVE；它只是软件测试。
4. E_eval访问保护：信号进程不能读取评价路径，写出实际访问清单。

## 10. 独立任务训练与闭环预算

Stage B策略训练规则沿用v1：
- 原模型结构、动作输出、NLL、clipping、数据流处理不变。
- 每任务源训练1000个调用步。
- 每有向对目标训练300个调用步，无replay。
- target optimizer从同一冻结初始规则重置，不继承source moments；每个source→同一target与base→target的batch流完全一致。
- 学习率按原生调用步定义，不因一个run计划终点为300、另一个为1000就偷偷重缩放调度。
- 相同前300步配置、RNG与数据流时，源模型300步保存点可复用为base→该target参照；必须验明，不能假定。否则显式独立训练reference。

默认主预算：
| 类型 | 数量 | 每项预算 |
|---|---:|---:|
| 新源模型 | 6×3=18 | 1000步 |
| 有向适应分支 | 30×3=90 | 300步 |
| 无源reference | 6×3=18 | 前缀完全相同时复用，否则300步 |
| 正式lifelong续训 | 0 | 0 |

更新总量：45,000步；若reference无法复用，上界50,400步。C1/5/20直接保存前缀，不再添加另一套学习轨迹。

Stage B闭环组合：
| 对象 | task-model-seed组合 |
|---|---:|
| 基座在6新任务 | 18 |
| 18源模型在自身任务 | 18 |
| 18无源reference在目标 | 18 |
| 90迁移模型各测source和target | 180 |
| 总计 | 234 |

每组合固定40次有效rollout：`234×40=9360`。不是9360个独立任务关系。基座/共享reference只评价一次，后面引用同一原始数组。

每次按同task×seed配对环境初态、真实策略输入、动作采样规则；随机策略使用相同规则和可复现随机流，分支轨迹不同后不要求所有中间状态一致。不以辅助非输入浮点字段完全相同作为错误硬门。

旧4任务Stage A默认0新增闭环。技术smoke最多2个新任务对的训练及对应评估，计入9360，不另加预算；只决定环境能否运行，不按效果替换任务。

资源：允许3090、4080S、4090，GPU UUID不是身份硬门。优先缓存相同source模型的旧任务梯度、公共基座表示、目标前缀reference。计时分开报告source/target训练、信号、闭环和统计。上一轮约17.5小时用于2880次有效闭环；按该平均速率9360约57小时，仅是粗略外推，新suite时长、并行度及硬件会改变它。先用计入总预算的smoke重新估时，不保证完成时间。

预算不足可在Stage B读取任何终点前另行冻结20次版本（4680），并明确低功效；不能看到40次结果的一部分后按显著性早停/扩样。完整推荐协议默认40次。

## 11. 不把识别实验擅自改成控制器实验

本轮预测的是v1无回放固定预算条件，不自动代表原生MLR中的效果。若找到新任务面板上有用信号：
1. 先报告其是C0还是试学型、预测transfer还是damage、能排序还是能校准。
2. 下一独立协议在原生MLR恢复回放和真实优化器状态，检验适用性。
3. 再比较基线、固定强度保护、信号门控保护、打乱信号门控，匹配平均保护/回放预算。
4. 正则、回放权重、更新控制是下一阶段的候选，不在本轮同时实现。

不以“需要找到知识块”拖延信号实验；不以pair交互残差是否显著决定信号有没有意义。

## 12. 技术检查与故障规则

只设三种硬门：
- 身份正确：共同base、task ID、源模型、optimizer/scheduler与数据流相符。
- 信息边界正确：训练/信号/评价demo隔离，预测时间早于终点结果。
- 数值测量有效：有效步真实写入、损失尺度与mask正确、信号非无意常数、预测器近常数处理正确。

下列不作为硬门：GPU UUID相同、QP/KKT/写回半空间阈值、每源已100%掌握、每个信号均有方差、每任务都能取得正收益。

源成功率为0/40仍保留；报告能力地板限制，不能叫不遗忘。允许某信号UNINFORMATIVE而继续其他包。损坏checkpoint/错任务/数据泄漏则该单元停止并保留，不静默换seed。

所有模型、优化器、scheduler和RNG在影子测量前后核对。梯度额外前向不能无意修改BatchNorm、dropout状态或训练数据指针。技术重复只用于确认，不制造新的关系样本。
