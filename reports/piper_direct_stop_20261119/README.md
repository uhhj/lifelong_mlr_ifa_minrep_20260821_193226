# PiPER 官方直连现场软件停机

2026-11-19 16:23:27（北京时间）核实，现场桌面「PiPER 操作臂 STOP」入口已安装，置顶窗口「PiPER 操作臂软件急停」可见。经现场授权，原硬件只听的单个 can0 已切换为 1 Mbit/s 正常收发模式。切换前确认接口与适配器身份，且无采集或转发程序在运行，两次总线收发采样一致。切换前后及开窗后的主机 TX 累计计数均为零。操作人员之前报告已经拔掉机械臂电源；本次没有远程启动机械臂或发送实机 STOP。

## 现场操作

按红色「停止操作臂 STOP」即可提交停机请求，无需再确认。窗口分别显示 SocketCAN 提交结果和来自操作臂的急停状态。未收到反馈时会明确提示使用现场实体急停。按钮发送固定的厂家 STOP 报文，无复位、使能、回零或运动功能。厂家说明软件停机后，手臂可能在阻尼作用下缓慢下落。 [AgileX 停机行为说明](https://github.com/agilexrobotics/piper_sdk/issues/20)

核对依据是同一已选接口上的外部状态帧（0x2A1）在本次提交之后报告急停状态。此前排队的旧帧、本机回显和其他 ID 均不能确认停机。反馈丢失时窗口显示当前状态未知。首次按下后立即提交，未确认时以约 100 ms 间隔有限重发，共至多三次；600 ms 后仍未确认即告警。这是按钮的确认提示，旧转发进程的 500 ms 看门狗不在官方直连路径中。反馈确认表示控制器报告的状态，未测机械停止距离或安全性能。

正常模式允许本机其他有权限的进程使用 CAN。面板仅发送 STOP，采集程序和原始监听器仍只接收。采集程序能识别本机 STOP 回显并中止当前记录。身份核对绑定本轮主机启动、接口实例及 USB 设备；重启或重新枚举后需复核配置。私有身份绑定与操作日志只保存在现场主机。

## 离线验证与交付

- 隔离测试核对真实按钮的 Qt 信号、固定线格式、启动关闭零发送、失联及替换接口、发送失败、有限重发和未确认超时。使用本地 Unix 数据报和 Linux 内核时间戳验证反馈确认，全程未打开物理 CAN 发送通道。
- 用已冻结的 655 组直连目标回放核对兼容性。官方写盘离线回归得到 64 对合成图像、64 条有效反馈和 48 条有效或保持的动作，首次目标前有 16 条空动作；四路时间索引一致。
