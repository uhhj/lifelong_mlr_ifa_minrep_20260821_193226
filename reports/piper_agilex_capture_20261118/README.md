# PiPER 时钟修复与 AgileX 官方采集接入

2026-11-18（北京时间）。`rlmi` 已安装时间戳修复和桌面入口 **PiPER AgileX 录制**。本轮完成离线验收，现场带机械臂的试采待验收。

## 时钟与 STOP

SocketCAN 接收和发送回显共用一次会话级时钟偏移。保留内核原始时间、主机观察时间与换算后的时间。真实时钟跳变、活动时陈旧积压及关节组帧保护仍有效。遥操入口、500 ms 本机管道心跳及 STOP 检查保持原样。

- `rlmi` 上通过 51 项控制和心跳测试，包括恰好 500 ms 时触发保护。
- 回放两段记录，共 106,707 帧主臂关节报文。原故障记录的 1 次投影时间倒退归零，重放多恢复出被误停打断的完整关节组。另一段的 34,243 个完整组保持一致。
- 替换时持有遥操锁且控制进程未运行，备份原文件并核对安装文件哈希。

## 官方录制

上游 `data_tools` ROS 2 版本 `1363e0579ad6cb3980f65e200a3c536481c819ab` 与 `data_msgs` 版本 `0405bbaad280e0d076850fce73cdfac473c202ca` 在本机独立构建。官方节点保存双相机和两条从臂数据流。只读桥从遥操日志匹配下发记录和 `can0` 发送回显，按图像对时间取已确认目标及反馈。目标和反馈在官方格式中使用 Float32 数组，另在 `alignment.jsonl` 保存未降精度的值、原始帧回显与来源时间。每组数据共用时间索引，原始 CAN 时间线独立保留。相机配对以主机收帧时刻为准。 [AgileX 官方源码](https://github.com/agilexrobotics/data_tools/tree/1363e0579ad6cb3980f65e200a3c536481c819ab)

现场遥操完成绑定后可保持静止起录。在首条完整下发目标得到确认前，目标数组为空，图像和有效反馈继续保存。已有完整目标保持不变时保留原始下发时间。旧录制台与新入口共用相机锁。
