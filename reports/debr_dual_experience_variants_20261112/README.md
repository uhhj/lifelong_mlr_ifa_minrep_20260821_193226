# DEBR 双经验协同框架：三种新版构图

用户要求重新设计多版，更直接呈现“双经验协同”的核心贡献，并为每版并排展示 SVG 和精修图。本次以原生 SVG 同步完成排版与视觉精修，再由相同母版导出高清 PNG；不是将 PNG 重新临摹成另一种构图。没有调用生成式栅格图像模型。每版 PNG 3600×1880，SVG viewBox 为1800×940。

- A：双流汇聚。两条平行经验通路在右侧候选门控汇聚。
- B：双翼协同。上方两种经验等宽并列，下方统一协调更新。推荐用于正文总览。
- C：双记忆循环。中央策略与两类经验相互衔接，强调下一任务的持续积累。

打开 compare.html 可直接并排浏览实际 SVG 和高清 PNG，切换适应窗口/原尺寸。DEBR_A/B/C_comparison.png 是每版独立的左右对照图，左侧为 SVG 原尺寸渲染，右侧为高分辨率 PNG 缩览。缩放与抗锯齿可能有细微渲染差别，几何、文案和配色由同一源确定。各版的 PNG 和 SVG 不是互相独立生成的两张图。

图内统一 Times New Roman；所有文字、线条、图标与形状为原生 SVG 元素，无嵌入位图。图稿在本地字体环境核对；其他电脑编辑时应安装 Times New Roman。

语义依据为用户提供稿件及已核对的框架内容。CADL组织专家示范与执行监督；SHBR保持策略自主成功历史及固定行为参考，并按独立成功轨迹支持度加权。候选从同一完整状态和主批次序列出发；三个训练探针条件为BC_Q≤BC_C、Exec_Q≤Exec_C、Ret_Q<Ret_C，全部满足才提交Q，否则C。阶段末分别更新两种记忆；部署使用原策略推理。为了让框架图聚焦贡献，公式和实现细节仅保留关键关系，详尽定义仍见论文方法节。

未修改Word、旧图片、实验源或结果；无训练、评估和采集调用。本次发布仅包含新图稿、可复建代码、审查与轻量清单。

重建：依次运行build_A.py、build_B.py、build_C.py；再用Node执行render.cjs。渲染脚本使用本机Codex捆绑Sharp路径。
