# PiPER 三任务桌面执行台

已在现场数据服务器的用户桌面安装并核验「PiPER 策略执行台」。本轮完成离线验证。实机动作和任务成功率仍待现场测试。

## 现场使用

1. 双击图标，选择 B1 左侧蓝碟抓放、B2 右侧浅色碟抓放或 B3 推入左侧黄色区。界面自动使用训练时对应的任务指令。
2. 点击「开始只读预测」。相机占用锁与录制台共用，同一时刻只能由一方采集。在窗口中查看六轴与夹爪的实际位置和预测目标。此模式允许示教主臂保持直连。
3. 实际执行前，现场排除既往静止抽动，断开示教主臂，按厂家步骤将操作臂准备为普通 CAN 关节位置速度模式，核对现场独立急停。实时预测稳定后，点击「开始现场执行」并核对任务。程序检查绑定接口、新鲜反馈、驱动状态及其他控制源。该入口不代办复位或六轴使能。[松灵双臂指南](https://github.com/agilexrobotics/piper_sdk/blob/master/assets/double_piper.MD#22-control-slave-arm)
4. 由现场人员判定结果，点击成功或失败结束。两者都会提交软件 STOP。遇到异常时点击「停止 / STOP」。若窗口显示 STOP 未确认，应使用现场独立急停。本轮结束后进程释放双相机。每次现场执行前重新核对控制器状态。

## 执行及保护参数

界面、GPU 推理和 CAN 监控独立运行。监控进程在本机管道接收窗口心跳与策略预测。只读预测时硬件发送为零。执行中窗口心跳或有效预测超时 500 ms、新鲜反馈丢失、八帧历史中断、收到其他运动指令或遇到总线错误，均结束该轮并尝试 STOP。执行停止时最多等待 500 ms 确认控制器急停反馈。软件监控与 STOP 均依赖主机及 CAN 通信。

首版现场调试参数为每轮最多 30 秒、普通关节模式 10% 速度档、关节目标变化上限每轴 24°/s、夹爪目标变化上限 35 mm/s。模型每次使用按俯视、腕部顺序配对的画面及同步从臂反馈。配对上限 20 ms，预测最多使用 100 ms 前的画面。每个会话的本地日志记录所选任务、单调时间、反馈、原始预测、执行时下发的限幅目标及结束原因。成功与失败由现场判定。

## 离线验证

分别在 B1、B2、B3 留出示范中回放一个八帧窗口。逐对提取视觉特征的实时实现与训练代码的批量回放相比，三次比对的六轴最大绝对差为 0.01011°，夹爪最大绝对差为 0.02287 mm。比较对象是两条推理实现的输出。

独立 Unix 套接字模拟五种工况。只读预测及持续收到主臂指令时均发送零帧。模拟成功结束、执行中出现另一发令源、窗口心跳中断三种工况均观察到 STOP 及模拟控制器的急停反馈。另验证缺失或超时的反馈帧不能跨组拼接。图形窗口启动检查通过，初始执行按钮禁用。桌面启动条目通过格式、可执行和桌面信任属性检查。离线验证没有打开真实 CAN 或相机。[验证程序](../../scripts/piper_executor/verify.py) · [运行记录](offline.json)
