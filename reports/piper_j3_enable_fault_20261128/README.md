J3 没有进入使能态，其余五轴仍报告使能，不能判整臂已失能。控制器仍能向上位机周期上报状态；整机报出的关节通信故障可以与这些周期报文同时出现。电压和温度均为采样时刻的反馈。它们不能追溯排除故障发生瞬间的掉电、接触不良或驱动重启。[松灵驱动状态位](https://github.com/agilexrobotics/piper_sdk/blob/master/piper_sdk/piper_msgs/msg_v2/feedback/arm_feedback_low_spd.py)
