# OVR：20条探索性教师筛查（授权范围）

用户在2026-10-20明确选择先做20条探索性教师筛查。此选择覆盖附件对本轮全流程独立分区的要求；完整蒸馏与独立测试协议暂不执行。

- OBJECT seed42 Task6，固定同一次RA+IFA阶段9为父模型、阶段7为历史教师，均最终epoch99。
- 固定初态20–29；每模型各10条，共20条，先父后教师，两个独立进程。50个官方初态中的20–39已被其他实验使用，本轮不是全新确认集。
- 每组一个10路vector，环境seed42，5次零动作初始化，最多600策略步，原8步历史、原图像预处理和模块eval模式。
- 每初态独立CPU torch.Generator，seed=42000000+initial_index；一次生成600×7标准Normal。双方使用相同初态与步号噪声，不共享已消费的generator状态，不因成功/失败追加或重试。
- 动作=原argmax混合分量的均值+该分量原标准差×匹配噪声。全部7维；不降低方差、不均值执行、不随机抽分量、不修改模型。
- 预检仅软件/真实GPU接口，history1/4/8；0 optimizer、0环境。正式预算不含任何额外环境smoke。出现技术异常保留attempt并停止，不盲恢复部分vector。
- 保存resolved config、权重/原源码/初态hash、两组完整episode结果与attempt、逐步动作及分布hash、噪声hash；二进制RNG只在服务器保存，不发布。
- 输出SS/SF/FS/FF（父→教师）、成功率差及逐初态对照。教师优于父模型仅描述本次探索性筛查；不据此自动训练OVR、不启动其他任务或seed。完整独立分区、蒸馏预算、损失及启用阈值另定。
- 仅20条完成、2个vector完成且无技术异常、输入hash不变、进程退出0、独立复算通过才标记SCREEN_COMPLETED。没有教师优势也属于有效筛查结果。
- 按AGENTS发布代码及轻量证据到MLR。禁止发布权重、原始动作、latent、噪声表、RNG二进制或凭据。
